# Самоперевірка та домашнє завдання

## Питання для самоперевірки

Питання згруповані за підрозділами теми. Відповідайте своїми словами — якщо
не виходить, поверніться до відповідного підрозділу.

### Створення та ініціалізація рядків

1. Чим ключове слово `string` відрізняється від `System.String`? Чи є між
   ними хоч якась реальна різниця під час виконання програми?
2. Ви маєте три змінні: `string a = "";`, `string b = String.Empty;`
   і `string c = null;`. Яка між ними різниця? Для якої з них виклик
   `a.Length` завершиться винятком і чому?
3. Що виведе `Console.WriteLine("C:\\Users\\Ivan");`? Запишіть той самий
   шлях через verbatim-рядок. Скільки символів у кожному з цих двох рядків?
4. Для чого потрібен префікс `@` перед рядком? Що станеться з послідовністю
   `\n` усередині такого рядка?
5. Порівняйте два способи скласти повідомлення: конкатенацію через `+`
   та інтерполяцію `$"..."`. Чому в сучасному коді радять другий варіант?
   Як із масиву `char[]` отримати рядок?

### Операції з рядками

6. Що означає «рядки в C# незмінні»? Що насправді відбувається в пам'яті,
   коли ви пишете `s += " World";`?
7. **Що виведе цей код?** Поясніть кожен рядок виводу.

   ```csharp
   string s1 = "Hello";
   string s2 = s1;
   s1 += " World";
   Console.WriteLine(s1);
   Console.WriteLine(s2);
   ```

8. Чому рядок `text[0] = 'h';` не компілюється, хоча `char c = text[0];`
   працює? Як тоді замінити один символ у рядку?
9. Чому індекс останнього символу — це `text.Length - 1`, а не `text.Length`?
   Що станеться, якщо звернутися за індексом `text.Length`?
10. **Що виведе цей код?** Порахуйте індекси вручну, не запускаючи програму.

    ```csharp
    string text = "Hello World";
    Console.WriteLine(text.IndexOf("o"));
    Console.WriteLine(text.LastIndexOf("o"));
    Console.WriteLine(text.Substring(6));
    Console.WriteLine(text.Remove(5));
    ```

11. Порівняйте `a == b`, `a.Equals(b, StringComparison.OrdinalIgnoreCase)`
    та `String.Compare(a, b)`. Що повертає кожен із них і в якій ситуації
    оператора `==` недостатньо? Що повертає `IndexOf`, якщо підрядок
    не знайдено, і чому саме таке значення, а не `0`?
12. **Знайдіть помилку в цьому коді.** Програма має вивести `Hello C#`,
    але виводить щось інше. Що саме і чому?

    ```csharp
    string text = "  Hello World  ";
    text.Trim();
    text.Replace("World", "C#");
    Console.WriteLine(text);
    ```

13. **Знайдіть помилку в цьому коді.** За яких вхідних даних він впаде?
    Як його захистити?

    ```csharp
    string name = Console.ReadLine();
    string prefix = name.Substring(0, 3);
    Console.WriteLine(prefix.ToUpper());
    ```

14. Чим `IsNullOrEmpty` відрізняється від `IsNullOrWhiteSpace`? Наведіть
    вхідні дані, на яких вони дадуть різний результат, і поясніть, який
    із методів доречніший для перевірки введення користувача.
15. Як із рядка `"C#,Java,Python"` отримати масив мов, а потім зібрати
    його назад у рядок, розділений словом « або »? Які два методи потрібні?

### StringBuilder

16. Чому конкатенація в циклі на 10 000 ітерацій — погана ідея? Скільки
    приблизно об'єктів у пам'яті створить такий цикл?
17. Що таке внутрішній буфер `StringBuilder` і що з ним відбувається, коли
    доданого тексту стає більше, ніж він може вмістити?
18. **Що виведе цей код?** Порахуйте індекси вручну. У конспекті поруч
    із цими рядками стоять коментарі `"Hello, Beautiful World!"`
    та `"Hello, Beautiful!"` — перевірте, чи другий коментар правдивий,
    і якщо ні, то які аргументи `Remove` дали б саме такий результат.

    ```csharp
    StringBuilder sb = new StringBuilder("Hello World!");
    sb.Insert(5, ", Beautiful");
    sb.Remove(13, 9);
    Console.WriteLine(sb);
    ```

19. Назвіть три ситуації, у яких `String` кращий за `StringBuilder`,
    і три — навпаки. Чому незмінність рядка є перевагою, коли рядок
    використовують як ключ у колекції?
20. Який простір імен треба підключити для роботи зі `StringBuilder`?
    Що треба викликати, щоб отримати зі `StringBuilder` звичайний рядок?

## Практичні міні-задачі

Короткі вправи на 5–10 хвилин кожна, для перевірки розуміння прямо
після лекції.

1. **Рядок навиворіт.** Прочитайте слово з консолі й виведіть його
   у зворотному порядку — двома способами: циклом `for` від кінця
   до початку та через `ToCharArray()` і `Array.Reverse()`. Перевірте
   обидва на слові «дід».

2. **Три числа про речення.** Прочитайте речення й виведіть: скільки
   в ньому символів, скільки символів без пробілів і скільки слів.
   Для слів скористайтеся `Split(' ', StringSplitOptions.RemoveEmptyEntries)`
   — інакше подвійний пробіл додасть «порожнє слово».

3. **Маска картки.** Користувач вводить номер картки з 16 цифр. Виведіть
   його у вигляді `**** **** **** 1234` — тобто видно лише останні чотири
   цифри. Знадобляться `Substring` і конструктор `new string('*', 4)`.

4. **Паліндром без прикрас.** Перевірте, чи є введений рядок паліндромом,
   ігноруючи регістр і пробіли. «А роза упала на лапу Азора» має вважатися
   паліндромом.

5. **Прогрес-бар.** Напишіть метод, який за числом відсотків від 0 до 100
   повертає рядок вигляду `[#######···········] 35%`. Смужка має 20 позицій.
   Зберіть її за допомогою `StringBuilder`, а не конкатенацією.

6. **Знайди неефективність.** Візьміть код із питання 16 (конкатенація
   в циклі), виміряйте час його роботи через `System.Diagnostics.Stopwatch`,
   потім перепишіть на `StringBuilder` і виміряйте ще раз. Запишіть обидва
   числа — різниця вас здивує.

## Домашнє завдання

:::info[Що здавати]
Один консольний проєкт (або один файл `.cs`) + скриншот роботи програми.
Орієнтовний час виконання — 30–45 хвилин.
:::

### Завдання: «Аналізатор тексту»

Ви пишете маленький інструмент, який студенти використовують перед здачею
реферату: вставляєш абзац — отримуєш статистику. Скільки там слів, чи не
надто довгі слова, яких літер забагато і скільки часу це читати.
Програма читає один рядок тексту з консолі й друкує звіт.

Увесь звіт треба **зібрати в один `StringBuilder`** і вивести одним
викликом `Console.WriteLine` наприкінці — не друкуйте по рядочку.

**Вимоги:**

- прочитати текст; якщо введення порожнє або складається лише з пробілів
  (`IsNullOrWhiteSpace`), чемно попросити ввести ще раз;
- порахувати: усього символів, символів без пробілів, кількість слів,
  кількість речень (за крапками, знаками оклику та питання);
- знайти найдовше та найкоротше слово (разом із їхньою довжиною);
- порахувати середню довжину слова з точністю до одного знака після коми;
- вивести топ-3 найчастіші літери тексту з кількістю входжень
  (регістр не враховувати, розділові знаки й цифри пропускати);
- знайти всі слова-паліндроми довжиною від трьох літер і вивести їх
  через кому;
- оцінити час читання: приблизно 200 слів за хвилину, результат — у секундах;
- весь звіт зібрати через `StringBuilder` і вивести один раз.

**Приклад роботи:**

```
Вставте текст для аналізу:
Кіт Тарас шукав око. Око заплющилось, а Тарас засміявся. Дід і біб!

=== АНАЛІЗ ТЕКСТУ ===
Символів усього:        66
Символів без пробілів:  55
Слів:                   12
Речень:                 3

Найдовше слово:    заплющилось (11 літер)
Найкоротше слово:  а (1 літера)
Середня довжина:   4,6 літери

Топ-3 літери:
  а — 9 разів
  с — 6 разів
  о — 5 разів

Слова-паліндроми: око, дід, біб

Час читання: приблизно 4 с
```

:::tip[Підказка]
Слова зручно отримати одним викликом:

```csharp
char[] separators = { ' ', ',', '.', '!', '?', ';', ':' };
string[] words = text.Split(separators, StringSplitOptions.RemoveEmptyEntries);
```

Перед порівнянням слова очищайте від розділових знаків і приводьте
до нижнього регістру: `word.Trim('.', ',', '!').ToLower()`.

Для частоти літер **не потрібні словники** — вони будуть у наступних темах.
Заведіть рядок з алфавітом
`string alphabet = "абвгґдеєжзиіїйклмнопрстуфхцчшщьюя";`
і масив `int[] counts = new int[alphabet.Length];`. Далі пройдіть текст
у нижньому регістрі символ за символом, для кожного символу знайдіть його
позицію через `alphabet.IndexOf(c)` і, якщо вона не `-1`, збільште
відповідний лічильник. Топ-3 — це три проходи по масиву лічильників
із пошуком максимуму (знайшли, вивели, обнулили).

Паліндром зручно перевіряти окремим методом `bool IsPalindrome(string w)`,
який ви вже написали в міні-задачі 4.
:::

**Додатково (за бажанням, на вищу оцінку):** додайте режим «форматувальник».
Після звіту програма пропонує привести текст до охайного вигляду: прибрати
подвійні пробіли, зробити першу літеру кожного речення великою, а решту
речення — з нормальним регістром — і вивести виправлений текст.
Підказка: `while (text.Contains("  ")) text = text.Replace("  ", " ");`
