# Самоперевірка та домашнє завдання

## Питання для самоперевірки

Питання згруповані за підрозділами теми. Відповідайте своїми словами — якщо не виходить,
поверніться до відповідного підрозділу.

### Цикли for, while та do-while

1. З яких трьох частин складається заголовок циклу `for`? Що саме робить кожна з них
   і в якому порядку вони виконуються під час першої ітерації?
2. Коли доречніше взяти `for`, а коли `while`? Сформулюйте правило одним реченням,
   спираючись на те, що вам відомо про кількість повторень.
3. Заповніть по пам'яті: скільки разів **щонайменше** виконається тіло циклу `for`,
   `while` та `do-while`? Чому в останнього це число інше?
4. У `while` умова перевіряється перед тілом, у `do-while` — після. Наведіть задачу,
   у якій ця різниця критична, і задачу, у якій вона не має значення.
5. Що виведе цей код? Скільки буде рядків і яким буде останнє число?

   ```csharp
   for (int i = 0; i < 5; i++)
   {
       Console.WriteLine("Ітерація: " + i);
   }
   ```

6. Що станеться, якщо в циклі `while (i < 5)` забути рядок `i++`? Як називається таке
   явище і чим воно небезпечне?
7. Змінна `i`, оголошена в заголовку `for`, недоступна після завершення циклу. Чому це
   не помилка мови, а зручність? Як бути, якщо значення лічильника потрібне й після
   циклу?

### Оператори break, continue та вкладені цикли

8. Чим `break` відрізняється від `continue`? Що з них «виходить», а що «пропускає»?
9. Що виведе цей код?

   ```csharp
   for (int i = 0; i < 10; i++)
   {
       if (i % 2 == 0)
       {
           continue;
       }
       Console.WriteLine(i);
   }
   ```

10. У вкладених циклах `break` стоїть у внутрішньому циклі. З якого саме циклу він
    виведе програму? Що потрібно, щоб перервати обидва?
11. Скільки разів усього виконається тіло внутрішнього циклу в прикладі з лекції,
    де зовнішній іде від 0 до 2 і внутрішній теж від 0 до 2? А якщо зовнішній зробити
    від 0 до 9?
12. `continue` у циклі `while` може легко призвести до зависання програми, а в `for` —
    ні. Поясніть, чому, і покажіть на короткому прикладі.

### Цикл foreach

13. Коли `foreach` зручніший за `for` і чого він принципово **не вміє**, на відміну
    від `for`?
14. Що станеться, якщо всередині `foreach` спробувати присвоїти нове значення змінній
    циклу? Чому мова це забороняє?
15. Що виведе цей код і яким є тип змінної `c`?

    ```csharp
    string text = "CSharp";
    foreach (char c in text)
    {
        Console.WriteLine(c);
    }
    ```

16. Вам потрібно вивести елементи масиву з нумерацією — «1. кіт», «2. будинок».
    Чи впорається сам `foreach`? Що доведеться додати і чи не простіше взяти `for`?

### Приклади використання циклів

17. У прикладі обчислення середнього арифметичного масив був `{1, 2, 3, 4, 5}`
    і відповідь виявилася правильною. Замініть масив на `{1, 2, 3, 4}`. Що виведе
    програма, чому не `2,5` і як це виправити?
18. У прикладі «сума чисел, поки не досягнемо 100» цикл виглядає так:

    ```csharp
    int sum = 0;
    int i = 1;
    while (sum < 100)
    {
        sum += i;
        i++;
    }
    Console.WriteLine("Сума: " + sum);
    ```

    Яке число виведе програма і чому воно не дорівнює рівно 100?
19. У прикладі пошуку першого числа, кратного 7, змінна `number` починається з 1.
    Що виведе програма, якщо почати з 0? Чому це вважають помилкою, а не особливістю?
20. Чому для «запитувати пароль, доки не введуть правильний» у лекції обрано саме
    `do-while`, а не `while`? Що довелося б додати, якби ми взяли `while`?

## Практичні міні-задачі

Короткі вправи на 5–10 хвилин кожна, для перевірки розуміння прямо після лекції.

1. **Сума цифр числа.** Користувач вводить ціле число (наприклад, 4729). Виведіть суму
   його цифр. Підказка: `n % 10` дає останню цифру, `n / 10` прибирає її.

2. **Таблиця множення.** Виведіть вкладеними циклами таблицю множення від 1 до 9
   у вигляді рівної таблиці, по дев'ять чисел у рядку. Вирівняйте стовпчики.

3. **Ялинка з зірочок.** За введеною висотою `n` виведіть трикутник із символів `*`:
   у першому рядку одна зірочка, у другому дві і так далі. Потім переверніть його
   вершиною вниз, змінивши лише заголовок циклу.

4. **Перше просте після числа.** Користувач вводить число. Знайдіть найближче більше
   за нього просте число. Використайте вкладений цикл для перевірки на простоту
   і `break`, щойно знайшли дільник.

5. **Три спроби.** Напишіть цикл, який дає користувачу рівно три спроби ввести число
   від 1 до 10. Якщо ввід коректний — вийдіть з циклу через `break` і привітайте.
   Якщо всі три спроби змарновано — виведіть повідомлення про це після циклу.

6. **Порахуй голосні.** Пройдіться `foreach` по введеному рядку і порахуйте, скільки
   в ньому голосних літер. Порівняйте, наскільки ця сама задача складніша через `for`.

## Домашнє завдання

:::info Що здавати
Один консольний проєкт (або один файл `.cs`) + скриншот роботи програми.
Орієнтовний час виконання — 30–45 хвилин.
:::

### Завдання: «Вгадай число за 7 спроб»

Класична гра, яку можна показати другові одразу після написання. Програма загадує
випадкове число від 1 до 100, а гравець намагається його вгадати. Після кожної спроби
програма підказує «більше» або «менше» і повідомляє, скільки спроб залишилось.
Якщо за 7 спроб число не вгадано — гра програна, і програма показує загадане число.

Сім спроб — не випадкове число: якщо щоразу ділити діапазон навпіл, ста чисел вистачає
рівно на сім кроків. Після того, як гра запрацює, спробуйте вигравати саме так.

**Вимоги:**

- загадати число: `Random random = new Random(); int secret = random.Next(1, 101);`
- цикл на **7 спроб**, з лічильником, який показується гравцеві;
- після кожного невдалого введення — підказка «Загадане число більше»
  або «Загадане число менше»;
- вихід із циклу через `break` одразу після правильної відповіді;
- після циклу — підсумок: перемога з кількістю витрачених спроб або поразка
  із загаданим числом;
- якщо гравець вводить не число або число поза межами 1–100 — сказати про це
  і **не зараховувати** спробу (підказка: `int.TryParse`).

**Приклад роботи:**

```
=== ВГАДАЙ ЧИСЛО ===
Я загадав число від 1 до 100. У тебе 7 спроб.

Спроба 1 з 7. Твоє число: 50
Загадане число більше.

Спроба 2 з 7. Твоє число: 75
Загадане число менше.

Спроба 3 з 7. Твоє число: 62
Загадане число менше.

Спроба 4 з 7. Твоє число: 150
Число має бути від 1 до 100. Спроба не зарахована.

Спроба 4 з 7. Твоє число: 56
Загадане число більше.

Спроба 5 з 7. Твоє число: 59
Вітаю! Ти вгадав за 5 спроб.
```

:::tip Підказка
Щоб некоректне введення не з'їдало спробу, збільшуйте лічильник спроб **не** в заголовку
`for`, а вручну, лише після коректного ходу. Тому тут природніше взяти `while`
з власним лічильником, ніж `for`.

`int.TryParse(input, out int guess)` повертає `true`, якщо рядок вдалося перетворити
на число, і не ламає програму, якщо гравець написав «сорок».

Створюйте `Random` **один раз** до циклу, а не всередині нього.
:::

**Додатково (за бажанням, на вищу оцінку):** після завершення раунду запитайте
«Зіграти ще? (так/ні)» і загорніть усю гру в зовнішній цикл `do-while`. Ведіть рахунок
по всіх раундах: скільки перемог, скільки поразок і за скільки спроб у середньому
гравець вгадує. Виведіть цю статистику, коли гравець нарешті відмовиться грати далі.
