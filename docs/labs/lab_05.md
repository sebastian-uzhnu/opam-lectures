# Лабораторна робота №5

## Тема
Програмування розгалужених алгоритмів. Оператори if/else та switch

## Мета
Навчитися складати й програмувати алгоритми з розгалуженням. Закріпити операції
порівняння та логічні операції, зокрема їх скорочене обчислення. Набути навичок
застосування операторів `if`, `if/else`, `else if`, тернарного оператора, оператора
й виразу `switch`, а також зіставлення зі зразком. Навчитися розпізнавати типові
помилки в умовах і уникати їх.

## Теоретичні відомості

### 1. Що таке розгалуження

У попередніх роботах усі програми були **лінійними**: оператори виконувалися один за
одним, згори вниз, без винятків. Такою програмою не можна описати навіть найпростіше
життєве правило: «якщо покупка дорожча за 1000 гривень — знижка 5 %».

**Розгалуження** — конструкція алгоритму, у якій подальший хід виконання залежить від
істинності певної умови. Воно буває **неповним** (дію виконують або пропускають)
і **повним** (обирають одну з двох дій).

```text
   НЕПОВНЕ РОЗГАЛУЖЕННЯ                ПОВНЕ РОЗГАЛУЖЕННЯ
          │                                    │
     ╱ умова ╲── ні ──┐                   ╱ умова ╲── ні ──┐
          │ так       │                        │ так       │
     ┌─────────┐      │                  ┌─────────┐  ┌─────────┐
     │   дія   │      │                  │  дія 1  │  │  дія 2  │
     └─────────┘      │                  └─────────┘  └─────────┘
          │           │                        │           │
          ▼◀──────────┘                        ▼◀──────────┘
```

### 2. Логічний тип і операції порівняння

**Тип `bool`** має рівно два значення: `true` (істина) і `false` (хиба). Саме значення
типу `bool` очікує будь-яка умова в C#.

**Операція порівняння** — це операція, що повертає `bool`.

| Операція | Назва | Приклад | Результат |
|---|---|---|---|
| `==` | дорівнює | `5 == 5` | `true` |
| `!=` | не дорівнює | `5 != 3` | `true` |
| `>` | більше | `2 > 7` | `false` |
| `<` | менше | `2 < 7` | `true` |
| `>=` | більше або дорівнює | `7 >= 7` | `true` |
| `<=` | менше або дорівнює | `8 <= 7` | `false` |

Результат порівняння можна зберегти у змінній — це звичайне значення:

```csharp
int temperature = 12;
bool isCold = temperature < 15;
Console.WriteLine($"Холодно: {isCold}");        // Холодно: True
```

Порівнювати через `>` і `<` можна лише впорядковані величини (числа, символи, дати).
Рядки так порівнювати не можна — для них є окремі методи, які розглядатимуться пізніше;
на рівність рядки порівнюють через `==`.

### 3. Логічні операції

Реальні умови рідко бувають простими: «якщо вік від 14 до 18 років», «якщо це субота або
неділя». Складені умови будують логічними операціями.

| Операція | Назва | Зміст | Приклад |
|---|---|---|---|
| `&&` | І (кон'юнкція) | істина, коли **обидві** частини істинні | `age >= 18 && hasPassport` |
| `\|\|` | АБО (диз'юнкція) | істина, коли істинна **хоч одна** частина | `day == 6 \|\| day == 7` |
| `!` | НЕ (заперечення) | змінює значення на протилежне | `!isWeekend` |

Таблиця істинності (`a` і `b` — логічні значення):

| a | b | `a && b` | `a \|\| b` | `!a` |
|---|---|---|---|---|
| `true` | `true` | `true` | `true` | `false` |
| `true` | `false` | `false` | `true` | `false` |
| `false` | `true` | `false` | `true` | `true` |
| `false` | `false` | `false` | `false` | `true` |

Пріоритет операцій, від вищого до нижчого: `!` → арифметика → порівняння → `&&` → `||`.
Отже, `a > 5 && b < 3` означає `(a > 5) && (b < 3)`; дужки все одно ставте там, де без них
читати важче. Поширена помилка — математичний запис подвійної нерівності: умова «x у
проміжку від 0 до 10» записується **не** як `0 <= x <= 10` (це не компілюється), а так:

```csharp
int x = 7;
bool inRange = x >= 0 && x <= 10;
Console.WriteLine($"Число в проміжку [0; 10]: {inRange}");   // True
```

**Скорочене обчислення** (short-circuit evaluation) — властивість операцій `&&` і `||`
не обчислювати другий операнд, якщо результат уже відомий: для `&&` хибна ліва частина
робить хибною всю умову, для `||` істинна ліва частина робить істинною всю умову.
Це не оптимізація заради швидкості, а засіб захисту — порядок частин умови важливий:

```csharp
int count = 0;
int total = 100;

// Безпечно: якщо count == 0, ділення навіть не почнеться
bool isBigAverage = count != 0 && total / count > 10;
Console.WriteLine($"Середнє більше за 10: {isBigAverage}");   // False
```

Якби частини стояли навпаки — `total / count > 10 && count != 0` — програма аварійно
завершилася б через ділення на нуль. Існують також операції `&` та `|`, які обчислюють
обидва операнди завжди; для умов у розгалуженнях вживайте саме `&&` і `||`.

### 4. Оператор `if` і `if/else`

```csharp
if (умова)
{
    // блок виконується, якщо умова істинна
}
else
{
    // необов'язкова частина: виконується, якщо умова хибна
}
```

Приклад: контроль ваги ручної поклажі в аеропорту.

```csharp
Console.Write("Вага ручної поклажі, кг: ");
double weight = double.Parse(Console.ReadLine());
double limit = 8.0;

if (weight > limit)
{
    double excess = weight - limit;
    Console.WriteLine($"Перевищення на {excess:F1} кг.");
    Console.WriteLine("Поклажу треба здати в багаж.");
}
else
{
    Console.WriteLine("Вага в межах норми, проходьте на посадку.");
}
```

**Вивід:**

```
Вага ручної поклажі, кг: 9,4
Перевищення на 1,4 кг.
Поклажу треба здати в багаж.
```

Фігурні дужки формально можна не ставити, якщо в гілці один оператор. **Ставте їх
завжди**: дужки рятують від класичної помилки, коли до гілки дописують другий рядок,
а він виконується незалежно від умови.

### 5. Ланцюжок `else if`

Коли варіантів більше за два, гілки вишиковують у ланцюжок. Перевірка йде згори вниз;
щойно якась умова виявилася істинною, виконується її блок, а **решта перевірок
пропускається**.

```csharp
Console.Write("Введіть бал за 100-бальною шкалою: ");
int score = int.Parse(Console.ReadLine());
string nationalGrade;

if (score >= 90)
{
    nationalGrade = "відмінно";
}
else if (score >= 75)
{
    nationalGrade = "добре";
}
else if (score >= 60)
{
    nationalGrade = "задовільно";
}
else
{
    nationalGrade = "незадовільно";
}

Console.WriteLine($"Бал {score} — оцінка «{nationalGrade}»");
```

**Вивід:**

```
Введіть бал за 100-бальною шкалою: 78
Бал 78 — оцінка «добре»
```

Зверніть увагу: друга умова записана просто `score >= 75`, без `score < 90` — якби перша
умова була істинною, до другої виконання не дійшло б. Саме це робить ланцюжок коротким.
Але порядок умов критичний: якщо поставити `score >= 60` першою, бал 95 теж потрапить
у цю гілку й отримає «задовільно». Правило: у ланцюжку з числовими межами йдуть
**від найсуворішої умови до найм'якшої**.

### 6. Вкладені умови

Гілка `if` може містити всередині ще одне розгалуження. Так перевіряють умови, які мають
сенс лише після виконання попередньої.

```csharp
int age = 20;                 // вік пасажира
string card = "так";          // чи є студентський квиток
double basePrice = 120.0;
double price;

if (age < 18)
{
    price = basePrice * 0.5;              // дитячий квиток
}
else
{
    if (card == "так")
    {
        price = basePrice * 0.75;         // студентська знижка
    }
    else
    {
        price = basePrice;                // повний тариф
    }
}
Console.WriteLine($"До сплати: {price:F2} грн");
```

**Вивід:**

```
До сплати: 90,00 грн
```

Ту саму логіку можна записати ланцюжком без вкладеності:
`if (age < 18) ... else if (card == "так") ... else ...`.

Глибока вкладеність погано читається. Якщо рівнів більше трьох, майже завжди умову
можна переписати ланцюжком `else if` зі складеними умовами через `&&`.

### 7. Тернарний оператор

**Тернарний (умовний) оператор** `?:` — це не оператор розгалуження, а **вираз**: він
повертає значення. Загальний вигляд: `умова ? значення_якщо_істина : значення_якщо_хиба`.

```csharp
int a = 17;
int b = 42;

int max = a > b ? a : b;
string parity = a % 2 == 0 ? "парне" : "непарне";

Console.WriteLine($"Більше з {a} і {b}: {max}");        // 42
Console.WriteLine($"Число {a} — {parity}");             // непарне
Console.WriteLine($"Знижка: {(a > 10 ? "є" : "немає")}");   // є
```

Вживайте `?:` там, де треба вибрати одне з двох **значень** (усередині рядка з
інтерполяцією дужки навколо нього обов'язкові). Для вибору між двома **діями** беріть
`if/else`: вкладені тернарні оператори читати важко.

### 8. Оператор `switch`

Коли одну й ту саму величину порівнюють на рівність із переліком сталих, замість довгого
ланцюжка `else if` зручніше вживати `switch`.

```csharp
Console.Write("Номер дня тижня (1-7): ");
int dayNumber = int.Parse(Console.ReadLine());
switch (dayNumber)
{
    case 1:
        Console.WriteLine("Понеділок");
        break;
    case 6:
    case 7:
        Console.WriteLine("Вихідний");
        break;
    default:
        Console.WriteLine("Робочий день серед тижня");
        break;
}
```

**Вивід:**

```
Номер дня тижня (1-7): 6
Вихідний
```

Правила класичного `switch`: `case` порівнює **лише на рівність** зі сталим значенням;
кожна гілка має завершуватися `break` (або `return`), бо «провалювання» в наступну гілку
в C# заборонено; кілька `case` підряд без коду між ними означають «або-або», як `6` і `7`
вище; `default` — гілка для всіх інших значень, її бажано писати завжди; порядок гілок
на результат не впливає.

### 9. Вираз `switch` (C# 8 і новіші)

Сучасний C# має **вираз** `switch`, який, як і тернарний оператор, повертає значення.
Стрілка `=>` відокремлює зразок від результату, символ підкреслення `_` замінює
`default`, гілки розділяються комами.

```csharp
Console.Write("Код категорії товару (A, B, C): ");
string category = Console.ReadLine().ToUpper();
double vatRate = category switch
{
    "A" => 0.20,
    "B" => 0.07,
    "C" => 0.00,
    _ => -1
};
Console.WriteLine($"Ставка ПДВ: {vatRate:P0}");
```

**Вивід:**

```
Код категорії товару (A, B, C): b
Ставка ПДВ: 7 %
```

Кома після останньої гілки не потрібна, а крапка з комою після закритої фігурної дужки —
обов'язкова: це вираз, а не блок. Порівняння двох форм:

| Ознака | Оператор `switch` | Вираз `switch` |
|---|---|---|
| Що це | оператор: виконує дії | вираз: повертає значення |
| Розділювач | `case ... :` і `break` | `зразок => значення,` |
| Гілка «решта» | `default:` | `_ =>` |
| Повнота | `default` не обов'язковий | якщо жодна гілка не підійшла, виникає помилка виконання |
| Коли зручний | у гілках кілька дій | треба присвоїти одне значення з кількох |

### 10. Зіставлення зі зразком

**Зіставлення зі зразком** (pattern matching) — перевірка не лише на рівність, а й на
вигляд та властивості значення. Три засоби, потрібні вже зараз.

**Операція `is`** перевіряє значення на відповідність зразку й може одразу оголосити
змінну для перевіреного значення:

```csharp
object data = 42;
Console.WriteLine($"Це ціле число: {data is int}");
Console.WriteLine($"Це додатне ціле: {data is int n && n > 0}");
```

**Вивід:**

```
Це ціле число: True
Це додатне ціле: True
```

**Реляційні зразки** дають змогу писати в гілках `switch` не сталі, а нерівності.
Зразки можна поєднувати словами `and`, `or`, `not`:

```csharp
Console.Write("Температура повітря, °C: ");
int t = int.Parse(Console.ReadLine());
string advice = t switch
{
    < -10 => "Сильний мороз: одягніть термобілизну",
    >= -10 and < 0 => "Мороз: шапка і рукавиці",
    >= 0 and < 15 => "Прохолодно: візьміть куртку",
    >= 15 and < 25 => "Комфортно",
    _ => "Спека: тримайтеся тіні й пийте воду"
};
Console.WriteLine(advice);
```

**Вивід:**

```
Температура повітря, °C: 18
Комфортно
```

**Охоронна умова `when`** додає до зразка довільну логічну умову — те, чого самим
зразком не висловити:

```csharp
double amount = 2400;         // сума покупки
bool hasCard = true;          // чи є картка клієнта

double discount = amount switch
{
    >= 2000 when hasCard => 0.15,
    >= 2000 => 0.10,
    >= 1000 => 0.05,
    _ => 0.0
};

Console.WriteLine($"Знижка: {discount:P0}, до сплати: {amount * (1 - discount):F2} грн");
```

**Вивід:**

```
Знижка: 15 %, до сплати: 2040,00 грн
```

Гілки виразу `switch` перевіряються **згори вниз**, тому конкретніші зразки (з `when`)
мають стояти перед загальнішими.

### 11. Перевірка введених даних

Метод `int.TryParse` повертає `bool` — саме те, що потрібно умові. На відміну від
`int.Parse`, він не завершує програму аварійно на хибних даних:

```csharp
Console.Write("Введіть ціле число: ");
if (int.TryParse(Console.ReadLine(), out int number))
{
    Console.WriteLine($"Прийнято число {number}");
}
else
{
    Console.WriteLine("Це не ціле число.");   // для введення «сорок»
}
```

### 12. Типові помилки

| Помилка | Приклад | Наслідок і виправлення |
|---|---|---|
| `=` замість `==` | `if (x = 5)` | присвоєння замість порівняння; у C# це помилка компіляції «cannot implicitly convert int to bool». Писати `if (x == 5)` |
| Крапка з комою після `if` | `if (x > 0);` | тіло `if` порожнє, наступний блок виконується завжди. Прибрати `;` |
| Порівняння дробових на рівність | `if (0.1 + 0.2 == 0.3)` | `false`: `double` зберігається наближено. Порівнювати за модулем різниці: `Math.Abs(a - b) < 0.0001` |
| Забутий `break` у `switch` | `case 1: Console.WriteLine("...");` | помилка компіляції про «control cannot fall through». Додати `break` |
| Неправильний порядок у ланцюжку | `if (s >= 60) ... else if (s >= 90)` | друга умова недосяжна; йти від суворішої до м'якшої |
| Дужки без потреби відсутні | `if (a) b(); c();` | `c()` виконується завжди; ставити фігурні дужки |
| Порівняння рядків без урахування регістру | `if (answer == "Так")` | «так» не збігається. Застосувати `answer.ToLower() == "так"` |

Демонстрація проблеми з дробовими числами:

```csharp
double sum = 0.1 + 0.2;
Console.WriteLine($"Сума: {sum:R}");                    // 0,30000000000000004
Console.WriteLine($"sum == 0.3: {sum == 0.3}");         // False
Console.WriteLine($"{Math.Abs(sum - 0.3) < 0.0001}");   // True — правильна перевірка
```

## Приклад виконання

**Умова.** Служба доставки рахує вартість пересилання посилки. Користувач вводить вагу
посилки в кілограмах і код зони доставки: `M` — місто, `R` — область, `U` — інші області
країни. Тариф: до 1 кг включно — базова ставка зони; понад 1 кг — базова ставка плюс
15 грн за кожний повний кілограм понад перший. Базові ставки: `M` — 45 грн, `R` — 60 грн,
`U` — 80 грн. Якщо вага перевищує 30 кг, посилку не приймають. За суми понад 300 грн
діє знижка 10 %. Вивести підсумок.

**Аналіз.** Вхідні дані: `weight` (дробове, кг) і `zone` (рядок, одна літера). Спочатку
перевіряємо коректність введення (вага має бути числом і додатною), потім обмеження 30 кг —
це окрема гілка з відмовою. Базову ставку обираємо за кодом зони: тут природний вираз
`switch`. Доплату за вагу понад 1 кг рахуємо в `if`, знижку — тернарним оператором.

**Схема рішення:**

```text
  введення ваги й зони
          │
          ▼
    ╱ дані коректні? ╲── ні ──▶ повідомлення про помилку ──▶ кінець
          │ так
          ▼
    ╱ вага > 30 кг? ╲──── так ─▶ відмова в прийманні ─────▶ кінець
          │ ні
          ▼
  базова ставка за зоною (switch)
          │
          ▼
    ╱ вага > 1 кг? ╲── так ─▶ + 15 грн за кожний повний кг понад перший
          │ ні                         │
          ▼◀─────────────────────────--┘
  знижка 10 %, якщо сума > 300 грн  (?:)
          │
          ▼
       виведення
```

**Код:**

```csharp
// Розрахунок вартості доставки посилки
Console.WriteLine("=== Розрахунок вартості доставки ===");
Console.Write("Вага посилки, кг: ");
string weightInput = Console.ReadLine();
Console.Write("Зона доставки (M - місто, R - область, U - країна): ");
string zone = Console.ReadLine().Trim().ToUpper();

// 1. Перевірка коректності введення
if (!double.TryParse(weightInput, out double weight) || weight <= 0)
{
    Console.WriteLine("Помилка: вага має бути додатним числом.");
}
else if (weight > 30)
{
    // 2. Обмеження служби доставки
    Console.WriteLine($"Вага {weight:F2} кг перевищує максимальні 30 кг.");
    Console.WriteLine("Посилку слід оформити як вантажне відправлення.");
}
else
{
    // 3. Базова ставка залежно від зони
    double baseRate = zone switch
    {
        "M" => 45.0,
        "R" => 60.0,
        "U" => 80.0,
        _ => -1.0                       // ознака невідомої зони
    };

    if (baseRate < 0)
    {
        Console.WriteLine($"Помилка: невідома зона доставки «{zone}».");
    }
    else
    {
        // 4. Доплата за вагу понад один кілограм
        double extraCharge = 0;
        if (weight > 1)
        {
            // Math.Ceiling округлює вгору: 1,2 кг - це вже один повний зайвий кілограм
            int extraKilos = (int)Math.Ceiling(weight - 1);
            extraCharge = extraKilos * 15.0;
        }

        double cost = baseRate + extraCharge;

        // 5. Знижка за суму понад 300 грн
        double discountRate = cost > 300 ? 0.10 : 0.0;
        double finalCost = cost * (1 - discountRate);
        string zoneName = zone switch { "M" => "місто", "R" => "область", _ => "країна" };

        Console.WriteLine();
        Console.WriteLine($"Зона: {zoneName}, базова ставка {baseRate:F2} грн");
        Console.WriteLine($"Доплата за вагу: {extraCharge:F2} грн");
        Console.WriteLine($"Вартість без знижки: {cost:F2} грн");
        Console.WriteLine($"Знижка: {discountRate:P0}");
        Console.WriteLine($"До сплати: {finalCost:F2} грн");
    }
}
```

**Вивід (вага в межах норми, доплата є, знижки немає):**

```

Вага посилки, кг: 4,5

Зона: область, базова ставка 60,00 грн
Доплата за вагу: 60,00 грн
Вартість без знижки: 120,00 грн
Знижка: 0 %
До сплати: 120,00 грн
```

**Вивід (спрацювала знижка):**

```
Вага посилки, кг: 18
Зона доставки (M - місто, R - область, U - країна): u

Зона: країна, базова ставка 80,00 грн
Доплата за вагу: 255,00 грн
Вартість без знижки: 335,00 грн
Знижка: 10 %
До сплати: 301,50 грн
```

Для ваги 42 кг програма не рахує нічого: спрацьовує друга гілка ланцюжка й виводиться
відмова в прийманні посилки.

**Висновок за прикладом.** У програмі задіяно три засоби розгалуження, і кожен ужито
за призначенням: ланцюжок `if / else if / else` — для взаємовиключних сценаріїв
(помилка, відмова, розрахунок); вираз `switch` — для вибору значення за кодом зони;
тернарний оператор — для вибору одного з двох чисел. Порядок перевірок не випадковий:
спочатку коректність даних, потім обмеження, і лише потім обчислення.
