# Лабораторна робота №3

## Тема
Програмування лінійних алгоритмів. Введення-виведення даних

## Мета
Навчитися складати й реалізовувати лінійні алгоритми — послідовності дій без повторень
і розгалужень. Закріпити арифметичні операції мови C#, зокрема цілочисельне ділення
й остачу, та правила пріоритету операцій. Набути навичок використання методів класу `Math`,
безпечного зчитування числових даних із клавіатури й форматованого виведення результатів.

## Тривалість
2 академічні години.

## Обладнання та програмне забезпечення
Персональний комп'ютер, .NET 8 SDK, будь-яке середовище розробки або текстовий редактор
разом із терміналом, система контролю версій Git.

## Теоретичні відомості

### 1. Лінійний алгоритм

**Алгоритм** — скінченна послідовність однозначних дій, що приводить від вихідних даних
до результату. **Лінійний алгоритм** — такий, у якому всі дії виконуються строго
одна за одною, кожна рівно один раз, а порядок їх виконання не залежить від даних.

```
 ┌─────────┐   ┌───────────┐   ┌──────────────┐   ┌───────────┐   ┌────────┐
 │ Початок │──►│ Введення  │──►│  Обчислення  │──►│ Виведення │──►│ Кінець │
 └─────────┘   │ вихідних  │   │ за формулами │   │ результату│   └────────┘
               │  даних    │   └──────────────┘   └───────────┘
               └───────────┘
```

Ця схема «введення — обробка — виведення» лежить в основі будь-якої обчислювальної
програми: більшість задач, у яких треба щось порахувати за готовою формулою,
розв'язуються саме лінійним алгоритмом.

Ознака того, що алгоритм **не** лінійний: у формулюванні є слова «якщо», «залежно від»,
«для кожного», «поки». Такі задачі — тема наступних робіт.

Перш ніж писати код, лінійний алгоритм корисно записати словами:

```
1. Зчитати відстань маршруту, км.
2. Зчитати витрату пального, л на 100 км.
3. Зчитати ціну літра, грн.
4. Обчислити обсяг пального: відстань / 100 * витрата.
5. Обчислити вартість: обсяг * ціна.
6. Вивести обсяг і вартість.
```

Такий запис називають **псевдокодом**. Він не залежить від мови програмування
й дає змогу знайти помилку в задумі ще до написання коду.

### 2. Арифметичні операції

| Операція | Знак | Приклад | Результат |
|---|---|---|---|
| Додавання | `+` | `7 + 3` | 10 |
| Віднімання | `-` | `7 - 3` | 4 |
| Множення | `*` | `7 * 3` | 21 |
| Ділення | `/` | `7.0 / 3.0` | 2,333… |
| Остача від ділення | `%` | `7 % 3` | 1 |
| Унарний мінус | `-` | `-7` | −7 |

Операція **`%`** — **остача від ділення**: те, що залишається після ділення націло.

### 3. Цілочисельне ділення — головна пастка

Знак `/` означає дві різні операції залежно від типів операндів.

Якщо **обидва** операнди цілі, виконується **цілочисельне ділення**: дробова частина
відкидається, результат — ціле число. Якщо хоча б один операнд дробовий,
виконується звичайне ділення.

```csharp
int sum = 17;
int count = 4;

Console.WriteLine($"17 / 4   = {sum / count}");            // обидва int: ціле ділення
Console.WriteLine($"17 % 4   = {sum % count}");            // остача
Console.WriteLine($"17.0 / 4 = {17.0 / count}");           // один операнд дробовий

double wrongAverage = sum / count;          // спершу 17/4 = 4 (ціле!), потім 4 → 4,0
double rightAverage = (double)sum / count;  // одразу дробове ділення
Console.WriteLine($"Неправильно: {wrongAverage}, правильно: {rightAverage}");
```

Вивід:

```
17 / 4   = 4
17 % 4   = 1
17.0 / 4 = 4,25
Неправильно: 4, правильно: 4,25
```

Тип змінної ліворуч від знака рівності **не впливає** на те, як обчислюється вираз
праворуч. Перетворення треба робити до ділення, а не після.

Практичне застосування пари `/` і `%` — розкладання числа на частини:

```csharp
int totalSeconds = 9_305;
int hours = totalSeconds / 3600;              // скільки повних годин
int minutes = totalSeconds % 3600 / 60;       // з остачі — скільки повних хвилин
int seconds = totalSeconds % 60;              // остача від хвилин
Console.WriteLine($"{totalSeconds} с = {hours} год {minutes} хв {seconds} с");

int amount = 1487;                            // сума в копійках
Console.WriteLine($"{amount} коп = {amount / 100} грн {amount % 100} коп");

int number = 4_729;
Console.WriteLine($"Остання цифра: {number % 10}, число без неї: {number / 10}");
```

Вивід:

```
9305 с = 2 год 35 хв 5 с
1487 коп = 14 грн 87 коп
Остання цифра: 9, число без неї: 472
```

Ділення цілого числа на нуль викликає помилку виконання `DivideByZeroException`.
Ділення дробового на нуль помилки не дає: результат — `Infinity` або `NaN`.

### 4. Пріоритет операцій

**Пріоритет** визначає, які операції виконуються першими, коли дужок немає.

| Ранг | Операції | Напрям обчислення |
|---|---|---|
| 1 | `( )` — дужки | зсередини назовні |
| 2 | `+x`, `-x`, `(тип)x` — унарні | справа наліво |
| 3 | `*`, `/`, `%` | зліва направо |
| 4 | `+`, `-` | зліва направо |
| 5 | `=`, `+=`, `-=`, `*=`, `/=`, `%=` | справа наліво |

```csharp
Console.WriteLine($"{2 + 3 * 4} | {(2 + 3) * 4} | {10 - 4 - 3} | " +
                  $"{20 / 4 * 5} | {20 / (4 * 5)} | {17 % 5 * 2}");
```

Вивід:

```
14 | 20 | 3 | 25 | 1 | 4
```

Зверніть увагу на `20 / 4 * 5` і `20 / (4 * 5)`: `*` і `/` мають однаковий пріоритет,
тому обчислюються **зліва направо**, і результати відрізняються у 25 разів.

Практична порада: у формулі з трьома і більше операціями ставте дужки, навіть якщо
пріоритет дозволяє без них — вони позбавляють читача потреби пригадувати таблицю.

Записуючи математичну формулу в коді, пам'ятайте, що дробова риска — це теж дужки:

```
   a + b                                 (a + b) / (2 * c)
  ───────   у коді записується як
   2 · c
```

### 5. Складені оператори присвоєння

Операція `=` — це **присвоєння**: обчислити вираз праворуч і покласти результат
у змінну ліворуч. Коли змінна бере участь і в правій частині, запис скорочують.

| Складений запис | Повний запис |
|---|---|
| `x += 5` | `x = x + 5` |
| `x -= 5` | `x = x - 5` |
| `x *= 2` | `x = x * 2` |
| `x /= 4` | `x = x / 4` |
| `x %= 3` | `x = x % 3` |
| `x++` | `x = x + 1` |
| `x--` | `x = x - 1` |

```csharp
decimal orderTotal = 0m;
orderTotal += 149.50m;      // додали піцу
orderTotal += 45m;          // додали напій
orderTotal += 89.90m;       // додали десерт
Console.WriteLine($"Сума позицій:    {orderTotal:F2} грн");

orderTotal *= 1.10m;        // додали 10 % сервісного збору
orderTotal -= 30m;          // застосували промокод
Console.WriteLine($"Разом до сплати: {orderTotal:F2} грн");

int counter = 10;
counter += 2.9;             // компілюється: результат приводиться до int
Console.WriteLine($"10 += 2,9 у типі int: {counter}");
```

Вивід:

```
Сума позицій:    284,40 грн
Разом до сплати: 282,84 грн
10 += 2,9 у типі int: 12
```

Останній рядок показує, що складений оператор виконує ще й **неявне приведення типу**.

Це зручно, але небезпечно: 12,9 мовчки перетворилося на 12. Записавши `counter = counter + 2.9`,
ви отримали б помилку компіляції CS0266 — і саме вона тут корисніша.

### 6. Клас `Math`

**`Math`** — клас стандартної бібліотеки з математичними методами й сталими.
Усі методи статичні, тобто викликаються через ім'я класу без створення об'єкта.

| Член класу | Призначення | Приклад | Результат |
|---|---|---|---|
| `Math.PI` | число π | `Math.PI` | 3,14159265358979 |
| `Math.E` | основа натурального логарифма | `Math.E` | 2,71828182845905 |
| `Math.Sqrt(x)` | квадратний корінь | `Math.Sqrt(81)` | 9 |
| `Math.Pow(x, y)` | піднесення до степеня | `Math.Pow(2, 10)` | 1024 |
| `Math.Abs(x)` | модуль числа | `Math.Abs(-17.5)` | 17,5 |
| `Math.Round(x)` | округлення до цілого | `Math.Round(2.6)` | 3 |
| `Math.Round(x, n)` | округлення до n знаків | `Math.Round(3.14159, 2)` | 3,14 |
| `Math.Floor(x)` | найбільше ціле, не більше за x | `Math.Floor(7.9)` | 7 |
| `Math.Ceiling(x)` | найменше ціле, не менше за x | `Math.Ceiling(7.1)` | 8 |
| `Math.Truncate(x)` | відкидання дробової частини | `Math.Truncate(-7.9)` | −7 |
| `Math.Max(a, b)` | більше з двох | `Math.Max(3, 9)` | 9 |
| `Math.Min(a, b)` | менше з двох | `Math.Min(3, 9)` | 3 |
| `Math.Sign(x)` | знак числа: −1, 0 або 1 | `Math.Sign(-4)` | −1 |
| `Math.Sin(x)`, `Math.Cos(x)` | синус, косинус (аргумент у радіанах) | `Math.Sin(Math.PI / 2)` | 1 |
| `Math.Log(x)`, `Math.Log10(x)` | логарифми | `Math.Log10(1000)` | 3 |

```csharp
double radius = 4.7;
double area = Math.PI * radius * radius;
double circumference = 2 * Math.PI * radius;
double diagonal = Math.Sqrt(Math.Pow(3, 2) + Math.Pow(4, 2));

Console.WriteLine($"Площа кола: {area:F3} см², довжина кола: {circumference:F3} см");
Console.WriteLine($"Гіпотенуза 3-4: {diagonal}, модуль -17,5: {Math.Abs(-17.5)}");
```

Вивід:

```
Площа кола: 69,398 см², довжина кола: 29,531 см
Гіпотенуза 3-4: 5, модуль -17,5: 17,5
```

Зверніть увагу: `Math.Pow` працює з типом `double` і повертає `double`. Для квадрата
це надлишково — простіше й точніше написати `radius * radius`; `Math.Pow` виправданий
тоді, коли показник степеня не дорівнює двом або сам є змінною.

Три способи «зробити з дробового ціле» дають різні результати, і різниця
особливо помітна на від'ємних числах:

```csharp
double a = 7.6;
double b = -7.6;
Console.WriteLine($"{"Значення",10}{"Floor",10}{"Ceiling",10}{"Round",10}{"Truncate",10}");
Console.WriteLine($"{a,10}{Math.Floor(a),10}{Math.Ceiling(a),10}{Math.Round(a),10}{Math.Truncate(a),10}");
Console.WriteLine($"{b,10}{Math.Floor(b),10}{Math.Ceiling(b),10}{Math.Round(b),10}{Math.Truncate(b),10}");
```

Вивід:

```
  Значення     Floor   Ceiling     Round  Truncate
       7,6         7         8         8         7
      -7,6        -8        -7        -8        -7
```

Окремо про `Math.Round`: за замовчуванням половина округлюється **до парного**
(банківське округлення). Щоб отримати звичне шкільне округлення, додають третій аргумент:

```csharp
Console.WriteLine($"Round(2.5) = {Math.Round(2.5)}, Round(3.5) = {Math.Round(3.5)}");
Console.WriteLine($"AwayFromZero: {Math.Round(2.5, MidpointRounding.AwayFromZero)}");
Console.WriteLine($"Round(2.567, 2) = {Math.Round(2.567, 2)}");

int peopleCount = 23;                                   // округлення вгору:
double exactBuses = (double)peopleCount / 8;            // скільки автобусів по 8 місць
Console.WriteLine($"Точно: {exactBuses:F3}, замовити: {Math.Ceiling(exactBuses)}");
```

Вивід:

```
Round(2.5) = 2, Round(3.5) = 4
AwayFromZero: 3
Round(2.567, 2) = 2,57
Точно: 2,875, замовити: 3
```

### 7. Безпечне зчитування чисел

Дані з клавіатури приходять рядком, тому кожне число потребує перетворення.
Спосіб, яким користуємося в цьому курсі, — `TryParse`: він не завершує програму
аварійно, а повертає ознаку успіху.

```csharp
Console.Write("Довжина ділянки, м: ");
bool okLength = double.TryParse(Console.ReadLine(), out double length);

Console.Write("Ширина ділянки, м: ");
bool okWidth = double.TryParse(Console.ReadLine(), out double width);

Console.WriteLine($"Введення розпізнано: довжина — {okLength}, ширина — {okWidth}");
Console.WriteLine($"Площа: {length * width:F2} м²");
```

Вивід (введено 25 і 18,5):

```
Довжина ділянки, м: 25
Ширина ділянки, м: 18,5
Введення розпізнано: довжина — True, ширина — True
Площа: 462,50 м²
```

Вивід (у ширині введено «багато»):

```
Довжина ділянки, м: 25
Ширина ділянки, м: багато
Введення розпізнано: довжина — True, ширина — False
Площа: 0,00 м²
```

Програма не «впала» — вона порахувала з нулем і чесно показала, що введення не розпізнано.
Реагувати на це (просити ввести повторно, показувати попередження) навчимося
в роботі про розгалуження; поки завдання лінійне, і достатньо повідомити результат
перевірки.

Виклик `Console.ReadLine()` можна писати прямо всередині `TryParse` — окрема змінна
для рядка потрібна лише тоді, коли той самий текст використовується двічі.

Щоб уводити дробові числа і з комою, і з крапкою незалежно від налаштувань системи,
скористайтеся розширеною формою:

```csharp
using System.Globalization;

double.TryParse(Console.ReadLine(), NumberStyles.Any,
                CultureInfo.InvariantCulture, out double value);
```

У цій формі дробовим роздільником завжди є крапка.

### 8. Форматований вивід результату

Зведення форматів, потрібних у цій роботі:

| Запис | Дія | Приклад результату |
|---|---|---|
| `{x:F2}` | два знаки після коми | `462,50` |
| `{x:F0}` | без дробової частини | `463` |
| `{x:N0}` | розділені розряди | `1 250 000` |
| `{x:N2}` | розряди й два знаки | `1 250 000,45` |
| `{x:C}` | грошовий формат | `284,40 ₴` |
| `{x:P1}` | відсотки | `12,5 %` |
| `{x,10}` | поле завширшки 10, праворуч | `␣␣␣␣␣462,50` |
| `{x,-10}` | поле завширшки 10, ліворуч | `462,50␣␣␣␣␣` |
| `{x,10:F2}` | ширина й формат разом | `␣␣␣␣462,50` |

Акуратний бланк результату:

```csharp
double distanceKm = 348.6;
double fuelUsed = 24.75;
decimal cost = 1287.45m;

Console.WriteLine("┌────────────────────────┬──────────────┐");
Console.WriteLine($"│ {"Показник",-22} │ {"Значення",12} │");
Console.WriteLine("├────────────────────────┼──────────────┤");
Console.WriteLine($"│ {"Відстань, км",-22} │ {distanceKm,12:F1} │");
Console.WriteLine($"│ {"Пальне, л",-22} │ {fuelUsed,12:F2} │");
Console.WriteLine($"│ {"Вартість",-22} │ {cost,12:C} │");
Console.WriteLine("└────────────────────────┴──────────────┘");
```

Вивід:

```
┌────────────────────────┬──────────────┐
│ Показник               │     Значення │
├────────────────────────┼──────────────┤
│ Відстань, км           │        348,6 │
│ Пальне, л              │        24,75 │
│ Вартість               │   1 287,45 ₴ │
└────────────────────────┴──────────────┘
```

## Приклад виконання

### Умова

Автомобіль здійснює поїздку між двома містами. Відомі: відстань у кілометрах,
паспортна витрата пального в літрах на 100 км, ціна літра пального в гривнях,
середня швидкість у км/год і кількість пасажирів, між якими вартість ділиться порівну.

Скласти програму, яка обчислює: обсяг витраченого пального, повну вартість поїздки,
вартість на одного пасажира, час у дорозі в годинах і хвилинах, а також вартість
одного кілометра. Усі вихідні дані вводяться з клавіатури.

### Аналіз

Задача суто обчислювальна: жодна дія не залежить від значень даних, повторень немає.
Отже, алгоритм лінійний.

Псевдокод:

```
1. Зчитати відстань (км), витрату (л/100 км), ціну літра (грн),
   швидкість (км/год), кількість пасажирів.
2. Пальне = відстань / 100 * витрата.
3. Вартість = пальне * ціна.
4. На пасажира = вартість / кількість пасажирів.
5. Час у годинах = відстань / швидкість.
6. Повні години = ціла частина часу; хвилини = дробова частина * 60.
7. Вартість кілометра = вартість / відстань.
8. Вивести всі результати в таблиці.
```

Підбір типів:

| Величина | Тип | Чому |
|---|---|---|
| Відстань, витрата, швидкість, час | `double` | фізичні величини, потрібен дріб |
| Ціна літра, вартість | `decimal` | гроші |
| Кількість пасажирів | `int` | ціле |

Два місця потребують особливої уваги.

По-перше, обсяг пального — `double`, а ціна — `decimal`. Перемножити їх напряму не можна:
компілятор видасть помилку CS0019, бо неявного перетворення між `double` і `decimal`
немає в жодному напрямку. Потрібне явне приведення `(decimal)fuelUsed`.

По-друге, розділення часу на години й хвилини. Час у годинах — дробове число,
наприклад 4,35 год. Повні години беремо через `Math.Floor`, а хвилини — це дробовий
залишок, помножений на 60. Використати `%` тут не можна: остача визначена
для цілих чисел, а ділити треба дробове.

### Код

```csharp
using System;

Console.OutputEncoding = System.Text.Encoding.UTF8;

const int MinutesPerHour = 60;
const double KmPerConsumptionUnit = 100.0;   // витрата задається на 100 км

Console.WriteLine("=== РОЗРАХУНОК ВАРТОСТІ ПОЇЗДКИ ===\n");

// --- Введення вихідних даних ---

Console.Write("Відстань, км:                 ");
bool okDistance = double.TryParse(Console.ReadLine(), out double distanceKm);

Console.Write("Витрата пального, л/100 км:   ");
bool okRate = double.TryParse(Console.ReadLine(), out double consumptionRate);

Console.Write("Ціна літра, грн:              ");
bool okPrice = decimal.TryParse(Console.ReadLine(), out decimal pricePerLiter);

Console.Write("Середня швидкість, км/год:    ");
bool okSpeed = double.TryParse(Console.ReadLine(), out double averageSpeed);

Console.Write("Кількість пасажирів:          ");
bool okPeople = int.TryParse(Console.ReadLine(), out int passengerCount);

Console.WriteLine();
Console.WriteLine($"Розпізнано: відстань — {okDistance}, витрата — {okRate}, " +
                  $"ціна — {okPrice}, швидкість — {okSpeed}, пасажири — {okPeople}");
Console.WriteLine();

// --- Обчислення ---

// Пальне: скільки разів по 100 км проїхали, помножено на витрату
double fuelUsed = distanceKm / KmPerConsumptionUnit * consumptionRate;

// Вартість: обсяг пального перетворюємо в decimal, бо гроші рахуємо в decimal
decimal totalCost = (decimal)fuelUsed * pricePerLiter;

// Частка одного пасажира: int у знаменнику неявно розширюється до decimal
decimal costPerPassenger = totalCost / passengerCount;

// Вартість кілометра
decimal costPerKm = totalCost / (decimal)distanceKm;

// Час у дорозі
double travelTimeHours = distanceKm / averageSpeed;
double fullHours = Math.Floor(travelTimeHours);                       // цілі години
double leftoverMinutes = Math.Round((travelTimeHours - fullHours) * MinutesPerHour);

// Скільки заправок по 40 л знадобиться (округлення вгору)
const double TankVolume = 40.0;
double refuelCount = Math.Ceiling(fuelUsed / TankVolume);

// --- Виведення результатів ---

Console.WriteLine("┌──────────────────────────────┬─────────────────┐");
Console.WriteLine($"│ {"Показник",-28} │ {"Значення",15} │");
Console.WriteLine("├──────────────────────────────┼─────────────────┤");
Console.WriteLine($"│ {"Відстань, км",-28} │ {distanceKm,15:N1} │");
Console.WriteLine($"│ {"Витрачено пального, л",-28} │ {fuelUsed,15:F2} │");
Console.WriteLine($"│ {"Ціна літра",-28} │ {pricePerLiter,15:C} │");
Console.WriteLine($"│ {"Повна вартість поїздки",-28} │ {totalCost,15:C} │");
Console.WriteLine($"│ {"На одного пасажира",-28} │ {costPerPassenger,15:C} │");
Console.WriteLine($"│ {"Вартість 1 км",-28} │ {costPerKm,15:F3} │");
Console.WriteLine($"│ {"Час у дорозі, год",-28} │ {travelTimeHours,15:F3} │");
Console.WriteLine($"│ {"Заправок по 40 л",-28} │ {refuelCount,15:F0} │");
Console.WriteLine("└──────────────────────────────┴─────────────────┘");

Console.WriteLine();
Console.Write("Час у дорозі: ");
Console.Write($"{fullHours:F0} год ");
Console.WriteLine($"{leftoverMinutes:F0} хв");
Console.WriteLine($"Середня витрата на пасажира: {fuelUsed / passengerCount:F2} л");
```

### Що варто помітити

Рядок «Повна вартість поїздки» зсунув праву межу таблиці на один символ: грошовий
формат `C` додав нерозривний пробіл у розряді тисяч, і рядок став довшим за очікуваний.
Це типова проблема табличного виводу — ширину поля треба брати із запасом
або відмовитися від `C` на користь `N2` з окремим підписом «грн».

Другий момент: `Math.Ceiling(24.75 / 40)` дало 1, хоча бак на 40 літрів довелося б
заповнити не повністю. Округлення вгору тут означає «скільки разів доведеться під'їхати
до колонки», і одного разу справді досить.

Третій момент: перетворення `(decimal)fuelUsed` — не формальність. Якщо його прибрати,
програма взагалі не скомпілюється з помилкою CS0019 «Operator `*` cannot be applied
to operands of type `double` and `decimal`». Компілятор навмисно не змішує ці типи:
одне число двійкове, інше десяткове, і мовчазне перетворення давало б непередбачувану
похибку в грошах.

6. Розрахункові формули у звичайному математичному записі та їхній запис мовою C#.
7. Текст програми з коментарями.
8. Вивід програми для трьох наборів даних: типового, граничного й хибного.
9. Перевірка одного з результатів ручним розрахунком: обчисліть його на калькуляторі
   й порівняйте з виводом програми.
10. Відповіді на контрольні питання.
11. Висновок: 3–5 речень про те, які помилки в лінійних обчисленнях трапляються
    найчастіше і як їх виявити.
