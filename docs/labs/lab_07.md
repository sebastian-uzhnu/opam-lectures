# Лабораторна робота №7

## Тема
Одновимірні масиви: створення та типові алгоритми обробки

## Мета
Навчитися оголошувати, ініціалізувати та заповнювати одновимірні масиви мовою C#
і звертатися до їхніх елементів за індексом. Закріпити вміння поєднувати цикли
з індексованим доступом до даних. Набути навичок реалізації типових алгоритмів
обробки масиву: обчислення суми й середнього, пошуку найбільшого та найменшого
елементів, підрахунку елементів за умовою, перестановки, вставляння та вилучення.
Навчитися користуватися стандартними можливостями класу `Array`.

## Тривалість
2 академічні години.

## Обладнання та програмне забезпечення
Персональний комп'ютер, .NET 8 SDK, будь-яке середовище розробки або текстовий
редактор і термінал, система контролю версій Git.

## Теоретичні відомості

### 1. Навіщо потрібен масив

До цієї роботи кожна величина зберігалася в окремій змінній. Але уявіть завдання:
кав'ярня хоче знати, скільки чашок кави продано за кожен із 30 днів місяця, яким
був найкращий день і скільки днів торгували гірше за середній рівень. Тридцять
окремих змінних `day1`, `day2`, … `day30` — це тридцять рядків введення, тридцять
порівнянь і жодної можливості написати цикл: у циклі не можна «скласти» ім'я
змінної з номера.

**Масив** — це іменована сукупність елементів одного типу, які розташовані
в пам'яті поспіль і доступні за цілим номером — **індексом**. До елемента можна
звернутися за номером, який обчислюється під час роботи програми. Саме тому масив
і цикл — нерозлучна пара.

### 2. Оголошення та ініціалізація

Тип масиву записується як тип елемента з квадратними дужками: `int[]`, `double[]`,
`string[]`, `bool[]`. Сам масив завжди створюється оператором `new` або через
список початкових значень.

```csharp
// 1. Створення порожнього масиву заданого розміру.
// Усі елементи одразу дістають значення за замовчуванням: для int це 0.
int[] sales = new int[10];

// 2. Створення з переліком значень — розмір визначається автоматично.
int[] temperatures = new int[] { -3, 0, 5, 12, 18 };

// 3. Скорочений запис того самого.
int[] marks = { 5, 4, 5, 3, 4 };

// 4. Колекційний вираз (C# 12) — сучасна й найкоротша форма.
int[] prices = [25, 30, 45, 45, 60];

// Для var форма з new обов'язкова: компілятор має знати тип.
var weights = new double[] { 1.5, 2.25, 0.75 };
```

Для `bool` значення за замовчуванням — `false`, для `string` — `null`
(порожнє посилання, а не порожній рядок).

| Запис | Коли застосовують |
|---|---|
| `new int[n]` | розмір відомий, значення будуть введені або обчислені пізніше |
| `new int[] { … }` | значення відомі, потрібен явний тип (наприклад, при `var`) |
| `{ … }` | коротка форма, лише в рядку оголошення змінної |
| `[ … ]` | колекційний вираз C# 12, читається найкраще |

Розмір масиву задається один раз під час створення і **не змінюється**: «дописати»
шостий елемент до масиву з п'яти неможливо — можна лише створити новий масив
більшого розміру й перенести туди дані.

### 3. Довжина масиву та індексація

Кількість елементів дає властивість `Length`. Індекси завжди починаються з нуля,
тому останній елемент має індекс `Length - 1`.

```csharp
int[] prices = [25, 30, 45, 45, 60];

Console.WriteLine(prices.Length);        // 5
Console.WriteLine(prices[0]);            // 25 — перший
Console.WriteLine(prices[prices.Length - 1]); // 60 — останній
Console.WriteLine(prices[^1]);           // 60 — те саме, індекс з кінця
prices[2] = 50;                          // зміна елемента
```

Вивід:

```
5
25
60
60
```

Схема відповідності індексів і значень:

```
 індекс:     0     1     2     3     4
           +-----+-----+-----+-----+-----+
 prices    |  25 |  30 |  45 |  45 |  60 |
           +-----+-----+-----+-----+-----+
 з кінця:    ^5    ^4    ^3    ^2    ^1
 Length = 5, останній індекс = Length - 1 = 4
```

Якщо індекс виходить за межі `0 … Length - 1`, програма аварійно завершується
з винятком **`IndexOutOfRangeException`** — «індекс поза межами масиву».

```csharp
int[] prices = [25, 30, 45, 45, 60];
Console.WriteLine(prices[5]);   // помилка: індексу 5 не існує
```

Вивід:

```
Unhandled exception. System.IndexOutOfRangeException: Index was outside the bounds of the array.
```

Це найпоширеніша помилка початківця. Дві типові її причини: цикл записаний
як `for (int i = 1; i <= a.Length; i++)` замість `for (int i = 0; i < a.Length; i++)`;
або всередині циклу звертаються до `a[i + 1]`, не зменшивши межу до `a.Length - 1`.

### 4. Перебір масиву: `for` і `foreach`

Класичний перебір — циклом `for`, де змінна циклу є індексом:

```csharp
int[] sales = [12, 18, 7, 25, 19];

for (int i = 0; i < sales.Length; i++)
{
    Console.WriteLine($"День {i + 1}: {sales[i]} чашок");
}
```

Якщо індекс сам по собі не потрібен, зручніший цикл `foreach`, який по черзі
кладе кожен елемент у робочу змінну:

```csharp
int total = 0;
foreach (int cups in sales)
{
    total += cups;
}
Console.WriteLine($"Усього: {total} чашок");   // Усього: 81 чашок
```

| | `for` | `foreach` |
|---|---|---|
| Доступ до індексу | є | немає |
| Зміна елементів масиву | дозволена | заборонена (змінна циклу — копія) |
| Можна йти з кінця чи через один | так | ні, тільки по порядку |

Важливо: у `foreach` присвоєння змінній циклу не змінює масив — такий запис
навіть не скомпілюється. Щоб змінювати елементи, потрібен `for` і запис `a[i] = …`.

### 5. Заповнення масиву

**З клавіатури.** Введення завжди перевіряємо через `int.TryParse`, як у попередніх
роботах, інакше один помилковий символ обвалить програму.

```csharp
int[] sales = new int[5];
for (int i = 0; i < sales.Length; i++)
{
    Console.Write($"Продажі за день {i + 1}: ");
    while (!int.TryParse(Console.ReadLine(), out sales[i]) || sales[i] < 0)
    {
        Console.Write("Потрібне ціле невід'ємне число. Повторіть: ");
    }
}
```

**Випадковими числами.** Для тестування вручну вводити 50 чисел безглуздо.
Готовий генератор випадкових чисел дає властивість `Random.Shared` — один
спільний на всю програму об'єкт, який не треба створювати самому.

```csharp
int[] temps = new int[7];
for (int i = 0; i < temps.Length; i++)
{
    temps[i] = Random.Shared.Next(-10, 16); // від -10 до 15 включно
}
Console.WriteLine(string.Join(", ", temps)); // 3, -7, 12, 0, 8, -2, 15 (щоразу інше)
```

Зверніть увагу на межі: `Next(a, b)` повертає число від `a` включно до `b`
**не включно**. Тому для діапазону від -10 до 15 пишемо `Next(-10, 16)`.
Для дійсних чисел є `Random.Shared.NextDouble()` — значення від 0 до 1,
яке масштабують множенням: `Random.Shared.NextDouble() * 100`.

**Виведення масиву одним рядком** зручно робити через `string.Join`: перший
аргумент — роздільник, другий — масив.

### 6. Типові алгоритми обробки

Наступні алгоритми — робочий мінімум, який треба вміти писати не задумуючись.
Усюди далі масив називається `a`.

**Сума й середнє арифметичне.** Середнє — дійсне число, тому одну з величин
треба привести до `double`, інакше отримаєте цілочислене ділення.

```csharp
int[] a = [12, 18, 7, 25, 19];

int sum = 0;
foreach (int x in a) sum += x;

double average = (double)sum / a.Length;
Console.WriteLine($"Сума = {sum}, середнє = {average:F2}"); // Сума = 81, середнє = 16,20
```

**Максимум, мінімум та їхні індекси.** Початкове значення шуканого — **перший
елемент масиву**, а не нуль. Якщо взяти нуль, алгоритм зламається на масиві
з самих від'ємних чисел.

```csharp
int max = a[0], maxIndex = 0;
int min = a[0], minIndex = 0;

for (int i = 1; i < a.Length; i++)
{
    if (a[i] > max) { max = a[i]; maxIndex = i; }
    if (a[i] < min) { min = a[i]; minIndex = i; }
}

Console.WriteLine($"Максимум {max} на позиції {maxIndex}");
Console.WriteLine($"Мінімум {min} на позиції {minIndex}");
```

Вивід:

```
Максимум 25 на позиції 3
Мінімум 7 на позиції 2
```

Якщо однакових максимумів кілька, умова `a[i] > max` залишить індекс **першого**
з них, а `a[i] >= max` — індекс останнього.

**Підрахунок і сума за умовою.** Лічильник і накопичувач працюють разом:

```csharp
int aboveAverage = 0;
int evenSum = 0;

foreach (int x in a)
{
    if (x > average) aboveAverage++;
    if (x % 2 == 0) evenSum += x;
}

Console.WriteLine($"Понад середнє: {aboveAverage}");
Console.WriteLine($"Сума парних: {evenSum}");
```

Вивід:

```
Понад середнє: 2
Сума парних: 30
```

**Реверс — перестановка задом наперед.** Іти треба лише до середини масиву:
якщо пройти весь масив, кожна пара переставиться двічі й масив повернеться
у вихідний стан.

```csharp
for (int i = 0; i < a.Length / 2; i++)
{
    int temp = a[i];
    a[i] = a[a.Length - 1 - i];
    a[a.Length - 1 - i] = temp;
}
```

```
   було:  12  18   7  25  19
           |___________|         міняємо 0 <-> 4
               |____|            міняємо 1 <-> 3
                 5                індекс 2 лишається на місці
   стало:  19  25   7  18  12
```

**Циклічний зсув уліво.** Перший елемент запам'ятовуємо, решту зсуваємо,
збережене значення кладемо в кінець.

```csharp
int first = a[0];
for (int i = 0; i < a.Length - 1; i++)
{
    a[i] = a[i + 1];
}
a[a.Length - 1] = first;
```

```
   було:  19  25   7  18  12
           <-- усі зсуваються вліво, 19 переїжджає в кінець
   стало:  25   7  18  12  19
```

Для зсуву вправо цикл іде **з кінця**: `for (int i = a.Length - 1; i > 0; i--) a[i] = a[i - 1];`
Якщо переплутати напрям обходу, масив заповниться копіями одного елемента.

**Вставляння й вилучення.** Розмір масиву незмінний, тому обидві дії — це
створення нового масиву і копіювання з пропуском або зі зсувом.

```csharp
int[] a = [10, 20, 30, 40];
int pos = 2, value = 99;

// вставляння значення value на позицію pos
int[] bigger = new int[a.Length + 1];
for (int i = 0; i < pos; i++) bigger[i] = a[i];
bigger[pos] = value;
for (int i = pos; i < a.Length; i++) bigger[i + 1] = a[i];

Console.WriteLine(string.Join(", ", bigger));

// вилучення елемента з позиції pos
int[] smaller = new int[a.Length - 1];
for (int i = 0, j = 0; i < a.Length; i++)
{
    if (i == pos) continue;   // пропускаємо непотрібний
    smaller[j] = a[i];
    j++;
}

Console.WriteLine(string.Join(", ", smaller));
```

Вивід:

```
10, 20, 99, 30, 40
10, 20, 40
```

Зверніть увагу на дві незалежні змінні: `i` біжить вихідним масивом, `j` — новим,
тому `j` збільшується не на кожній ітерації, а тільки після запису.

### 7. Готові можливості класу `Array`

Клас `Array` містить статичні методи, які роблять типові дії за вас.
Писати власні реалізації сортування ви навчитеся в лабораторній роботі №9;
поки що користуйтеся готовими там, де завдання цього не забороняє.

| Виклик | Що робить | Результат |
|---|---|---|
| `Array.Sort(a)` | впорядковує масив за зростанням | змінює `a` |
| `Array.Sort(keys, items)` | сортує `keys`, переставляючи `items` синхронно | змінює обидва |
| `Array.Reverse(a)` | перевертає масив | змінює `a` |
| `Array.IndexOf(a, x)` | індекс першого входження `x` | індекс або `-1` |
| `Array.LastIndexOf(a, x)` | індекс останнього входження | індекс або `-1` |
| `Array.Fill(a, x)` | заповнює весь масив значенням `x` | змінює `a` |
| `Array.Copy(src, dst, n)` | копіює `n` елементів | заповнює `dst` |

```csharp
int[] a = [40, 10, 30, 20];

int pos = Array.IndexOf(a, 30);
Console.WriteLine($"30 стоїть на позиції {pos}");

Array.Sort(a);
Console.WriteLine(string.Join(", ", a));

Array.Reverse(a);
Console.WriteLine(string.Join(", ", a));

Console.WriteLine(Array.IndexOf(a, 77));
```

Вивід:

```
30 стоїть на позиції 2
10, 20, 30, 40
40, 30, 20, 10
-1
```

Запам'ятайте: `Array.Sort` і `Array.Reverse` **змінюють сам масив**, а не повертають
новий. Якщо вихідний порядок ще знадобиться, спершу зробіть копію `(int[])a.Clone()`.

### 8. Масив у пам'яті

Змінна типу масиву — не сам масив, а **посилання** на нього. Сама змінна
лежить у **стеку** (ділянка пам'яті для локальних змінних методу), а елементи —
у **купі** (ділянка для об'єктів, розмір яких визначається під час роботи програми).

```
          СТЕК                                    КУПА
  +----------------------+            +----+----+----+----+----+
  | a  | посилання ------+----------> | 25 | 30 | 45 | 45 | 60 |
  +----------------------+            +----+----+----+----+----+
  | b  | посилання ------+---+          0    1    2    3    4
  +----------------------+   |          (+ службовий заголовок,
  | n  | 5                |   |           де зберігається Length)
  +----------------------+   |
                             +------> той самий блок, що й у a
```

Із цього випливає важливий наслідок. Присвоєння `b = a` копіює **посилання**,
а не елементи: після нього `a` і `b` показують на один і той самий блок пам'яті,
і зміна через `b` видно через `a`.

```csharp
int[] a = [1, 2, 3];
int[] b = a;            // копіюється посилання
b[0] = 100;
Console.WriteLine(a[0]); // 100 — змінився «чужий» масив

int[] c = (int[])a.Clone(); // повноцінна копія елементів
c[1] = 555;
Console.WriteLine(a[1]);    // 2 — вихідний масив не зачеплено
```

Вивід:

```
100
2
```

### 9. Типові помилки

| Помилка | Прояв | Як уникнути |
|---|---|---|
| `i <= a.Length` у циклі | `IndexOutOfRangeException` | межа завжди `i < a.Length` |
| `a[i + 1]` без зменшення межі | виняток на останній ітерації | цикл до `a.Length - 1` |
| Максимум шукається від нуля | неправильний результат для від'ємних | починати з `a[0]` |
| `sum / a.Length` для середнього | відкидається дробова частина | `(double)sum / a.Length` |
| Реверс через весь масив | масив не змінюється | цикл до `a.Length / 2` |
| `b = a` замість копії | «сам собою» змінився інший масив | `(int[])a.Clone()` |

## Приклад виконання

**Умова.** Кав'ярня фіксує кількість проданих чашок кави за кожен день робочого
тижня (7 днів). Заповнити масив випадковими числами в діапазоні від 40 до 120,
вивести його, обчислити загальну кількість продажів і середньоденний показник,
знайти найкращий і найгірший день (день і значення), порахувати, скільки днів
торгували краще за середній рівень, а потім вивести дані в оберненому порядку
та переставити найкращий день на перше місце.

**Аналіз.** Задача розкладається на незалежні кроки, кожен з яких — окремий
прохід масивом:

1. Заповнення: цикл `for` і `Random.Shared.Next(40, 121)`.
2. Вивід: `string.Join`.
3. Сума: накопичувач, середнє — ділення з приведенням до `double`.
4. Максимум і мінімум з індексами: один прохід, початкові значення — `a[0]`.
5. Лічильник днів, де значення більше за середнє.
6. Реверс копії масиву (вихідний масив ще потрібен) — цикл до середини.
7. Обмін місцями елементів `0` і `maxIndex` через тимчасову змінну.

Найкращий день у звіті нумеруємо з одиниці (`maxIndex + 1`), бо людина рахує
дні з першого, а масив — з нульового.

**Код.**

```csharp
// Лабораторна робота №7. Приклад виконання.
// Аналіз продажів кави за тиждень.

const int Days = 7;
string[] dayNames = ["Пн", "Вт", "Ср", "Чт", "Пт", "Сб", "Нд"];

// --- Крок 1. Заповнення випадковими числами ---
int[] cups = new int[Days];
for (int i = 0; i < cups.Length; i++)
{
    cups[i] = Random.Shared.Next(40, 121); // 40..120 включно
}

// --- Крок 2. Вивід вихідних даних ---
Console.WriteLine("Продажі за тиждень (чашок):");
for (int i = 0; i < cups.Length; i++)
{
    Console.WriteLine($"  {dayNames[i]}: {cups[i],4}");
}

// --- Крок 3. Сума й середнє ---
int total = 0;
foreach (int c in cups)
{
    total += c;
}
double average = (double)total / cups.Length;

Console.WriteLine($"Усього за тиждень: {total} чашок");
Console.WriteLine($"Середньоденний показник: {average:F2}");

// --- Крок 4. Найкращий і найгірший день ---
int max = cups[0], maxIndex = 0;
int min = cups[0], minIndex = 0;
for (int i = 1; i < cups.Length; i++)
{
    if (cups[i] > max) { max = cups[i]; maxIndex = i; }
    if (cups[i] < min) { min = cups[i]; minIndex = i; }
}

Console.WriteLine($"Найкращий день: {dayNames[maxIndex]} ({max} чашок), індекс {maxIndex}");
Console.WriteLine($"Найгірший день: {dayNames[minIndex]} ({min} чашок), індекс {minIndex}");

// --- Крок 5. Скільки днів вище за середнє ---
int goodDays = 0;
foreach (int c in cups)
{
    if (c > average) goodDays++;
}
Console.WriteLine($"Днів, кращих за середній рівень: {goodDays}");

// --- Крок 6. Обернений порядок (працюємо з копією) ---
int[] reversed = (int[])cups.Clone();
for (int i = 0; i < reversed.Length / 2; i++)
{
    int temp = reversed[i];
    reversed[i] = reversed[reversed.Length - 1 - i];
    reversed[reversed.Length - 1 - i] = temp;
}
Console.WriteLine("У оберненому порядку: " + string.Join(", ", reversed));

// --- Крок 7. Найкращий день — на перше місце ---
int swap = cups[0];
cups[0] = cups[maxIndex];
cups[maxIndex] = swap;
Console.WriteLine("Після перестановки:   " + string.Join(", ", cups));
```
