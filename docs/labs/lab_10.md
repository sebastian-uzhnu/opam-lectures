# Лабораторна робота №10

## Тема
Обробка рядків засобами класів String та StringBuilder

## Мета
Навчитися працювати з текстовими даними як із послідовністю символів: визначати довжину рядка, звертатися до окремих символів за індексом і перебирати їх циклом. Закріпити застосування стандартних методів класу `String` для пошуку, вирізання, заміни та розбиття тексту. Набути навичок коректного порівняння рядків і використання класу `StringBuilder` для багаторазової зміни тексту. Зрозуміти, чому рядок у C# незмінний і які наслідки це має для швидкодії програми.

## Тривалість
2 академічні години.

## Обладнання та програмне забезпечення
Персональний комп'ютер, .NET 8 SDK, будь-яке середовище розробки або текстовий редактор і термінал, система контролю версій Git.

## Теоретичні відомості

### 1. Рядок як послідовність символів

**Рядок** (`string`, повне ім'я типу — `System.String`) — це тип даних, який зберігає впорядковану послідовність символів. Кожен елемент цієї послідовності має тип `char` — один символ у кодуванні Unicode (2 байти).

Уявіть рядок як масив символів із нумерацією від нуля — так само, як масив `int[]` із ЛР7:

```
             рядок "Програма"
             
  індекс:    0   1   2   3   4   5   6   7
           ┌───┬───┬───┬───┬───┬───┬───┬───┐
  символ:  │ П │ р │ о │ г │ р │ а │ м │ а │
           └───┴───┴───┴───┴───┴───┴───┴───┘
             ▲                           ▲
             │                           │
        text[0]                    text[text.Length - 1]

        text.Length == 8   (кількість символів, не максимальний індекс!)
```

Звертання до символу виконується так само, як до елемента масиву — через квадратні дужки:

```csharp
string city = "Полтава";

Console.WriteLine(city.Length);            // скільки символів
Console.WriteLine(city[0]);                // перший символ
Console.WriteLine(city[city.Length - 1]);  // останній символ
```

```
Вивід:
7
П
а
```

Спроба звернутися за індексом, більшим за `Length - 1`, спричиняє помилку виконання `IndexOutOfRangeException` — точно так само, як вихід за межі масиву.

### 2. Незмінність рядка (immutability)

**Незмінність** (англ. immutability) — властивість типу, за якої створений об'єкт неможливо змінити: будь-яка «зміна» насправді створює новий об'єкт.

Рядок у C# незмінний. Це означає, що запис `text[0] = 'X'` не скомпілюється взагалі, а методи на кшталт `ToUpper()` чи `Replace()` **не змінюють** вихідний рядок, а повертають новий:

```csharp
string name = "олена";
name.ToUpper();                 // результат нікуди не збережено — рядок не змінився
Console.WriteLine(name);

name = name.ToUpper();          // а ось тепер змінна вказує на новий рядок
Console.WriteLine(name);
```

```
Вивід:
олена
ОЛЕНА
```

Що насправді відбувається в пам'яті:

```
   Крок 1: string name = "олена";

        name ──────────────► [ о л е н а ]      (об'єкт №1)

   Крок 2: name = name.ToUpper();

                              [ о л е н а ]      (об'єкт №1, більше ніхто
                                                  на нього не вказує — його
                                                  згодом прибере збирач сміття)
        name ──────────────► [ О Л Е Н А ]      (об'єкт №2, новий)
```

Чому так зроблено: незмінні об'єкти безпечно передавати в методи (метод не зіпсує ваш рядок), їх можна кешувати й безпечно використовувати з кількох потоків. Ціна цього рішення — кожна операція над рядком виділяє пам'ять під новий об'єкт.

### 3. Перебирання символів

Оскільки рядок — послідовність, його можна перебрати циклом `for` за індексом або циклом `foreach`, коли індекс не потрібен:

```csharp
string word = "дім";

// варіант 1: потрібен індекс
for (int i = 0; i < word.Length; i++)
{
    Console.WriteLine($"{i}: {word[i]}");
}

// варіант 2: індекс не потрібен
foreach (char c in word)
{
    Console.Write(c + "-");
}
```

```
Вивід:
0: д
1: і
2: м
д-і-м-
```

### 4. Основні методи класу String

Усі методи нижче **повертають новий рядок або число** і ніколи не змінюють той рядок, до якого їх застосовано.

| Метод | Що робить | Приклад | Результат |
|---|---|---|---|
| `Substring(start)` | підрядок від позиції `start` до кінця | `"Полтава".Substring(3)` | `"тава"` |
| `Substring(start, len)` | підрядок завдовжки `len` від позиції `start` | `"Полтава".Substring(0, 3)` | `"Пол"` |
| `IndexOf(s)` | індекс першого входження, або `-1` | `"абраабра".IndexOf("бра")` | `1` |
| `LastIndexOf(s)` | індекс останнього входження, або `-1` | `"абраабра".LastIndexOf("бра")` | `5` |
| `Contains(s)` | чи міститься підрядок (`bool`) | `"довідка".Contains("від")` | `true` |
| `StartsWith(s)` | чи починається рядок із `s` | `"UA-2024".StartsWith("UA")` | `true` |
| `EndsWith(s)` | чи закінчується рядком `s` | `"звіт.csv".EndsWith(".csv")` | `true` |
| `Replace(a, b)` | заміняє всі входження `a` на `b` | `"2+2".Replace("+", "-")` | `"2-2"` |
| `Trim()` | прибирає пробіли з обох кінців | `"  код  ".Trim()` | `"код"` |
| `TrimStart()` / `TrimEnd()` | прибирає пробіли зліва / справа | `"  код  ".TrimEnd()` | `"  код"` |
| `ToUpper()` / `ToLower()` | у верхній / нижній регістр | `"Код".ToUpper()` | `"КОД"` |
| `Split(sep)` | розбиває на масив рядків за роздільником | `"a,b,c".Split(',')` | `["a", "b", "c"]` |
| `string.Join(sep, arr)` | склеює масив у рядок через роздільник | `string.Join("-", parts)` | `"a-b-c"` |
| `PadLeft(n)` / `PadRight(n)` | доповнює пробілами до довжини `n` | `"7".PadLeft(3)` | `"  7"` |
| `PadLeft(n, ch)` | доповнює символом `ch` | `"7".PadLeft(3, '0')` | `"007"` |
| `Insert(pos, s)` | вставляє `s` у позицію `pos` | `"код".Insert(0, "мій ")` | `"мій код"` |
| `Remove(pos, len)` | видаляє `len` символів від `pos` | `"звіт2024".Remove(4, 4)` | `"звіт"` |
| `string.IsNullOrWhiteSpace(s)` | чи рядок порожній або лише пробіли | `string.IsNullOrWhiteSpace("  ")` | `true` |
| `string.Compare(a, b)` | порівняння: від'ємне / 0 / додатне | `string.Compare("a", "b")` | `-1` |

Кілька методів у дії:

```csharp
string record = "  Шевченко Тарас Григорович  ";

string clean = record.Trim();
Console.WriteLine($"[{clean}]");
Console.WriteLine($"Довжина після Trim: {clean.Length}");

int firstSpace = clean.IndexOf(' ');
string surname = clean.Substring(0, firstSpace);
Console.WriteLine($"Прізвище: {surname}");

string[] parts = clean.Split(' ');
Console.WriteLine($"Частин ПІБ: {parts.Length}");
Console.WriteLine(string.Join(" | ", parts));
```

```
Вивід:
[Шевченко Тарас Григорович]
Довжина після Trim: 25
Прізвище: Шевченко
Частин ПІБ: 3
Шевченко | Тарас | Григорович
```

### 5. Метод Split і зайві порожні елементи

`Split` розбиває рядок за роздільником і повертає **масив рядків** (`string[]`) — звичайний масив, з яким ви працювали в ЛР7. Якщо роздільники йдуть підряд, між ними утворюються порожні елементи:

```csharp
string line = "сім  вісім   дев'ять";

string[] rough = line.Split(' ');
Console.WriteLine($"Просто Split: {rough.Length} елементів");

string[] clean = line.Split(' ', StringSplitOptions.RemoveEmptyEntries);
Console.WriteLine($"З RemoveEmptyEntries: {clean.Length} елементів");
```

```
Вивід:
Просто Split: 6 елементів
З RemoveEmptyEntries: 3 елементів
```

Параметр `StringSplitOptions.RemoveEmptyEntries` прибирає порожні елементи — саме він потрібен, коли ви рахуєте слова в тексті з подвійними пробілами.

Розбити можна й за кількома роздільниками одразу, передавши масив символів:

```csharp
string sentence = "Один, два; три. Чотири";
string[] words = sentence.Split(
    [' ', ',', ';', '.'],
    StringSplitOptions.RemoveEmptyEntries);

Console.WriteLine($"Слів: {words.Length}");
Console.WriteLine(string.Join("/", words));
```

```
Вивід:
Слів: 4
Один/два/три/Чотири
```

### 6. Порівняння рядків

Це місце, де початківці припускаються найбільше помилок. Є три способи порівняти рядки, і вони мають різне призначення.

| Спосіб | Що дає | Коли застосовувати |
|---|---|---|
| `a == b` | `true`, якщо рядки посимвольно однакові | звичайна перевірка на рівність |
| `a.Equals(b)` | те саме, що `==` | те саме; має перевантаження з правилами порівняння |
| `a.Equals(b, StringComparison.OrdinalIgnoreCase)` | рівність без урахування регістру | логіни, команди меню, ключові слова |
| `string.Compare(a, b)` | `-1`, `0` або `1` — порядок рядків | сортування за алфавітом |

```csharp
string input = "ТАК";
string expected = "так";

Console.WriteLine(input == expected);
Console.WriteLine(input.ToLower() == expected);
Console.WriteLine(input.Equals(expected, StringComparison.OrdinalIgnoreCase));
```

```
Вивід:
False
True
True
```

**Чутливість до регістру** означає, що великі й малі літери вважаються різними символами: `'А'` і `'а'` мають різні коди. Тому `"Іван" == "іван"` дає `false`. Якщо регістр для вас не має значення (користувач міг увімкнути Caps Lock), використовуйте `StringComparison.OrdinalIgnoreCase`.

**Культура** — набір мовних правил країни: порядок літер в алфавіті, правила переведення регістру, формат чисел і дат. `string.Compare` за замовчуванням враховує поточну культуру, тому українські літери впорядковуються за українським алфавітом, а не за кодами символів. Для сортування текстів, які бачить людина, це те, що потрібно. Для порівняння службових рядків (імена файлів, коди, ідентифікатори) надійніше вказати `StringComparison.Ordinal` — порівняння суто за кодами символів, без мовних правил.

Результат `string.Compare(a, b)` читається так:

```
   від'ємне число  →  a йде в алфавіті ДО b
   нуль            →  a і b однакові
   додатне число   →  a йде в алфавіті ПІСЛЯ b
```

```csharp
string[] names = ["Яремчук", "Андрієнко", "Мельник"];

// бульбашкове сортування з ЛР9, але порівнюємо рядки
for (int i = 0; i < names.Length - 1; i++)
{
    for (int j = 0; j < names.Length - 1 - i; j++)
    {
        if (string.Compare(names[j], names[j + 1]) > 0)
        {
            (names[j], names[j + 1]) = (names[j + 1], names[j]);
        }
    }
}

Console.WriteLine(string.Join(", ", names));
```

```
Вивід:
Андрієнко, Мельник, Яремчук
```

### 7. Клас Char

Клас `Char` містить статичні методи для перевірки окремого символу. Вони потрібні майже в кожній задачі на розбір тексту.

| Метод | Що перевіряє або робить | Приклад | Результат |
|---|---|---|---|
| `char.IsDigit(c)` | чи це цифра 0–9 | `char.IsDigit('7')` | `true` |
| `char.IsLetter(c)` | чи це літера будь-якої мови | `char.IsLetter('ї')` | `true` |
| `char.IsLetterOrDigit(c)` | літера або цифра | `char.IsLetterOrDigit('_')` | `false` |
| `char.IsWhiteSpace(c)` | пробіл, табуляція, перехід рядка | `char.IsWhiteSpace('\t')` | `true` |
| `char.IsUpper(c)` / `char.IsLower(c)` | великий / малий регістр | `char.IsUpper('Д')` | `true` |
| `char.IsPunctuation(c)` | розділовий знак | `char.IsPunctuation(',')` | `true` |
| `char.ToUpper(c)` / `char.ToLower(c)` | переводить у інший регістр | `char.ToUpper('м')` | `'М'` |

```csharp
string passport = "СМ 123456";
int digits = 0;
int letters = 0;

foreach (char c in passport)
{
    if (char.IsDigit(c)) digits++;
    else if (char.IsLetter(c)) letters++;
}

Console.WriteLine($"Цифр: {digits}, літер: {letters}");
```

```
Вивід:
Цифр: 6, літер: 2
```

### 8. Інтерполяція та дослівні рядки

**Інтерполяція рядків** — підстановка значень виразів у текст, позначається символом `$` перед лапками. Ви користувалися нею з ЛР2; тут додамо форматування.

```csharp
string product = "Кава";
double price = 87.5;
int count = 3;

Console.WriteLine($"{product}: {count} шт. по {price:F2} грн = {count * price:F2} грн");
Console.WriteLine($"{product,-10}|{count,5}|{price,10:F2}");
```

```
Вивід:
Кава: 3 шт. по 87.50 грн = 262.50 грн
Кава      |    3|     87.50
```

Після коми у фігурних дужках вказують **ширину поля**: додатне число вирівнює праворуч, від'ємне — ліворуч. Після двокрапки — **формат**: `F2` — два знаки після коми, `N0` — з розділювачем тисяч без дробової частини, `P1` — відсотки.

**Дослівний рядок** (verbatim string) позначається символом `@` перед лапками. У ньому вимикається обробка керуючих послідовностей, тому зворотна похила риска залишається сама собою:

```csharp
string usual = "C:\\Робота\\Звіти\\звіт.txt";
string verbatim = @"C:\Робота\Звіти\звіт.txt";

Console.WriteLine(usual);
Console.WriteLine(verbatim);
Console.WriteLine(usual == verbatim);
```

```
Вивід:
C:\Робота\Звіти\звіт.txt
C:\Робота\Звіти\звіт.txt
True
```

Дослівний рядок може займати кілька фізичних рядків тексту програми — усі переходи рядків потрапляють у значення. Комбінований запис `$@"..."` (або `@$"..."`) поєднує інтерполяцію з дослівністю.

Нагадування про керуючі послідовності у звичайних рядках: `\n` — перехід на новий рядок, `\t` — табуляція, `\"` — лапки, `\\` — сама похила риска.

### 9. Клас StringBuilder і чому `+=` у циклі — погано

Через незмінність рядків кожне склеювання створює **новий** об'єкт у пам'яті. Якщо склеювання відбувається в циклі, програма створює стільки проміжних рядків, скільки в неї ітерацій, і всі вони, крім останнього, одразу стають сміттям:

```
   Цикл із трьома ітераціями:  result += "abc";

   ітерація 1:  створено ""         →  "abc"          (копіювання 0 символів)
   ітерація 2:  створено "abc"      →  "abcabc"       (копіювання 3 символів)
   ітерація 3:  створено "abcabc"   →  "abcabcabc"    (копіювання 6 символів)

   На 10 000 ітерацій — 10 000 непотрібних об'єктів
   і десятки мільйонів скопійованих символів.
```

**StringBuilder** (`System.Text.StringBuilder`) — це змінюваний буфер символів. Він тримає один внутрішній масив, дописує в нього символи, а коли місця бракує — збільшує масив приблизно вдвічі. Готовий текст отримують методом `ToString()` один раз наприкінці.

| Член класу | Призначення |
|---|---|
| `new StringBuilder()` | створити порожній буфер |
| `new StringBuilder(capacity)` | створити буфер із запасом місця |
| `Append(x)` | дописати значення в кінець |
| `AppendLine(x)` | дописати значення й перехід рядка |
| `Insert(pos, x)` | вставити в позицію |
| `Remove(pos, len)` | видалити фрагмент |
| `Replace(a, b)` | замінити всі входження |
| `Clear()` | очистити буфер |
| `Length` | поточна кількість символів |
| `ToString()` | отримати звичайний рядок |

```csharp
using System.Text;

var table = new StringBuilder();
table.AppendLine("Місяць     | Витрати");
table.AppendLine("-----------+--------");

string[] months = ["Січень", "Лютий", "Березень"];
double[] costs = [4200.5, 3980.0, 5120.75];

for (int i = 0; i < months.Length; i++)
{
    table.AppendLine($"{months[i],-10} | {costs[i],7:F2}");
}

Console.WriteLine(table.ToString());
Console.WriteLine($"Символів у буфері: {table.Length}");
```

```
Вивід:
Місяць     | Витрати
-----------+--------
Січень     | 4200.50
Лютий      | 3980.00
Березень   | 5120.75

Символів у буфері: 90
```

Практичне правило: якщо склеювань **менше десяти й вони йдуть підряд у коді** — звичайна інтерполяція чи `+` цілком прийнятні, компілятор сам їх оптимізує. Якщо склеювання **всередині циклу** — беріть `StringBuilder`.

### 10. Рядок у масив символів і назад

Іноді зручно працювати з текстом як зі справжнім масивом (наприклад, щоб застосувати сортування з ЛР9):

```csharp
string word = "алгоритм";
char[] letters = word.ToCharArray();
Array.Sort(letters);
string sorted = new string(letters);

Console.WriteLine(sorted);
Console.WriteLine(new string('=', 10));
```

```
Вивід:
аглмоирт
==========
```

Конструктор `new string(char[])` збирає рядок із масиву символів, а `new string(ch, n)` повторює символ `n` разів — зручно для роздільних ліній у звітах.

## Приклад виконання

**Умова.** Користувач вводить рядок тексту. Потрібно:
1. прибрати зайві пробіли на початку, в кінці й усередині (кілька пробілів підряд звести до одного);
2. підрахувати кількість слів;
3. знайти найдовше слово;
4. підрахувати, скільки в тексті голосних літер;
5. вивести кожне слово з великої літери, склавши результат через `StringBuilder`.

**Аналіз.**

Нормалізацію пробілів зручно зробити не посимвольно, а через розбиття й склеювання: `Split` із параметром `RemoveEmptyEntries` дає масив слів без порожніх елементів, а `string.Join(" ", words)` збирає їх назад рівно через один пробіл. Тоді пункти 2 і 3 працюють уже з готовим масивом: довжина масиву — це кількість слів, а найдовше слово шукається лінійним пошуком максимуму з ЛР7.

Голосні зручно тримати в одному рядку-довіднику й перевіряти кожен символ тексту методом `IndexOf`: якщо результат не `-1`, символ є в довіднику. Регістр знімаємо `char.ToLower`.

Для пункту 5 у циклі виконується багато склеювань, тому беремо `StringBuilder`.

Окремий випадок: користувач може ввести порожній рядок або самі пробіли. Тоді масив слів має нуль елементів, і шукати максимум немає в чому — програма має коректно повідомити про це, а не впасти з помилкою.

**Код.**

```csharp
using System.Text;

Console.Write("Введіть речення: ");
string input = Console.ReadLine() ?? "";

// 1. Нормалізація пробілів: розбиваємо на слова й склеюємо через один пробіл
string[] words = input.Split(
    [' ', '\t'],
    StringSplitOptions.RemoveEmptyEntries);

if (words.Length == 0)
{
    Console.WriteLine("Текст порожній — обробляти немає чого.");
    return;
}

string normalized = string.Join(" ", words);
Console.WriteLine($"Нормалізований текст: [{normalized}]");
Console.WriteLine($"Було символів: {input.Length}, стало: {normalized.Length}");

// 2. Кількість слів — це довжина масиву після RemoveEmptyEntries
Console.WriteLine($"Кількість слів: {words.Length}");

// 3. Найдовше слово — лінійний пошук максимуму
string longest = words[0];
foreach (string w in words)
{
    if (w.Length > longest.Length)
    {
        longest = w;
    }
}
Console.WriteLine($"Найдовше слово: \"{longest}\" ({longest.Length} симв.)");

// 4. Підрахунок голосних
const string Vowels = "аеєиіїоуюяaeiouy";
int vowelCount = 0;
foreach (char c in normalized)
{
    if (Vowels.IndexOf(char.ToLower(c)) >= 0)
    {
        vowelCount++;
    }
}
Console.WriteLine($"Голосних літер: {vowelCount}");

// 5. Кожне слово з великої літери; склеювання в циклі — через StringBuilder
var builder = new StringBuilder(normalized.Length);
for (int i = 0; i < words.Length; i++)
{
    string w = words[i];
    builder.Append(char.ToUpper(w[0]));      // перша літера велика
    if (w.Length > 1)
    {
        builder.Append(w.Substring(1).ToLower());  // решта — малі
    }

    if (i < words.Length - 1)
    {
        builder.Append(' ');                 // пробіл між словами, але не в кінці
    }
}

Console.WriteLine($"У заголовковому регістрі: {builder.ToString()}");
```

**Вивід програми.**

```
Введіть речення:    полтавський   фаховий  КОЛЕДЖ  нафти і газу   
Нормалізований текст: [полтавський фаховий КОЛЕДЖ нафти і газу]
Було символів: 54, стало: 40
Кількість слів: 6
Найдовше слово: "полтавський" (11 симв.)
Голосних літер: 15
У заголовковому регістрі: Полтавський Фаховий Коледж Нафти І Газу
```

**Перевірка на граничному випадку.**

```
Введіть речення:        
Текст порожній — обробляти немає чого.
```

**Що тут варто помітити.** Нормалізація пробілів зроблена без жодного посимвольного циклу — два виклики методів замінили десяток рядків коду. Умова `if (i < words.Length - 1)` потрібна, щоб у результаті не з'явився зайвий пробіл наприкінці; альтернатива — дописувати пробіл завжди, а наприкінці зрізати його методом `Trim()`.

## Додаткове завдання (на вищу оцінку)

Доповніть свою програму **текстовим меню**, яке працює в циклі, поки користувач не обере пункт «Вихід». Меню має містити щонайменше чотири дії: увести новий текст, виконати обробку за вашим варіантом, показати статистику тексту (кількість символів, слів, речень, літер, цифр, пробілів) і показати накопичений **журнал операцій**.

Журнал складайте в одному об'єкті `StringBuilder`, який живе протягом усієї роботи програми: кожна виконана дія дописує в нього рядок із порядковим номером і коротким описом. Вивід журналу — одним викликом `Console.WriteLine`. У звіті поясніть, чому для журналу взято `StringBuilder`, а не звичайне склеювання `+=`, і оцініть, скільки проміжних рядків створила б програма за 200 операцій.

## Контрольні питання

1. Що означає твердження «рядок у C# незмінний»? Наведіть приклад коду, який виглядає як зміна рядка, але насправді нею не є.
2. Чому вираз `text[0] = 'A'` не компілюється, хоча `array[0] = 5` для масиву працює?
3. Чим `Length` рядка відрізняється від індексу останнього символу? Який індекс отримає останній символ рядка `"код"`?
4. У чому різниця між `IndexOf` і `LastIndexOf`? Що повертає `IndexOf`, якщо підрядок не знайдено, і чому саме таке значення?
5. Порівняйте `==`, `Equals` і `string.Compare`. Який із них ви застосуєте для сортування прізвищ за алфавітом і чому?
6. Що таке чутливість до регістру й до культури при порівнянні рядків? Наведіть ситуацію, коли ігнорувати регістр обов'язково.
7. Чому склеювання рядків оператором `+=` у циклі на 10 000 ітерацій — погане рішення? Що саме відбувається в пам'яті на кожній ітерації?
8. Як влаштований `StringBuilder` усередині й чому він швидший за багаторазове `+=`? Коли `StringBuilder` застосовувати не варто?
9. Що робить параметр `StringSplitOptions.RemoveEmptyEntries` і в якій задачі без нього результат буде неправильним?
10. Чим дослівний рядок `@"..."` відрізняється від звичайного? Запишіть шлях `C:\temp\a.txt` обома способами.
