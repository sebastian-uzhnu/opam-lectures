# Самоперевірка та домашнє завдання

## Питання для самоперевірки

Питання згруповані за підрозділами теми. Відповідайте своїми словами — якщо
не виходить, поверніться до відповідного підрозділу.

## Практичні міні-задачі

Короткі вправи на 5–10 хвилин кожна, для перевірки розуміння прямо після лекції.

1. **Світлофор без коду.** Намалюйте у XAML три кола в темному прямокутнику
   із заокругленими кутами. Верхнє залийте радіальним градієнтом від світлого
   центру до темного краю, два інші — темними суцільними кольорами.
   Жодного рядка C#.

2. **Стрілка, що крутиться.** Покладіть на `Canvas` вузький `Rectangle`
   і змусьте його обертатися нескінченно навколо власного центру.
   Перевірте, що буде, якщо прибрати `RenderTransformOrigin="0.5,0.5"`.

3. **П'ять кроків згладжування.** Зробіть п'ять однакових кружечків
   і запустіть їм одну й ту саму `DoubleAnimation` по `Canvas.Left`,
   але з різними функціями: без згладжування, `QuadraticEase`, `BackEase`,
   `ElasticEase`, `BounceEase` — усі з `EasingMode="EaseOut"`. Подивіться,
   як по-різному вони доїжджають до фінішу.

4. **Косинус із сіткою.** Побудуйте графік `Math.Cos` на проміжку
   від -2·pi до 2·pi з горизонтальною сіткою й підписами -1, -0.5, 0, 0.5, 1.
   Розтягніть вікно й переконайтесь, що графік перемальовується.

5. **Три стовпчики.** Намалюйте стовпчикову діаграму для масиву
   `[12, 45, 7]` так, щоб вона правильно виглядала і для масиву
   `[1200, 4500, 700]` без жодної зміни коду.

### Завдання: «Годинник зі стрілками»

Зробіть настільний годинник, який показує реальний час — такий, щоб його
не соромно було залишити відкритим на другому моніторі. Циферблат
малюється примітивами, стрілки крутяться через `RotateTransform`,
а рухає їх `DispatcherTimer`.

Задача не така велика, як здається: увесь годинник — це коло, дванадцять
рисок, три прямокутники й одна формула переведення часу в кут.

**Вимоги:**

- циферблат на окремому `Canvas`: коло (`Ellipse`) із заливкою
  й помітним обведенням, усередині — центральна крапка;
- дванадцять годинних поділок по колу, побудованих **у циклі в коді**,
  а не вручну в XAML; годинні риски товщі за хвилинні;
- три стрілки — годинна, хвилинна, секундна — різної довжини, товщини
  й кольору; кожна повертається власним `RotateTransform`;
- `DispatcherTimer` з інтервалом 1 секунда оновлює кути стрілок
  за поточним `DateTime.Now`;
- кути рахуються правильно: секундна `сек * 6`, хвилинна
  `хв * 6 + сек * 0.1`, годинна `(год % 12) * 30 + хв * 0.5` —
  тобто годинна стрілка плавно повзе між цифрами, а не стрибає;
- під циферблатом — цифровий час у форматі `ГГ:ХХ:СС`
  (`DateTime.Now.ToString("HH:mm:ss")`);
- при зміні розміру вікна циферблат перемальовується й залишається
  по центру (обробник `SizeChanged`);
- кнопки та цифровий час лежать **не** на тому `Canvas`, де малюється
  циферблат.

**Приклад роботи:**

```
┌─ Годинник ────────────────────────── ─ □ ✕ ┐
│                                            │
│              ╭───────────────╮             │
│           ╱        12         ╲            │
│         ╱   │                  ╲           │
│        │ 9  │         3         │          │
│        │    ╲───────▶           │          │
│         ╲    ╲                 ╱           │
│           ╲   ▼      6       ╱             │
│              ╰───────────────╯             │
│                                            │
│                 14:37:52                   │
│                                            │
│        [ Світла тема ] [ Темна тема ]      │
└────────────────────────────────────────────┘
```

Формула розміщення поділки номер `i` (від 0 до 11) на колі радіуса `r`
із центром `(cx, cy)`:

```
   кут = i * 30 градусів - 90        (мінус 90, щоб нуль був угорі)
   рад = кут * Math.PI / 180

   x = cx + r * Math.Cos(рад)
   y = cy + r * Math.Sin(рад)
```

:::tip[Підказка]
Стрілку зручно робити як `Rectangle` із `RenderTransformOrigin="0.5,1"` —
тоді точка обертання опиниться посередині нижнього краю, тобто рівно
в центрі циферблата. Саму стрілку ставте так, щоб її нижній край був
у центрі: `Canvas.SetLeft(hand, cx - width / 2)` і
`Canvas.SetTop(hand, cy - length)`.

Кут задається одним рядком:
`((RotateTransform)hand.RenderTransform).Angle = angle;`

І не забудьте викликати обробник таймера **один раз одразу** після старту —
інакше перша секунда стрілки стоятимуть на нулі.
:::

**Додатково (за бажанням, на вищу оцінку):** зробіть секундну стрілку
по-справжньому плавною — замініть інтервал таймера на 50 мілісекунд
і рахуйте кут із урахуванням мілісекунд
(`DateTime.Now.Millisecond`). А ще додайте `Storyboard` із `ColorAnimation`,
який раз на хвилину плавно «підморгує» кольором центральної крапки.

### Альтернативне завдання: «Аналізатор оцінок»

Якщо хочеться попрацювати саме з даними, а не з анімацією, візьміть цю
задачу замість годинника.

Вікно містить `DataGrid` зі списком предметів і оцінок (предмет плюс
число від 1 до 12) та діаграму, яка оновлюється **миттєво**, щойно
користувач змінив оцінку, додав або видалив рядок. Перемикач обирає
тип діаграми: стовпчики або кругова. Під діаграмою — рядок із середнім
балом, найкращим і найгіршим предметом.

**Вимоги:**

- дані у `ObservableCollection` з елементом, що реалізує `INotifyPropertyChanged`;
- підписки на `CollectionChanged` **і** на `PropertyChanged` елементів;
- масштаб осі рахується з даних, а не зашитий числом;
- стовпчики розфарбовані за оцінкою: від 10 до 12 — зелений, від 7 до 9 —
  жовтий, нижче 7 — червоний;
- підпис значення над кожним стовпчиком;
- діаграма малюється на окремому `Canvas` і перемальовується
  у `SizeChanged`;
- середній бал рахується звичайним циклом `foreach` (LINQ ще не проходили).
