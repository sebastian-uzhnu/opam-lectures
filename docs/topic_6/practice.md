# Самоперевірка та домашнє завдання

## Питання для самоперевірки

Питання згруповані за підрозділами теми. Відповідайте своїми словами — якщо не виходить,
поверніться до відповідного підрозділу.

### Логічні типи даних та оператори розгалуження

1. Скільки значень може мати тип `bool` і які вони? Скільки різних станів можна
   закодувати двома змінними типу `bool`?
2. Чому рядок `bool check = number;` не компілюється в C#, хоча в деяких інших мовах
   «ненульове число = істина» працює? Як записати те саме правильно?
3. Що є результатом виразу `a > b` — число чи логічне значення? Чому тоді можна
   написати `bool result = a > b;` без жодного перетворення?
4. Що виведе цей код і чому саме так?

   ```csharp
   bool isOpen = true;
   Console.WriteLine(isOpen);
   Console.WriteLine(!isOpen);
   ```

   Чому в консолі з'являється слово з великої літери, хоча в коді ми пишемо `true`?
5. Назвіть порядок пріоритетів операцій `!`, `&&`, `||`. Чому вираз
   `true || false && false` дає `true`, а `(true || false) && false` дає `false`?
6. Що виведе цей код?

   ```csharp
   int x = 7;
   Console.WriteLine(x > 0 && x % 2 == 0 ? "додатне парне" : "інше");
   ```

7. Чим ланцюжок `else if` кращий за глибоко вкладені `if` усередині `if`?
   Чи змінюється при цьому результат роботи програми?
8. У прикладі з віком (`age < 12`, потім `age < 18`, потім `age < 60`) умови не містять
   нижньої межі: ніде не написано `age >= 12 && age < 18`. Чому ланцюжок все одно
   працює правильно?
9. Тернарний оператор — це скорочення `if`/`else`. Наведіть ситуацію, де він робить код
   чистішим, і ситуацію, де краще написати повний `if`.
10. Навіщо кожен блок `case` у `switch` завершують оператором `break`?
    Що таке «провалювання» (fall-through)?
11. Що виведе цей код і чому одна гілка обслуговує два значення?

    ```csharp
    int value = 3;
    switch (value)
    {
        case 1:
            Console.WriteLine("Один");
            break;
        case 2:
        case 3:
            Console.WriteLine("Два або три");
            break;
        default:
            Console.WriteLine("Інше число");
            break;
    }
    ```

12. Оператор `goto` існує в C#, але користуватися ним не радять. Поясніть, що саме
    він псує в програмі, і чим його замінюють на практиці.

### Таблиці істинності

13. Скільки рядків має таблиця істинності для двох змінних? А для трьох? Звідки береться
    це число?
14. Порівняйте таблиці для `A || B` та `A ^ B`. У якому єдиному рядку вони розходяться
    і як це пояснити словами?
15. Заповніть таблицю істинності для виразу `!(A && B)` і окремо для `!A || !B`.
    Що ви помітили? (Це закон, який має ім'я — спробуйте пригадати яке.)

### Побітові логічні операції

16. Чим оператор `&` відрізняється від `&&`? До чого застосовується перший, а до чого
    другий?
17. Обчисліть вручну, у двійковій формі, і перевірте в коді. Що виведе кожен рядок?

    ```csharp
    int a = 6;  // 0110
    int b = 3;  // 0011

    Console.WriteLine(a & b);
    Console.WriteLine(a | b);
    Console.WriteLine(a ^ b);
    Console.WriteLine(a << 1);
    Console.WriteLine(a >> 2);
    ```

18. Чому `~5` дорівнює `-6`, а не якомусь великому додатному числу? Що робить оператор
    `~` з усіма 32 бітами числа `int`?
19. Чому зсув вліво на `n` позицій — це множення на 2 у степені `n`? Поясніть
    на прикладі `5 << 2` через двійковий запис, а не через формулу.
20. Зсув вправо ділить число «з округленням донизу». Перевірте це на `20 >> 2`
    та на `7 >> 1`. Чим такий зсув зручний і чому його все ж не варто писати замість
    звичайного ділення в навчальному коді?

## Практичні міні-задачі

Короткі вправи на 5–10 хвилин кожна, для перевірки розуміння прямо після лекції.

1. **Опис числа.** Користувач вводить ціле число. Виведіть про нього один рядок,
   який містить одразу дві характеристики: «додатне» / «від'ємне» / «нуль»
   і «парне» / «непарне». Нуль вважайте парним.

2. **Найбільше з трьох.** Прочитайте три числа і виведіть найбільше, використавши
   лише `if`/`else if` та логічні операції — без готових методів на кшталт `Math.Max`.
   Потім перепишіть те саме одним виразом із двома тернарними операторами.

3. **Високосний рік.** Рік високосний, якщо він ділиться на 4, але не на 100, або ж
   ділиться на 400. Запишіть цю умову одним логічним виразом і перевірте на роках
   1900, 2000, 2024, 2100.

4. **Таблиця істинності програмою.** Виведіть у консоль таблицю істинності для `A ^ B`
   у вигляді чотирьох рядків. Значення `A` та `B` задайте явно, без циклів.
   Переконайтеся, що вивід збігається з таблицею з лекції.

5. **Літера оцінки.** Число від 1 до 12 переведіть у рівень: 1–3 «початковий»,
   4–6 «середній», 7–9 «достатній», 10–12 «високий», усе інше — «некоректна оцінка».
   Зробіть це спочатку через `else if`, а потім через `switch` із групуванням `case`.

6. **Парність без остачі.** Перевірте парність числа виразом `n & 1` замість `n % 2`.
   Поясніть у коментарі, чому це працює, і перевірте на від'ємних числах.

## Домашнє завдання

:::info[Що здавати]
Один консольний проєкт (або один файл `.cs`) + скриншот роботи програми.
Орієнтовний час виконання — 30–45 хвилин.
:::

### Завдання: «Каса аквапарку»

В аквапарку біля вашого міста ціна квитка залежить одразу від кількох речей: віку
відвідувача, дня тижня, студентського квитка і того, чи береться додатково сауна.
Касирка тримає всі ці правила в голові й іноді помиляється. Напишіть їй помічника:
консольну програму, яка запитує кілька відповідей і рахує остаточну ціну.

Уся задача — це один великий логічний вираз, розкладений на зрозумілі кроки. Саме тому
вона добре показує, чи вмієте ви поєднувати умови, а не просто писати `if`.

**Вимоги:**

- запитати: вік, номер дня тижня (1–7), чи є студентський (`так`/`ні`),
  чи потрібна сауна (`так`/`ні`);
- **базова ціна**: будній день (1–5) — 250 грн, вихідний (6–7) — 350 грн;
- **категорія та знижка від базової ціни** (ланцюжок `else if`):
  - до 5 років — «Малеча», безкоштовно;
  - 5–13 — «Дитячий», 50% базової;
  - 14–17 — «Юнацький», 70% базової;
  - 18–59 — «Дорослий», 100% базової, але зі студентським — 80%;
  - 60 і більше — «Пенсійний», 50% базової;
- **сауна** коштує додатково 120 грн і доступна лише з 18 років; якщо сауну просить
  молодша людина — вивести відмову і не додавати ціну;
- день тижня вивести словом, використавши `switch`;
- якщо вік від'ємний або день тижня поза межами 1–7 — вивести повідомлення про помилку
  і завершити роботу, а не рахувати ціну.

**Приклад роботи:**

```
=== КАСА АКВАПАРКУ ===
Ваш вік: 19
День тижня (1-7): 6
Студентський квиток (так/ні): так
Сауна (так/ні): так

--- РОЗРАХУНОК ---
День: субота (вихідний)
Базова ціна: 350 грн
Категорія: Дорослий (студентська знижка 20%)
Ціна квитка: 280 грн
Сауна: +120 грн
------------------
ДО СПЛАТИ: 400 грн
```

```
=== КАСА АКВАПАРКУ ===
Ваш вік: 8
День тижня (1-7): 2
Студентський квиток (так/ні): ні
Сауна (так/ні): так

--- РОЗРАХУНОК ---
День: вівторок (будній)
Базова ціна: 250 грн
Категорія: Дитячий (знижка 50%)
Ціна квитка: 125 грн
Сауна: недоступна, до 18 років
------------------
ДО СПЛАТИ: 125 грн
```

:::tip[Підказка]
Відповідь «так»/«ні» зручно одразу перетворити на `bool`:
`bool isStudent = Console.ReadLine() == "так";` — тоді далі в умовах ви працюєте
з логічним значенням, а не порівнюєте рядки в кожному `if`.

Ціну зі знижкою рахуйте у `double`, а виводьте округлено. Не пишіть
`basePrice * 50 / 100` у цілих числах — так ви загубите копійки на інших відсотках.

Будній день чи вихідний — це один логічний вираз: `bool isWeekend = day >= 6;`
Далі базову ціну обирає тернарний оператор.
:::

**Додатково (за бажанням, на вищу оцінку):** додайте сімейний квиток. Якщо відвідувачів
двоє дорослих і хоча б одна дитина віком 5–13 років, вся компанія отримує ще 15% знижки
на підсумкову суму. Запитайте кількість дорослих і дітей, порахуйте загальну суму
і покажіть у чеку окремим рядком, скільки грошей зекономила сім'я.
