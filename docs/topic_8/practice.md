# Самоперевірка та домашнє завдання

## Питання для самоперевірки

Питання згруповані за підрозділами теми. Відповідайте своїми словами — якщо не виходить,
поверніться до відповідного підрозділу.

### Масиви

1. У означенні масиву з лекції є кілька ознак: упорядкований набір, фіксована кількість,
   однотипні елементи, послідовно розташовані комірки пам'яті. Поясніть, що дає кожна
   з цих ознак програмі, і що зламалося б, якби якоїсь із них не було.
2. Порівняйте чотири записи. Які з них створюють однаковий масив, а який рядок узагалі
   не скомпілюється і чому?

   ```csharp
   int[] a = new int[] { 1, 2, 3 };
   int[] b = { 1, 2, 3 };
   int[] c = new int[3];
   int[] d;
   d = { 1, 2, 3 };
   ```

3. Що міститься в масиві одразу після `new int[5]`? А після `new string[5]`?
   Чому відповіді різні?
4. Індекси масиву починаються з нуля. Який індекс має **останній** елемент масиву
   з 5 елементів? Що станеться під час виконання, якщо звернутися до `numbers[5]`,
   і чому компілятор цього не спіймав?
5. Чи можна після створення масиву додати до нього ще один елемент? Що насправді
   доводиться робити, якщо потрібен масив іншої довжини?

### Обробка масивів

6. Що виведе цей код і чому останнім числом буде саме 5, а не 6?

   ```csharp
   int[] numbers = { 1, 2, 3, 4, 5 };

   for (int i = 0; i < numbers.Length; i++)
   {
       Console.WriteLine(numbers[i]);
   }
   ```

7. Той самий обхід можна записати через `foreach`. Назвіть дві задачі, у яких `foreach`
   не підійде і доведеться повернутися до `for`.
8. Чому в лекції написано `Array.Reverse(numbers);` окремим рядком, а не
   `int[] reversed = Array.Reverse(numbers);`? Що станеться з вихідним масивом після
   виклику і як це називається?
9. У заголовку циклу стоїть `i < numbers.Length`, а не `i <= numbers.Length`.
   Поясніть, чому саме так, через означення індексації з нуля.

### Класи пам'яті

10. Масив — посилальний тип. Де в пам'яті лежить сама змінна `numbers`, а де —
    її п'ять чисел? Намалюйте це схемою зі стеком і купою.
11. Чим відрізняється розміщення масиву `int[]` від масиву `string[]`? Чому перший
    працює швидше під час обходу (згадайте про кеш процесора та послідовне
    розміщення).
12. У C# `string` фактично є масивом символів. Чому тоді рядок `text[0] = 'h';`
    не скомпілюється? Що відбувається в пам'яті щоразу, коли ви «змінюєте» рядок?
13. Що виведе цей код і чому? Скільки масивів насправді існує в пам'яті?

    ```csharp
    int[] first = { 1, 2, 3 };
    int[] second = first;
    second[0] = 99;

    Console.WriteLine(first[0]);
    Console.WriteLine(second[0]);
    ```

### Багатовимірні масиви

14. Порівняйте прямокутний `int[,]` та зубчастий `int[][]` масиви за чотирма ознаками
    з таблиці в лекції. Який синтаксис доступу в кожного?
15. Для масиву `new int[3, 4]`: що повернуть `GetLength(0)`, `GetLength(1)`
    і просто `Length`? Чому для двовимірного масиву `Length` майже ніколи не потрібен
    у циклі?
16. Що виведе цей код і чому такий вивід незручний для таблиці?

    ```csharp
    int[,] matrix =
    {
        { 1, 2, 3 },
        { 4, 5, 6 }
    };

    foreach (int value in matrix)
    {
        Console.Write(value + " ");
    }
    ```

17. Наведіть задачу, у якій зубчастий масив підходить краще за прямокутний,
    і поясніть, що саме економиться. Чому для таблиці оцінок групи навпаки —
    краще прямокутний?

### Вказівники та багатовимірні масиви

18. Навіщо потрібне ключове слово `fixed` перед роботою з вказівником на масив?
    Що може зробити збирач сміття, якщо масив не зафіксувати?
19. У прикладі з лекції адреса елемента обчислюється як `*(ptr + i * 4 + j)`.
    Звідки взялася четвірка і як зміниться формула для матриці розміром 3 на 5?
    А яку формулу довелося б писати для тривимірного масиву?
20. У більшості випадків замість `unsafe` радять `Span<T>`. Назвіть три переваги
    `Span<T>` із лекції та скажіть, який рядок треба додати у файл `.csproj`, щоб
    небезпечний код узагалі скомпілювався.

## Практичні міні-задачі

Короткі вправи на 5–10 хвилин кожна, для перевірки розуміння прямо після лекції.

1. **Три числа за один прохід.** Створіть масив із 10 випадкових чисел і за **один**
   цикл знайдіть мінімум, максимум і суму. Середнє порахуйте після циклу — не забудьте
   про приведення до `double`.

2. **Реверс власноруч.** Розверніть масив без `Array.Reverse`: міняйте місцями елементи
   `i` та `Length - 1 - i`. Поясніть у коментарі, чому цикл має йти лише до середини
   масиву і що станеться, якщо пустити його до кінця.

3. **Копія чи посилання.** Напишіть маленьку програму, у якій один масив присвоєно
   іншому напряму (`b = a`), а третій отримано через `(int[])a.Clone()`. Змініть
   елемент і виведіть усі три. Поясніть результат схемою стека й купи.

4. **Шахівниця.** Заповніть двовимірний масив символів 8 на 8 так, щоб виходив
   шаховий візерунок із `#` та `.`, і виведіть його вкладеними циклами.
   Підказка: колір клітинки залежить від парності суми індексів.

5. **Сума діагоналі.** Для квадратної матриці 5 на 5, заповненої числами,
   порахуйте суму головної діагоналі (`i == j`) і суму побічної. Зверніть увагу,
   що для цього достатньо **одного** циклу, а не двох вкладених.

6. **Розклад як зубчастий масив.** Складіть зубчастий масив `string[][]` на п'ять днів,
   де в понеділок три пари, у вівторок чотири, а в п'ятницю дві. Виведіть розклад
   по днях, використавши `jagged[i].Length` у внутрішньому циклі.

## Домашнє завдання

:::info Що здавати
Один консольний проєкт (або один файл `.cs`) + скриншот роботи програми.
Орієнтовний час виконання — 30–45 хвилин.
:::

### Завдання: «Журнал оцінок групи»

Наприкінці семестру куратор групи щоразу вручну рахує середні бали й шукає, кому
загрожує перескладання. Напишіть йому електронний журнал: двовимірний масив, у якому
рядок — це студент, а стовпчик — предмет. Програма має вивести охайну таблицю
й одразу дати відповідь на питання, заради яких журнал і заводять.

Дані задайте прямо в коді — вводити 20 оцінок із клавіатури щоразу під час перевірки
надто довго.

**Вимоги:**

- масив прізвищ `string[] students` (щонайменше 5) і масив назв предметів
  `string[] subjects` (щонайменше 4);
- двовимірний масив оцінок `int[,] grades` розміром «студенти на предмети»,
  заповнений оцінками за 12-бальною шкалою;
- вивести **таблицю** з шапкою: прізвища ліворуч, предмети згори, оцінки
  вирівняні в стовпчики;
- у стовпчику праворуч — **середній бал кожного студента** (середнє по рядку);
- у рядку знизу — **середній бал з кожного предмета** (середнє по стовпчику);
- знайти й вивести: найкращого та найгіршого студента за середнім балом;
  найвищу та найнижчу оцінку в журналі із зазначенням студента і предмета;
- порахувати, скільки студентів мають середній бал вище 9.

**Приклад роботи:**

```
=== ЖУРНАЛ ОЦІНОК ГРУПИ ПІ-21 ===

Студент          Мат   Прог  Англ  Іст   Середнє
----------------------------------------------------
Бондар А.         10    12     8     9      9,75
Гнатюк М.          7     9    11     6      8,25
Ковальчук І.      12    11    12    10     11,25
Лисенко О.         5     7     6     8      6,50
Марчук Д.          9    10     9    11      9,75
----------------------------------------------------
Середнє         8,60  9,80  9,20  8,80

=== ПІДСУМКИ ===
Найкращий студент: Ковальчук І. (11,25)
Найгірший студент: Лисенко О. (6,50)
Найвища оцінка: 12 - Бондар А., Програмування
Найнижча оцінка: 5 - Лисенко О., Математика
Найлегший предмет: Програмування (9,80)
Найважчий предмет: Математика (8,60)
Студентів із середнім вище 9: 3
```

:::tip Підказка
Розміри двовимірного масиву беріть не константами, а з самого масиву:
`grades.GetLength(0)` — кількість рядків (студентів), `grades.GetLength(1)` —
кількість стовпчиків (предметів). Тоді програма не зламається, коли ви додасте
шостого студента.

Середнє по **рядку** — зовнішній цикл по студентах, внутрішній по предметах.
Середнє по **стовпчику** — навпаки: зовнішній по предметах, внутрішній по студентах.
Це той самий масив, просто пройдений у різному порядку.

Рівні стовпчики дає вирівнювання в інтерполяції рядків: `$"{name,-16}"` притискає
текст ліворуч у полі шириною 16, а `$"{avg,8:F2}"` — праворуч, із двома знаками після
коми.
:::

**Додатково (за бажанням, на вищу оцінку):** додайте до журналу можливість «перескладання».
Знайдіть усі оцінки нижчі за 6, виведіть список боргів у форматі «студент — предмет —
оцінка», а потім створіть **копію** масиву оцінок (не друге посилання на той самий!),
у якій усі такі оцінки підняті до 6, і покажіть, як зміняться середні бали.
Поясніть у коментарі, чому тут обов'язково потрібна саме копія.
