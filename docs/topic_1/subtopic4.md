# Базові алгоритмічні структури

У 1966 році італійські математики Коррадо Бем і Джузеппе Якопіні довели теорему, яка
досі визначає вигляд усього програмного коду у світі: **будь-який алгоритм можна
записати, використовуючи лише три структури — слідування, розгалуження і повторення**.

Це сильніше твердження, ніж здається. Воно означає, що складність програми ніколи
не полягає в екзотичних конструкціях: у Windows, у браузері й у вашій першій
лабораторній роботі використані ті самі три цеглинки. Різниця — тільки в кількості
та способі їх поєднання.

Тому мета цього підрозділу проста: навчитися впізнавати ці три структури й записувати
кожну з них псевдокодом, блок-схемою та мовою C#.

## 1. Лінійний алгоритм (слідування)

**Лінійний алгоритм** — це послідовність дій, які виконуються одна за одною, згори
вниз, рівно один раз. Немає ні умов, ні повторень.

### Задача

Дано довжини двох сторін прямокутника. Знайти площу і периметр.

### Псевдокод

```
початок
    ввести a
    ввести b
    S = a * b
    P = 2 * (a + b)
    вивести S
    вивести P
кінець
```

### Структура

```
( Початок ) → ▱ввести a▱ → ▱ввести b▱ → ▭S = a*b▭ → ▭P = 2*(a+b)▭ → ▱вивести S, P▱ → ( Кінець )
```

### Реалізація на C#

```csharp
double a = double.Parse(Console.ReadLine());
double b = double.Parse(Console.ReadLine());

double s = a * b;
double p = 2 * (a + b);

Console.WriteLine($"Площа: {s}");
Console.WriteLine($"Периметр: {p}");
```

### Що важливо

Порядок дій у лінійному алгоритмі не довільний. Рядок `S = a * b` не можна поставити
перед введенням `a` — на момент обчислення змінна ще не має значення. Це правило
називається **залежністю за даними**: дія, яка використовує значення, має стояти після
дії, яка це значення задає.

:::note
Лінійних алгоритмів у чистому вигляді в реальних програмах майже не буває — вони
завжди є частиною більшої структури. Але будь-яка гілка розгалуження і будь-яке тіло
циклу всередині — це лінійна ділянка.
:::

## 2. Розгалужений алгоритм (розгалуження)

**Розгалуження** — структура, у якій залежно від істинності умови виконується одна
з кількох гілок. Це те, що дає програмі здатність «приймати рішення».

### Форми розгалуження

#### Повне розгалуження (if / else)

Виконується одна з двох гілок — третього не дано.

```
якщо умова то
    дія 1
інакше
    дія 2
```

```csharp
if (умова)
{
    // дія 1
}
else
{
    // дія 2
}
```

#### Неповне розгалуження (if)

Якщо умова хибна — не робиться нічого, алгоритм просто йде далі.

```
якщо умова то
    дія
```

```csharp
if (умова)
{
    // дія
}
```

#### Множинний вибір (if / else if / switch)

Коли варіантів більше двох.

```
якщо умова 1 то
    дія 1
інакше якщо умова 2 то
    дія 2
інакше
    дія 3
```

### Задача

Дано ціле число. Визначити, парне воно чи непарне.

### Псевдокод

```
початок
    ввести n
    якщо остача від ділення n на 2 дорівнює 0 то
        вивести "Парне"
    інакше
        вивести "Непарне"
кінець
```

### Реалізація на C#

```csharp
int n = int.Parse(Console.ReadLine());

if (n % 2 == 0)
{
    Console.WriteLine("Парне");
}
else
{
    Console.WriteLine("Непарне");
}
```

Оператор `%` повертає остачу від ділення — саме те, що в псевдокоді записано словами.

### Задача складніша: розв'язання квадратного рівняння

Тут розгалуження вкладене одне в одне — типова ситуація в реальних задачах.

```
початок
    ввести a, b, c
    якщо a = 0 то
        вивести "Це не квадратне рівняння"
        кінець
    D = b * b - 4 * a * c
    якщо D > 0 то
        x1 = (-b + корінь(D)) / (2 * a)
        x2 = (-b - корінь(D)) / (2 * a)
        вивести x1, x2
    інакше якщо D = 0 то
        x = -b / (2 * a)
        вивести x
    інакше
        вивести "Дійсних коренів немає"
кінець
```

```csharp
double a = double.Parse(Console.ReadLine());
double b = double.Parse(Console.ReadLine());
double c = double.Parse(Console.ReadLine());

if (a == 0)
{
    Console.WriteLine("Це не квадратне рівняння");
    return;
}

double d = b * b - 4 * a * c;

if (d > 0)
{
    double x1 = (-b + Math.Sqrt(d)) / (2 * a);
    double x2 = (-b - Math.Sqrt(d)) / (2 * a);
    Console.WriteLine($"x1 = {x1}, x2 = {x2}");
}
else if (d == 0)
{
    double x = -b / (2 * a);
    Console.WriteLine($"x = {x}");
}
else
{
    Console.WriteLine("Дійсних коренів немає");
}
```

Зверніть увагу на **перевірку `a = 0` на самому початку**. Без неї при `a = 0` програма
поділить на нуль. Такі перевірки на початку алгоритму називають **захисними умовами**,
і саме вони відрізняють робочу програму від навчальної.

:::warning
Умова `d == 0` для дійсних чисел — небезпечний прийом: через похибки представлення
дробових чисел дискримінант майже ніколи не дорівнює точному нулю. У реальному коді
пишуть `Math.Abs(d) < 1e-9`. Зараз запам'ятайте сам факт — детально повернемося до
нього в темі про типи даних.
:::

## 3. Циклічний алгоритм (повторення)

**Цикл** — структура, у якій група дій виконується кілька разів. Дії всередині циклу
називають **тілом циклу**, одне виконання тіла — **ітерацією**.

Цикл — це те, заради чого існують комп'ютери. Людина не може виконати мільйон операцій,
а машина виконує їх саме тому, що ці операції описані одним циклом на три рядки.

### Три види циклів

| Вид | Коли застосовують | Скільки разів виконається тіло |
|-----|-------------------|--------------------------------|
| **З лічильником** (`for`) | Кількість повторень відома заздалегідь | Рівно стільки, скільки задано |
| **З передумовою** (`while`) | Кількість наперед невідома, залежить від умови | 0 або більше |
| **З післяумовою** (`do…while`) | Тіло має виконатися хоча б раз | 1 або більше |

### Цикл з лічильником

**Задача:** вивести квадрати чисел від 1 до `n`.

```
початок
    ввести n
    для i від 1 до n
        вивести i * i
кінець
```

```csharp
int n = int.Parse(Console.ReadLine());

for (int i = 1; i <= n; i++)
{
    Console.WriteLine(i * i);
}
```

У заголовку `for` три частини, розділені крапкою з комою: початкове значення
(`int i = 1`), умова продовження (`i <= n`) і крок (`i++`). Це і є шестикутник
з блок-схеми, розкладений на складові.

### Цикл з передумовою

**Задача:** знайти суму цифр натурального числа.

Скільки цифр у числі, ми заздалегідь не знаємо — отже, лічильник тут не підходить.

```
початок
    ввести n
    s = 0
    поки n > 0
        s = s + остача від ділення n на 10   // остання цифра
        n = n / 10 (націло)                  // відкидаємо останню цифру
    вивести s
кінець
```

```csharp
int n = int.Parse(Console.ReadLine());
int s = 0;

while (n > 0)
{
    s = s + n % 10;   // остання цифра
    n = n / 10;       // цілочисельне ділення відкидає останню цифру
}

Console.WriteLine(s);
```

Протрасуємо для `n = 493`:

| Ітерація | n на вході | n % 10 | s після | n після |
|----------|-----------|--------|---------|---------|
| 1 | 493 | 3 | 3 | 49 |
| 2 | 49 | 9 | 12 | 4 |
| 3 | 4 | 4 | 16 | 0 |
| — | 0 | умова хибна, вихід | 16 | 0 |

Результат `16` = 4 + 9 + 3. Правильно.

Зверніть увагу на рядок `n = n / 10` — це і є та дія, що наближає цикл до завершення.
Прибрати її означає отримати нескінченний цикл.

### Цикл з післяумовою

**Задача:** просити користувача ввести додатне число, доки він не введе додатне.

Спитати треба **хоча б один раз** — це рівно та ситуація, для якої існує `do…while`.

```
початок
    повторювати
        ввести n
    поки n <= 0
    вивести "Прийнято: ", n
кінець
```

```csharp
int n;

do
{
    Console.Write("Введіть додатне число: ");
    n = int.Parse(Console.ReadLine());
}
while (n <= 0);

Console.WriteLine($"Прийнято: {n}");
```

:::note[Як обрати вид циклу]
Поставте собі два питання:

1. **Чи знаю я заздалегідь кількість повторень?** Якщо так — `for`.
2. **Якщо ні: чи має тіло виконатися хоча б раз?** Якщо так — `do…while`, якщо ні — `while`.

Технічно будь-який із трьох циклів можна виразити через будь-який інший, але
код, написаний «не тим» циклом, читається помітно гірше.
:::

## Поєднання структур

У реальних задачах структури вкладаються одна в одну. Класичний приклад — **цикл
із розгалуженням усередині**.

**Задача:** дано `n` чисел. Порахувати, скільки серед них додатних.

```
початок
    ввести n
    k = 0                           // лічильник додатних
    для i від 1 до n
        ввести x
        якщо x > 0 то
            k = k + 1
    вивести k
кінець
```

```csharp
int n = int.Parse(Console.ReadLine());
int k = 0;                          // лічильник додатних

for (int i = 1; i <= n; i++)
{
    int x = int.Parse(Console.ReadLine());

    if (x > 0)
    {
        k++;
    }
}

Console.WriteLine(k);
```

Тут видно обидва прийоми, які зустрінуться вам у сотнях задач:

- **лічильник** (`k`) — змінна, яку обнуляють до циклу і збільшують усередині
  за виконання умови;
- **накопичувач** — та сама ідея, але замість `k + 1` додається саме значення
  (`s = s + x`), щоб отримати суму.

Обидві змінні **обов'язково ініціалізуються до циклу**. Якщо оголосити `k` усередині
тіла, лічильник обнулятиметься на кожній ітерації, і відповідь завжди буде 0 або 1 —
класична помилка, яку компілятор не виявить.

:::tip[Універсальна схема задач «обробити N значень»]
```
підготувати результат (s = 0 або k = 0)
цикл по всіх значеннях
    отримати чергове значення
    якщо воно нас цікавить
        оновити результат
вивести результат
```
Під цю схему підпадають: сума, кількість, середнє, максимум, мінімум, пошук —
тобто більшість задач першого семестру.
:::

## Зведена таблиця

| Структура | Псевдокод | C# | Фігура на схемі |
|-----------|-----------|-----|-----------------|
| Слідування | дії одна за одною | `;` між операторами | Ланцюжок прямокутників |
| Повне розгалуження | `якщо…то…інакше` | `if…else` | Ромб з двома гілками |
| Неповне розгалуження | `якщо…то` | `if` | Ромб, гілка «ні» йде в обхід |
| Множинний вибір | `якщо…інакше якщо…` | `else if`, `switch` | Ланцюжок ромбів |
| Цикл з лічильником | `для i від 1 до n` | `for` | Шестикутник |
| Цикл з передумовою | `поки умова` | `while` | Ромб на вході + стрілка назад |
| Цикл з післяумовою | `повторювати…поки` | `do…while` | Ромб на виході + стрілка назад |

## Висновок

- За теоремою Бема-Якопіні будь-який алгоритм будується з трьох структур:
  **слідування, розгалуження, повторення**.
- **Лінійний** алгоритм виконує дії по черзі; порядок визначається залежністю за даними.
- **Розгалуження** буває повним (`if/else`), неповним (`if`) і множинним (`else if`);
  захисні умови на початку алгоритму запобігають некоректним даним.
- **Цикли** бувають з лічильником, з передумовою і з післяумовою; вид обирають за тим,
  чи відома кількість повторень і чи має тіло виконатися хоча б раз.
- Структури **вкладаються** одна в одну; більшість навчальних задач зводиться до
  схеми «лічильник/накопичувач + цикл + умова всередині».
