# Самоперевірка та домашнє завдання

## Питання для самоперевірки

Питання згруповані за підрозділами теми. Відповідайте своїми словами — якщо не виходить,
поверніться до відповідного підрозділу.

### Поняття змінної. Системні типи даних

1. Назвіть три характеристики будь-якої змінної в C#. Чим оголошення змінної відрізняється
   від її ініціалізації? Яке значення за замовчуванням мають числові типи, `bool` і `char`,
   і чим запис `int i = default;` відрізняється від `int i = default(int);`?
2. `byte` і `sbyte` займають однакові 8 біт, але один зберігає числа від 0 до 255,
   а другий — від -128 до 127. Поясніть, куди дівається «половина» діапазону.
3. Порівняйте `float`, `double` і `decimal` за розміром і точністю. Чому для зберігання
   ціни товару в гривнях обирають `decimal`, а не `double`?

### Неявно типізовані змінні

4. Що таке неявно типізована змінна? Чому рядок `var x;` не скомпілюється, а
   `var x = 5;` — скомпілюється? Чи означає `var`, що тип змінної потім можна змінити?

### Області видимості змінних

5. Назвіть види областей видимості з підрозділу. Чому змінна, оголошена всередині блока `if`,
   недоступна після закриття цього блока?
6. Чому цей код не скомпілюється і як його виправити двома різними способами?

    ```csharp
    for (int i = 0; i < 3; i++)
    {
        int total = i * 10;
    }
    Console.WriteLine(total);
    ```

### Ієрархія класів для типів даних і операція new

7. Намалюйте ієрархію типів C# від `System.Object` до `int`. Чому навіть у звичайного
   цілого числа можна викликати `ToString()` і `GetType()`?
8. Що робить операція `new` і де вона виділяє пам'ять? Чому для `int` писати `new`
   не обов'язково, а для об'єкта класу — обов'язково?

### Робота з рядковими даними та керуючі послідовності

9. Що означає «рядки в C# незмінні»? Опишіть, що насправді відбувається в пам'яті
   під час виконання рядка `text = text + "!";`.
10. Що виведе цей код? Пам'ятайте, що `Substring` приймає початковий індекс і довжину.

    ```csharp
    string s = "Програмування";
    Console.WriteLine(s.Length);
    Console.WriteLine(s.Substring(0, 5).ToUpper());
    Console.WriteLine(s.IndexOf('а'));
    ```

11. Навіщо потрібні керуючі послідовності? Чому шлях до файлу доводиться писати
    як `"C:\\Program Files"`, і як вербатим-рядок позбавляє від цієї мороки?

### Перетворення типів. Перевірка переповнення

12. Чим розширення типу відрізняється від звуження? Чому перетворення `int` у `long`
    компілятор виконує сам, а `double` у `int` вимагає явного приведення?
13. Що виведе цей код і чому саме таке число?

    ```csharp
    int large = 260;
    byte small = (byte)large;
    Console.WriteLine(small);
    ```

14. Для чого потрібні блоки `checked` і `unchecked`? Який із них ви поставили б у програмі
    підрахунку грошей на рахунку і чому?

### Операції в C#

15. Що виведе цей код? Розпишіть покроково, що відбувається зі змінною `x`.

    ```csharp
    int x = 5;
    int y = x++ + ++x;
    Console.WriteLine($"x = {x}, y = {y}");
    ```

16. Що виведе кожен із трьох рядків? Поясніть різницю між першим і другим.

    ```csharp
    int a = 7;
    int b = 2;
    Console.WriteLine(a / b);
    Console.WriteLine((double)a / b);
    Console.WriteLine(a % b);
    ```

    Заодно поясніть, чому вираз `5 + 2 * 3` дорівнює 11, а не 21, і перепишіть
    за допомогою тернарного оператора конструкцію, яка обирає більше з двох чисел.

### Побітові операції

17. Що виведе цей код? Розпишіть кожну операцію в двійковому вигляді.

    ```csharp
    int value = 12;   // 1100
    int mask = 5;     // 0101
    Console.WriteLine(value & mask);
    Console.WriteLine(value | mask);
    Console.WriteLine(value ^ mask);
    ```

18. Чому `x << 1` дає той самий результат, що й множення на 2? Як за допомогою `&` перевірити,
    чи увімкнено певний прапорець, а за допомогою `|=` і `&= ~` — увімкнути й вимкнути його?

### Стек, куча, значимі та посилальні типи

19. Заповніть із пам'яті таблицю порівняння стека і кучі за п'ятьма ознаками. Коли виникає
    `StackOverflowException` і що зазвичай є її причиною?
20. Що виведе цей код і чому два схожі присвоєння поводяться по-різному?

    ```csharp
    int a = 10;
    int b = a;
    b = 20;

    int[] first = { 1, 2, 3 };
    int[] second = first;
    second[0] = 99;

    Console.WriteLine($"{a} {first[0]}");
    ```

    Що таке boxing і unboxing і в якому з двох присвоєнь вище нічого подібного не відбувається?
    Навіщо потрібні nullable значимі типи і як безпечно прочитати значення зі змінної `int?`.

## Практичні міні-задачі

Короткі вправи на 5–10 хвилин кожна, для перевірки розуміння прямо після лекції.

1. **Межі типів.** Виведіть у консоль `MinValue` і `MaxValue` для `byte`, `short`, `int`
   і `long`. Порівняйте з таблицею з лекції та переконайтеся, що числа збігаються.

2. **Переповнення під контролем.** Напишіть два фрагменти: один у блоці `unchecked`,
   другий у `checked`, які множать `100000 * 100000` у змінній типу `int`. Перший
   має вивести неправильне число, другий — перехопити `OverflowException`
   і вивести зрозуміле повідомлення.

3. **Ділення, що обманює.** Обчисліть середнє арифметичне чисел 7, 8 і 10 двома способами:
   через `int` і через `double`. Поясніть у коментарі, звідки взялася різниця
   і в якому місці треба поставити приведення типу.

4. **Рядок під мікроскопом.** Для рядка `"   Основи програмування   "` виведіть довжину
   до і після `Trim()`, індекс першого пробілу після обрізання та останні п'ять символів.

5. **Прапорці налаштувань.** Оголосіть три маски: 1, 2 і 4 (звук, відео, повний екран).
   Увімкніть звук і повний екран одним числом, виведіть його, потім вимкніть звук
   і перевірте за допомогою `&`, які прапорці лишилися.

6. **Значення чи посилання.** Напишіть два методи: один приймає `int` і збільшує його
   на 10, другий приймає масив `int[]` і збільшує на 10 його перший елемент.
   Викличте обидва й покажіть у консолі, чому оригінали змінилися по-різному.

7. **`Parse` проти `TryParse`.** Напишіть програму, що просить увести число і виводить
   його квадрат. Спочатку використайте `int.Parse` і введіть слово замість числа —
   запишіть текст помилки. Потім перепишіть через `int.TryParse` так, щоб програма
   не падала, а просила ввести ще раз.

8. **Коли `var` шкодить.** Для кожного рядка скажіть, чи доречний тут `var`,
   і поясніть чому:

   ```csharp
   var count = 10;
   var data = new Dictionary<string, List<int>>();
   var result = Calculate();
   var average = total / count;
   ```

9. **Пастка з `var` і діленням.** Що виведе цей код і як це виправити?

   ```csharp
   var total = 7;
   var count = 2;
   var average = total / count;
   Console.WriteLine(average);
   ```

10. **Незмінність рядків.** Виміряйте час склеювання 50 000 рядків через `+=`
    і через `StringBuilder` (скористайтеся `System.Diagnostics.Stopwatch`).
    Запишіть обидва результати й поясніть різницю.

11. **`null` чи порожньо.** Що виведе кожен рядок і де буде виняток?

    ```csharp
    string a = "";
    string b = null;

    Console.WriteLine(a.Length);
    Console.WriteLine(string.IsNullOrEmpty(a));
    Console.WriteLine(b.Length);
    ```

12. **Nullable у дії.** Оголосіть `int? mark` для оцінки студента, який ще не складав
    іспит. Виведіть «Не складав», якщо значення відсутнє, і саму оцінку — якщо є.
    Потім перепишіть виведення через оператор `??`.

13. **Округлення чи відкидання.** Для значення `9.7` виведіть результат `(int)value`
    і `Convert.ToInt32(value)`. Поясніть, чому числа різні й коли ця різниця
    може зіпсувати розрахунок.

## Домашнє завдання

:::info[Що здавати]
Один консольний проєкт (або один файл `.cs`) + скриншот роботи програми.
Орієнтовний час виконання — 30–45 хвилин.
:::

### Завдання: «Кишеньковий калькулятор ІМТ»

Ви робите маленький калькулятор індексу маси тіла — той самий, що показують у спортзалах.
Користувач вводить зріст у сантиметрах і вагу в кілограмах, програма рахує ІМТ
за формулою «вага поділена на квадрат зросту в метрах» і показує акуратну картку
з результатом та категорією.

Задача виглядає простою, але саме на ній найлегше спіймати всі три класичні помилки
з цієї теми: цілочисельне ділення там, де треба дробове, втрату дробової частини
під час приведення типів і нечитабельне число з десятьма знаками після коми.

**Вимоги:**

- зріст зчитувати як ціле число сантиметрів, вагу — як дробове;
- перевести сантиметри в метри та обчислити ІМТ; результат вивести
  з **одним знаком після коми**;
- визначити категорію за значенням ІМТ і вивести її словами:
  менше 18,5 — «недостатня вага», від 18,5 до 24,9 — «норма»,
  від 25 до 29,9 — «надлишкова вага», 30 і більше — «ожиріння»;
- вивести також **ідеальну вагу** для цього зросту (ІМТ, що дорівнює 22)
  і різницю з поточною вагою — з відповідним знаком;
- вивести окремим рядком зріст у різних одиницях: сантиметри (ціле число),
  метри (два знаки після коми) і дюйми (один знак після коми, 1 дюйм — 2,54 см);
- у коментарях біля кожної змінної пояснити, чому обрано саме такий тип.

**Приклад роботи:**

```
=== КАЛЬКУЛЯТОР ІМТ ===
Введіть зріст у сантиметрах: 176
Введіть вагу в кілограмах: 68,5

--------------------------------
 Зріст : 176 см = 1,76 м = 69,3 дюйма
 Вага  : 68,5 кг
 ІМТ   : 22,1
 Стан  : норма
--------------------------------
 Ідеальна вага для вашого зросту: 68,1 кг
 Різниця: +0,4 кг
--------------------------------
```

:::tip[Підказка]
Головна пастка — цілочисельне ділення. Якщо написати `height / 100`, де `height` має тип
`int`, ви отримаєте 1 замість 1,76. Або оголошуйте змінну для метрів як `double`
і діліть на `100.0`, або приводьте явно: `(double)height / 100`.

Для зчитування дробового числа знадобиться `double.Parse(Console.ReadLine())`. Зверніть увагу,
що в українській локалізації роздільником є **кома**, а не крапка — вводьте `68,5`.

Один знак після коми дає специфікатор формату `F1`: `$"ІМТ: {bmi:F1}"`.
:::

**Додатково (за бажанням, на вищу оцінку):** додайте перевірку введених даних без падіння
програми — якщо зріст або вага виявилися недодатними чи неправдоподібними (зріст менший
за 50 см або більший за 250 см), виведіть зрозуміле повідомлення замість розрахунку.
Обчислення ІМТ при цьому загорніть у блок `checked`.
