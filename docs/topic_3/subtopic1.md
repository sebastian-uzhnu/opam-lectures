# Змінні та типи даних

Змінна — це найменша цеглинка будь-якої програми. Усе, що програма робить, вона робить
зі значеннями, які десь зберігаються, і саме змінні дають цим значенням імена.

## Поняття змінної

**Змінна** — це іменована область пам'яті, у якій зберігається значення певного типу.

Уявіть камеру схову на вокзалі. Комірка має **номер** (ім'я змінної), певний **розмір**
(тип), і в ній щось **лежить** (значення). Ви звертаєтеся до вмісту за номером комірки,
не думаючи про те, де фізично вона розташована.

У змінної три характеристики:

| Характеристика | Що це | Приклад |
|----------------|-------|---------|
| **Ім'я** | Ідентифікатор для звернення | `age` |
| **Тип** | Які значення можна зберігати і які операції дозволені | `int` |
| **Значення** | Те, що зберігається зараз | `25` |

## Оголошення та ініціалізація

**Оголошення** — повідомлення компілятору, що така змінна існує:

```csharp
int age;            // оголошення
```

**Ініціалізація** — перше присвоєння значення:

```csharp
age = 25;           // ініціалізація
```

Найчастіше це роблять одночасно:

```csharp
int age = 25;       // оголошення з ініціалізацією
```

Значення можна змінювати скільки завгодно разів — звідси й назва «змінна»:

```csharp
int age = 25;
age = 30;           // тепер 30
age = age + 1;      // тепер 31
```

:::warning[Використання неініціалізованої змінної]
```csharp
int x;
Console.WriteLine(x);   // ❌ помилка компіляції:
                        // Use of unassigned local variable 'x'
```

C# не дозволяє читати локальну змінну, якій жодного разу не присвоїли значення.
У C++ такий код скомпілюється й виведе випадкове сміття з пам'яті — ще один випадок,
коли строгість C# рятує від важковловимої помилки.
:::

### Кілька змінних одного типу

```csharp
int a = 1, b = 2, c = 3;      // допустимо, але читається гірше
```

### Константи

Якщо значення не має змінюватися ніколи, оголошуйте його як `const`:

```csharp
const double Pi = 3.14159;
const int MaxStudents = 30;

Pi = 3;     // ❌ помилка компіляції: неможливо змінити константу
```

:::tip
Константи прибирають із коду «магічні числа». Порівняйте:

```csharp
if (count > 30) { ... }                  // 30 — це що?
if (count > MaxStudents) { ... }         // ✅ зрозуміло без пояснень
```

Крім читабельності, це економить час: щоб змінити граничне значення, достатньо
виправити одне місце, а не шукати `30` по всьому файлу.
:::

## Системні типи даних

Кожне ключове слово типу в C# — це псевдонім до типу зі стандартної бібліотеки .NET:

```csharp
int number = 5;             // те саме, що
System.Int32 number2 = 5;   // ось це
```

Обидва записи рівноцінні, але пишуть завжди перший.

| Ключове слово | Системний тип | Група |
|---------------|---------------|-------|
| `int` | `System.Int32` | Ціле |
| `long` | `System.Int64` | Ціле |
| `double` | `System.Double` | Дійсне |
| `decimal` | `System.Decimal` | Дійсне |
| `bool` | `System.Boolean` | Логічне |
| `char` | `System.Char` | Символ |
| `string` | `System.String` | Рядок |

### Цілі числові типи

| Тип | Розмір (біт) | Діапазон | Signed / Unsigned |
|-----|--------------|----------|-------------------|
| `sbyte` | 8 | −128 … 127 | signed |
| `byte` | 8 | 0 … 255 | unsigned |
| `short` | 16 | −32 768 … 32 767 | signed |
| `ushort` | 16 | 0 … 65 535 | unsigned |
| `int` | 32 | −2 147 483 648 … 2 147 483 647 | signed |
| `uint` | 32 | 0 … 4 294 967 295 | unsigned |
| `long` | 64 | ±9,2 · 10¹⁸ | signed |
| `ulong` | 64 | 0 … 1,8 · 10¹⁹ | unsigned |

> **Signed** зберігає додатні й від'ємні числа, **unsigned** — лише додатні,
> зате вдвічі більший максимум за тієї самої розрядності.

Звідки беруться ці діапазони — розібрано в темі 2: `N` бітів дають `2^N` комбінацій.

### Числа з плаваючою комою

| Тип | Розмір (біт) | Точність | Призначення |
|-----|--------------|----------|-------------|
| `float` | 32 | ~7 знаків | Графіка, ігри |
| `double` | 64 | ~15–16 знаків | Типовий вибір |
| `decimal` | 128 | ~28–29 знаків | Фінанси |

```csharp
float f = 3.14f;        // суфікс f обов'язковий
double d = 3.14;        // за замовчуванням
decimal m = 3.14m;      // суфікс m обов'язковий
```

:::warning
Для грошей — **тільки `decimal`**. `double` зберігає числа наближено, тому
`0.1 + 0.2 != 0.3`, і в фінансових розрахунках така похибка накопичується.
:::

### Логічний і символьний типи

| Тип | Значення |
|-----|----------|
| `bool` | `true` або `false` |
| `char` | Один символ Unicode (UTF-16) |

### Посилальні типи

| Тип | Опис |
|-----|------|
| `object` | Базовий тип для всіх типів у C# |
| `string` | Послідовність символів |
| `dynamic` | Тип визначається під час виконання |

:::note[`string` — не примітив]
`string` виглядає як простий тип, але технічно це клас `System.String`, тобто
**посилальний** тип. Він поводиться незвично для посилального типу — про це
детально у підрозділі про рядки та в підрозділі про значимі й посилальні типи.
:::

## Значення за замовчуванням

Кожен тип має значення за замовчуванням, яке присвоюється, якщо явного немає
(наприклад, полям класу або елементам масиву):

| Група типів | Значення |
|-------------|----------|
| Числові (`int`, `double`, …) | `0` |
| `bool` | `false` |
| `char` | `'\0'` |
| Посилальні (`string`, класи) | `null` |

```csharp
int i = default;        // 0
bool b = default;       // false
string s = default;     // null

int[] numbers = new int[3];
Console.WriteLine(numbers[0]);   // 0 — елементи масиву вже ініціалізовані
```

:::note
Запис `default(int)` — старий синтаксис, який працює досі. З C# 7.1 тип можна
не вказувати: просто `default`, якщо він зрозумілий із контексту.
:::

## Як обрати тип

| Що зберігаємо | Тип |
|---------------|-----|
| Вік, кількість, індекс | `int` |
| Дуже велике ціле (ID, мітка часу) | `long` |
| Середнє, вимірювання, відсоток | `double` |
| Гроші, ціна | `decimal` |
| Одна літера, оцінка | `char` |
| Ім'я, текст | `string` |
| Так/ні, прапорець | `bool` |

:::tip
Не оптимізуйте передчасно. Спокуса взяти `short` замість `int` заради економії
2 байтів не має сенсу для окремої змінної — процесор однаково працює з 32-бітними
значеннями найшвидше. Економія важлива лише в масивах на мільйони елементів.
:::

## Висновок

- **Змінна** — іменована область пам'яті; має ім'я, тип і значення.
- **Оголошення** створює змінну, **ініціалізація** дає їй перше значення;
  читати неініціалізовану локальну змінну C# забороняє.
- **`const`** оголошує значення, яке не можна змінити — це прибирає з коду
  «магічні числа».
- Ключові слова типів (`int`, `string`) — псевдоніми до системних типів
  (`System.Int32`, `System.String`).
- Кожен тип має **значення за замовчуванням**: `0` для чисел, `false` для `bool`,
  `null` для посилальних.
- `string` виглядає примітивом, але є **посилальним** типом.
