# Класифікація операцій та даних

Операція (оператор) — це дія над одним або кількома значеннями. Значення, над якими
виконується дія, називають **операндами**.

```csharp
int sum = 5 + 3;
//        ↑   ↑
//    операнд операнд
//          ↑
//      операція
```

За кількістю операндів операції поділяють на:

| Вид | Операндів | Приклад |
|-----|-----------|---------|
| **Унарні** | 1 | `-x`, `!flag`, `i++` |
| **Бінарні** | 2 | `a + b`, `a > b` |
| **Тернарна** | 3 | `a > b ? a : b` |

## Арифметичні операції

| Операція | Дія | Приклад | Результат |
|----------|-----|---------|-----------|
| `+` | Додавання | `7 + 3` | `10` |
| `-` | Віднімання | `7 - 3` | `4` |
| `*` | Множення | `7 * 3` | `21` |
| `/` | Ділення | `7 / 3` | `2` ⚠️ |
| `%` | Остача від ділення | `7 % 3` | `1` |

### Пастка цілочисельного ділення

```csharp
int a = 7;
int b = 3;

Console.WriteLine(a / b);   // 2, а не 2.333
```

Якщо **обидва** операнди цілі, C# виконує **цілочисельне ділення**: дробова частина
просто відкидається (не округлюється!). Щоб отримати дріб, хоча б один операнд
має бути дійсним:

```csharp
Console.WriteLine(7 / 3);           // 2      обидва int
Console.WriteLine(7.0 / 3);         // 2.333  один double
Console.WriteLine((double)a / b);   // 2.333  явне перетворення
```

:::warning
Це найпоширеніша логічна помилка першого семестру. Програма рахує середній бал
як `sum / count`, обидві змінні `int`, і середнє 4.8 перетворюється на 4.
Компілятор мовчить — усе «правильно» з точки зору типів.
:::

### Навіщо потрібна остача `%`

Операція `%` виглядає екзотично, але застосовується постійно:

```csharp
// Парність
bool isEven = (n % 2 == 0);

// Остання цифра числа
int lastDigit = n % 10;

// Кожен третій елемент
if (i % 3 == 0) { /* ... */ }

// Перевести секунди у хвилини й секунди
int minutes = totalSeconds / 60;
int seconds = totalSeconds % 60;
```

:::note
Ділення на нуль поводиться по-різному залежно від типу:

```csharp
int x = 5 / 0;        // ❌ виняток DivideByZeroException — програма падає
double y = 5.0 / 0;   // Infinity — програма працює далі
double z = 0.0 / 0;   // NaN (Not a Number)
```
:::

### Інкремент і декремент

```csharp
int i = 5;

i++;    // збільшити на 1 → 6
i--;    // зменшити на 1  → 5
```

Є два варіанти запису, і різниця між ними проявляється, коли результат одразу
використовують:

```csharp
int a = 5;
int b = a++;    // ПОСТфікс: спочатку віддати значення, потім збільшити
                // b = 5, a = 6

int c = 5;
int d = ++c;    // ПРЕфікс: спочатку збільшити, потім віддати
                // d = 6, c = 6
```

:::tip
Якщо `i++` стоїть окремою інструкцією (як у заголовку циклу `for`), різниці немає —
пишіть `i++` і не думайте. Різниця виникає лише тоді, коли ви одночасно
збільшуєте змінну й використовуєте її значення, а так робити взагалі не варто:
код стає важко читати.
:::

## Операції порівняння

Повертають **завжди** `bool` — `true` або `false`.

| Операція | Значення | Приклад |
|----------|----------|---------|
| `==` | Дорівнює | `a == b` |
| `!=` | Не дорівнює | `a != b` |
| `>` | Більше | `a > b` |
| `<` | Менше | `a < b` |
| `>=` | Більше або дорівнює | `a >= b` |
| `<=` | Менше або дорівнює | `a <= b` |

```csharp
int age = 20;

bool isAdult = age >= 18;       // true
Console.WriteLine(isAdult);     // True
```

:::warning[`=` проти `==`]
`=` — **присвоєння** (записати значення).
`==` — **порівняння** (перевірити рівність).

```csharp
if (a = 5)    // ❌ помилка компіляції: присвоєння замість порівняння
if (a == 5)   // ✅
```

У C# цю помилку ловить компілятор, бо `if` вимагає саме `bool`. У C++ той самий
код скомпілюється й працюватиме неправильно — вважайте, що вам пощастило з мовою.
:::

:::note[Порівняння дійсних чисел]
```csharp
double x = 0.1 + 0.2;
Console.WriteLine(x == 0.3);       // False (!)
Console.WriteLine(x);              // 0.30000000000000004
```

Дробові числа зберігаються наближено, тому `double` майже ніколи не можна порівнювати
через `==`. Порівнюють різницю з малим допуском:

```csharp
Console.WriteLine(Math.Abs(x - 0.3) < 1e-9);   // True
```
:::

## Логічні операції

Працюють з `bool` і повертають `bool`.

| Операція | Назва | Результат `true`, коли |
|----------|-------|------------------------|
| `&&` | І (AND) | Обидва операнди `true` |
| `\|\|` | АБО (OR) | Хоча б один `true` |
| `!` | НЕ (NOT) | Операнд `false` |

```csharp
int age = 20;
bool hasPassport = true;

bool canVote = age >= 18 && hasPassport;    // true
bool isChild = !(age >= 18);                // false
```

Таблиця істинності:

| `a` | `b` | `a && b` | `a \|\| b` | `!a` |
|-----|-----|----------|------------|------|
| true | true | true | true | false |
| true | false | false | true | false |
| false | true | false | true | true |
| false | false | false | false | true |

:::tip[Скорочене обчислення]
`&&` і `||` обчислюють другий операнд **тільки за потреби**:

```csharp
if (count != 0 && sum / count > 5)
```

Якщо `count == 0`, перша умова хибна, і друга **не обчислюється** — ділення на нуль
не станеться. Саме тому перевірку завжди ставлять **перед** небезпечною дією.
:::

## Операції присвоєння

| Операція | Еквівалент |
|----------|------------|
| `a = 5` | Записати 5 |
| `a += 3` | `a = a + 3` |
| `a -= 3` | `a = a - 3` |
| `a *= 2` | `a = a * 2` |
| `a /= 2` | `a = a / 2` |
| `a %= 2` | `a = a % 2` |

```csharp
int total = 0;
total += 10;    // 10
total += 5;     // 15
total *= 2;     // 30
```

## Тернарна операція

Скорочений запис `if/else`, що повертає значення:

```csharp
// Довго
int max;
if (a > b)
    max = a;
else
    max = b;

// Коротко — те саме
int max = a > b ? a : b;
```

Читається так: «умова ? що_якщо_true : що_якщо_false».

```csharp
string result = (n % 2 == 0) ? "парне" : "непарне";
Console.WriteLine($"Число {n} — {result}");
```

## Пріоритет операцій

Операції виконуються не зліва направо, а за **пріоритетом** — як у математиці.

| Пріоритет | Операції |
|-----------|----------|
| 1 (найвищий) | `()` — дужки |
| 2 | `!`, `++`, `--`, унарний `-` |
| 3 | `*`, `/`, `%` |
| 4 | `+`, `-` |
| 5 | `<`, `>`, `<=`, `>=` |
| 6 | `==`, `!=` |
| 7 | `&&` |
| 8 | `\|\|` |
| 9 (найнижчий) | `=`, `+=`, `-=` … |

```csharp
int result = 2 + 3 * 4;       // 14, а не 20 — множення першим
int result2 = (2 + 3) * 4;    // 20 — дужки змінили порядок
```

:::tip
Не заучуйте таблицю. **Ставте дужки**, коли вираз складніший за два операнди —
це безкоштовно, а код стає однозначним для читача:

```csharp
if (a > 0 && (b < 10 || c == 5))
```
:::

## Класифікація даних

Типи даних у C# поділяють на дві великі групи.

### Значимі типи (value types)

Змінна містить **саме значення**. Зберігаються переважно у стеку.

- цілі: `byte`, `short`, `int`, `long`;
- дійсні: `float`, `double`, `decimal`;
- інші: `char`, `bool`;
- структури (`struct`) і перелічення (`enum`).

### Посилальні типи (reference types)

Змінна містить **посилання** (адресу) на дані, що лежать у купі.

- `string`, `object`;
- масиви, класи, інтерфейси, делегати.

Різниця проявляється при копіюванні:

```csharp
int a = 5;
int b = a;      // копія значення
b = 10;
Console.WriteLine(a);   // 5 — a не змінилася

int[] arr1 = { 1, 2, 3 };
int[] arr2 = arr1;      // копія ПОСИЛАННЯ — обидві змінні на той самий масив
arr2[0] = 99;
Console.WriteLine(arr1[0]);   // 99 (!) — змінився й arr1
```

:::note
Це одна з найважливіших відмінностей у C#, і повноцінно вона розбирається
в темі 3 разом зі стеком і купою. Поки достатньо запам'ятати сам факт:
**значимі типи копіюються, посилальні — ні**.
:::

## Висновок

- Операції бувають **унарні, бінарні й тернарна**; за призначенням — арифметичні,
  порівняння, логічні, побітові, присвоєння.
- **Цілочисельне ділення** `7 / 3` дає `2` — це джерело логічних помилок;
  для дробу потрібен хоча б один `double`.
- Операції порівняння завжди повертають `bool`; `=` — присвоєння, `==` — порівняння.
- **Дійсні числа не можна порівнювати через `==`** — тільки через різницю з допуском.
- `&&` і `||` використовують **скорочене обчислення** — це захищає від ділення на нуль.
- Порядок дій визначає **пріоритет**; дужки роблять вираз однозначним.
- Дані поділяються на **значимі** (копіюється значення) і **посилальні**
  (копіюється посилання).
