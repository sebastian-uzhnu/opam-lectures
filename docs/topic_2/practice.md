# Самоперевірка та домашнє завдання

## Питання для самоперевірки

Питання згруповані за підрозділами теми. Відповідайте своїми словами — якщо не виходить,
поверніться до відповідного підрозділу.

### Загальні відомості про мову C#

1. Хто і коли створив C#? Із двох світів — простоти мов високого рівня та потужності
   низькорівневих — що саме мова взяла від кожного?
2. Що означає твердження «C# — суворо типізована мова»? Наведіть приклад дії, яку через
   це компілятор заборонить ще до запуску програми.
3. Назвіть п'ять основних характеристик C# із підрозділу. Яка з них звільняє програміста
   від ручного звільнення пам'яті та завдяки чому мова стала кросплатформною?

### Біт, байт і системи числення

4. Що таке біт і що таке байт? Скільки різних значень можна закодувати одним байтом
   і чому саме стільки?
5. Чим позиційна система числення відрізняється від непозиційної? Наведіть приклад кожної.
   Переведіть число 25 у двійкову систему і число 83 у вісімкову, показавши ділення із залишками.
6. Переведіть двійкове число 11010111 у шістнадцяткову систему. Чому біти групують саме
   по чотири, а для вісімкової системи — по три?
7. Переведіть шістнадцяткове число 1A3 у десяткову систему. Де на практиці застосовують
   шістнадцяткову систему і чому вона зручніша за двійкову для запису великих чисел?

### Алфавіт мови

8. Які групи символів входять до алфавіту мови C#? Назвіть щонайменше чотири.
   Чому ключові слова (`int`, `class`, `if`) формально не є частиною алфавіту, хоча
   складаються тільки з його символів? Чим символьний літерал `'A'` відрізняється
   від рядкового `"A"`?

### Структура програми

9. Назвіть три обов'язкові структурні елементи найпростішої програми на C# і роль кожного.
   Чому метод `Main` оголошується зі словом `static`?
10. Подивіться на код і скажіть, що він виведе:

    ```csharp
    int a = 5;
    // int b = 10;
    /* Console.WriteLine(a + b); */
    Console.WriteLine(a);
    ```

    Що станеться, якщо прибрати символи `/*` і `*/` із третього рядка, а другий залишити
    закоментованим?

11. Що виведе ця програма?

    ```csharp
    class Program
    {
        static void Main()
        {
            Console.WriteLine("Крок 1")
            Console.WriteLine("Крок 2");
        }
    }
    ```

    Відповідь «Крок 1 і Крок 2» — неправильна. Поясніть чому.

12. Для чого потрібні простори імен? Що станеться, якщо два розробники створять класи
    з однаковою назвою `Helper`, і як простори імен розв'язують цю проблему?

### Класифікація операцій та стандартні типи даних

13. Назвіть п'ять категорій операцій із підрозділу і наведіть по одному оператору з кожної.
    Чим логічне `&&` відрізняється від побітового `&`?
14. Чим значимі типи відрізняються від посилальних? До якої групи належить `string`
    і чому це може здивувати, адже він виглядає як звичайний примітив?
15. Що виведе цей код і чому?

    ```csharp
    short small = 32767;
    small++;
    Console.WriteLine(small);
    ```

16. Рядок `int distance = 5000000000;` не компілюється. Поясніть причину і запропонуйте
    два різні способи це виправити. Коли варто брати `uint` замість `int`,
    а коли це буде помилкою?

### Компіляція у C#

17. Опишіть шлях від файлу `.cs` до інструкцій, які виконує процесор. Що таке IL,
    що таке метадані і що таке збірка?
18. Чому саме завдяки IL програма на C# є портативною? Чим AOT-компіляція відрізняється
    від JIT і для яких застосунків її обирають?

### Garbage Collector

19. Що робить збирач сміття і в якій області пам'яті він працює? Поясніть, навіщо об'єкти
    ділять на покоління 0, 1 і 2 та чому покоління 0 перевіряється найчастіше.
    Чому викликати `GC.Collect()` вручну не рекомендують?

### Visual Studio

20. Чим проєкт відрізняється від рішення (solution)? Що дає Visual Studio порівняно
    з роботою в блокноті та компіляцією через `csc` вручну — назвіть три переваги
    і поясніть, для чого потрібні точки зупинки (breakpoints).

## Практичні міні-задачі

Короткі вправи на 5–10 хвилин кожна, для перевірки розуміння прямо після лекції.

1. **Ваш рік у трьох системах.** Переведіть рік свого народження з десяткової системи
   у двійкову, вісімкову та шістнадцяткову. Перевірте себе зворотним переведенням
   двійкового результату назад у десяткову.

2. **Програма по кісточках.** Створіть у Visual Studio консольний проєкт і підпишіть
   коментарем кожен рядок згенерованого шаблону: що таке `using`, що таке `namespace`,
   що таке `class`, що таке `Main`. Мета — не залишити жодного незрозумілого слова.

3. **Перший breakpoint.** У програмі з трьох рядків, де обчислюється сума двох чисел,
   поставте точку зупинки на рядку виведення, запустіть налагодження і подивіться
   значення всіх трьох змінних у вікні Locals. Запишіть, що ви побачили.

4. **Зламай і полагодь.** Візьміть робочу програму «Hello, World!» і внесіть у неї
   три помилки: приберіть крапку з комою, перейменуйте `Main` на `main`, приберіть `static`.
   Запишіть текст кожного повідомлення компілятора і те, що воно насправді означає.

5. **Межа типу.** Напишіть програму, яка виводить `short.MaxValue`, потім додає до нього
   одиницю і виводить результат. Поясніть у коментарі, чому вийшло саме таке число.

6. **Підбір типу.** Для кожної величини оберіть найекономніший з можливих типів
   і обґрунтуйте вибір: вік студента, населення Землі, температура за вікном,
   номер аудиторії, кількість байтів у відеофайлі.

## Домашнє завдання

:::info[Що здавати]
Один консольний проєкт у Visual Studio (або один файл `.cs`) + скриншот роботи програми.
Орієнтовний час виконання — 30–45 хвилин.
:::

### Завдання: «Цифрова візитівка»

Ви робите собі консольну візитівку — маленьку програму, яку не соромно показати друзям
і яка розповідає про вас у вигляді акуратної картки. Нічого вводити з клавіатури не треба:
всі дані задаються прямо в коді змінними. Головна мета — свідомо обрати тип для кожної
величини і зробити вивід охайним, а не «як вийшло».

**Вимоги:**

- створити консольний проєкт у Visual Studio, назвати його осмислено (наприклад, `BusinessCard`),
  а не залишити `ConsoleApp1`;
- використати щонайменше **п'ять різних типів даних**: `string`, `int`, `double`
  (або `decimal`), `char`, `bool`;
- серед змінних обов'язково мають бути: ім'я, рік народження, курс, середній бал,
  перша літера прізвища та ознака «чи є в мене вже досвід програмування»;
- вивести картку в рамці з символів, вирівнявши значення в колонку;
- середній бал вивести з двома знаками після коми;
- окремим рядком вивести рік народження у двійковій системі — переведіть його вручну
  і запишіть у програмі як рядок, з коментарем, як ви його отримали;
- кожну змінну супроводити коротким коментарем: чому обрано саме цей тип.

**Приклад роботи:**

```
============================================
            ЦИФРОВА ВІЗИТІВКА
============================================
 Ім'я              : Олена
 Літера прізвища   : К
 Рік народження    : 2008
 Рік у двійковій   : 11111011000
 Курс              : 2
 Середній бал      : 10,75
 Вже програмувала  : Так
============================================
   Мова: C#   Платформа: .NET 8
============================================
```

:::tip[Підказка]
Щоб вивести число з двома знаками після коми, у рядок інтерполяції додають специфікатор
формату після двокрапки: `$"Середній бал: {average:F2}"`.

Значення типу `bool` виводиться як `True` або `False`. Щоб отримати «Так» або «Ні»,
скористайтеся тернарним оператором: `hasExperience ? "Так" : "Ні"`.

Рамку зручно робити не вручну, а повторюваним рядком: збережіть його в окрему змінну
`string line` і виводьте цю змінну щоразу, коли потрібна лінія.
:::

**Додатково (за бажанням, на вищу оцінку):** додайте до картки ще один рядок — рік
народження у шістнадцятковій системі — і напишіть під кодом коментар на 2–3 речення:
як ви отримали шістнадцятковий запис із двійкового, не переводячи число заново
через десяткову систему.
