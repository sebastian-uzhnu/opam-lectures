# Загальні відомості про мову C#

Минулу тему ми закінчили на тому, що алгоритм треба комусь віддати на виконання.
Тепер обираємо виконавця — мову, якою розмовлятимемо з комп'ютером увесь наступний рік.

## Звідки взявся C#

Наприкінці 1990-х Microsoft мала проблему. Windows-розробники писали на C++ — швидко,
але кожна помилка з пам'яттю валила програму. Java була безпечнішою, але належала
конкуренту (Sun Microsystems), і спроба Microsoft зробити власну версію Java
закінчилася судовим процесом.

Рішенням стала власна мова. У 2000 році команда під керівництвом **Андерса Гейлсберга**
(того самого, хто до того створив Turbo Pascal і Delphi, а пізніше — TypeScript)
випустила **C#** разом із платформою **.NET Framework**.

Назва — музичний жарт: `C#` читається «сі дієз», тобто «на півтону вище за C».
Символ `#` візуально складається з чотирьох плюсів — натяк на «C++ ++».

### Коротка історія версій

| Рік | Версія | Що додалося важливого для нас |
|-----|--------|-------------------------------|
| 2000 | C# 1.0 | Базова мова, .NET Framework, тільки Windows |
| 2005 | C# 2.0 | Узагальнення (generics), nullable-типи |
| 2007 | C# 3.0 | `var`, LINQ, лямбда-вирази |
| 2012 | C# 5.0 | `async`/`await` — асинхронність |
| 2016 | C# 7.0 | .NET Core: Linux і macOS, справжня кросплатформність |
| 2021 | C# 10 | Глобальні `using`, file-scoped namespace |
| 2023+ | C# 12+ | Top-level statements стали стандартом для консольних програм |

:::info[Чому це важливо саме вам]
Коли ви шукатимете рішення в інтернеті, натрапите на приклади різного віку. Код 2010 року
працюватиме й сьогодні, але виглядатиме багатослівно. Далі в темі ми побачимо, як та сама
програма «Hello, World» скоротилася з 11 рядків до одного.
:::

## .NET, C# і CLR — що є що

Три слова, які студенти постійно плутають:

| Поняття | Що це | Аналогія |
|---------|-------|----------|
| **C#** | Мова програмування — синтаксис і правила | Українська мова |
| **.NET** | Платформа: бібліотеки класів + середовище виконання | Бібліотека книжок і друкарня |
| **CLR** | Common Language Runtime — те, що виконує програму | Читач, який розуміє написане |

Мова C# без .NET марна: навіть `Console.WriteLine` — це не частина мови, а клас
зі стандартної бібліотеки .NET. І навпаки, .NET не прив'язаний до C#: на ньому працюють
також F# і Visual Basic.

:::note[Плутанина в назвах]
До 2016 року платформа звалася **.NET Framework** (тільки Windows). Потім з'явився
кросплатформний **.NET Core**, а з 2020 року назви об'єднали просто в **.NET** з номером
версії: .NET 6, .NET 8, .NET 10. Якщо в статті написано «.NET Framework 4.8» — це стара
гілка, і приклади звідти можуть не працювати в сучасному проєкті.
:::

## Основні характеристики C#

### Об'єктно-орієнтованість

C# підтримує всі концепції ООП — інкапсуляцію, наслідування, поліморфізм, абстракцію.
Детально ці поняття розглянемо в темах 6–8; поки достатньо знати, що будь-який код
на C# живе всередині **класу**.

### Строга типізація

Кожна змінна має тип, відомий ще до запуску програми, і компілятор перевіряє кожну
операцію на відповідність типам.

```csharp
int age = 20;
age = "двадцять";   // ❌ помилка компіляції: неможливо перетворити string на int
```

Це здається обмеженням, але насправді це подарунок: помилка виявляється **до** запуску,
а не в найгірший момент у користувача. У мовах зі слабкою типізацією (JavaScript, Python)
такий рядок спокійно виконається, і програма зламається значно пізніше й далеко від
справжньої причини.

### Автоматичне керування пам'яттю

У C++ програміст сам виділяє й звільняє пам'ять, і забута операція звільнення —
це витік пам'яті. У C# цим займається **збирач сміття** (Garbage Collector): він сам
знаходить об'єкти, на які більше ніхто не посилається, і звільняє їх.

Детально механізм розберемо наприкінці теми — спочатку потрібні базові поняття.

### Кросплатформність

Сучасний .NET працює на Windows, Linux і macOS. Той самий проєкт компілюється й
запускається на всіх трьох без змін у коді.

### Масштабованість застосувань

На C# пишуть:

| Сфера | Технологія |
|-------|-----------|
| Консольні програми | .NET Console — наш курс |
| Настільні застосунки | WPF, WinForms, MAUI — теми 24–26 |
| Вебсервіси та сайти | ASP.NET Core |
| Ігри | Unity — один із найпопулярніших рушіїв у світі |
| Мобільні застосунки | .NET MAUI |

## Порівняння з іншими мовами

| Критерій | C# | C++ | Python | JavaScript |
|----------|-----|-----|--------|------------|
| Типізація | Строга, статична | Строга, статична | Динамічна | Динамічна, слабка |
| Керування пам'яттю | Автоматичне (GC) | Ручне | Автоматичне | Автоматичне |
| Швидкодія | Висока | Найвища | Низька | Середня |
| Поріг входу | Середній | Високий | Низький | Низький |
| Помилки типів виявляються | На компіляції | На компіляції | Під час виконання | Під час виконання |

:::tip[Чому для навчання обрано саме C#]
C# стоїть посередині: він досить суворий, щоб привчити до дисципліни типів і
структури коду, і водночас досить зручний, щоб не витрачати перший семестр на ручне
керування пам'яттю. Навички, отримані тут, переносяться на Java майже один в один,
а на C++ і TypeScript — зі зрозумілими поправками.
:::

## Перша програма

Традиційно знайомство з мовою починають із програми, що виводить привітання.
Сучасний варіант виглядає так:

```csharp
Console.WriteLine("Привіт, світе!");
```

Один рядок. Розберемо його по частинах:

- `Console` — клас зі стандартної бібліотеки .NET, що відповідає за консольне
  введення й виведення;
- `.` — крапка означає «звернутися до члена»: візьми з класу `Console` те, що далі;
- `WriteLine` — метод, який виводить текст і переводить курсор на новий рядок;
- `("Привіт, світе!")` — аргумент методу: те, що саме виводити. Текст у подвійних лапках
  називається **рядковим літералом**;
- `;` — крапка з комою завершує інструкцію. Обов'язкова.

:::warning
Крапка з комою — не прикраса. Компілятор за нею розуміє, де закінчується одна
інструкція. Її пропуск — найчастіша помилка перших тижнів, і повідомлення про неї
часто вказує на **наступний** рядок, а не на той, де насправді проблема.
:::

### Чому раніше було 11 рядків

Той самий результат до C# 9 записувався так:

```csharp
using System;

namespace HelloApp
{
    class Program
    {
        static void Main(string[] args)
        {
            Console.WriteLine("Привіт, світе!");
        }
    }
}
```

Уся ця обгортка нікуди не зникла — компілятор дописує її сам. Ви побачите обидва
варіанти: у старих прикладах і в шаблонах Visual Studio — довгий, у сучасних
навчальних матеріалах — короткий. Що означає кожен рядок обгортки, розберемо
в підрозділі про структуру програми.

## Висновок

- **C#** створено в Microsoft у 2000 році під керівництвом Андерса Гейлсберга
  як безпечнішу альтернативу C++ для платформи .NET.
- **C#** — мова, **.NET** — платформа з бібліотеками, **CLR** — середовище виконання.
  Це три різні речі.
- Ключові властивості: об'єктна орієнтованість, **строга статична типізація**,
  автоматичне керування пам'яттю, кросплатформність.
- Строга типізація ловить помилки **на етапі компіляції** — до того, як програму
  побачить користувач.
- Найпростіша програма на сучасному C# — один рядок `Console.WriteLine("...");`
