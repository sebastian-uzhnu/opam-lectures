# Основи Visual Studio

## Поняття рішення і проекту

**Проект** — це набір файлів і ресурсів, що складають програму або бібліотеку. У межах одного проекту зберігаються всі необхідні для компіляції файли.
**Рішення** (solution) — це контейнер для одного або кількох проектів. Рішення дозволяє керувати взаємозв’язками між проектами і спрощує їх спільний розвиток.

---

## Створення проекту

* Відкрийте Visual Studio.
* Виберіть "Створити новий проект".
* Виберіть шаблон проекту (наприклад, "Console App", "Web Application").
* Вкажіть ім'я проекту та його місцезнаходження.
* Налаштуйте параметри проекту, такі як цільова платформа, мова програмування.
* Натисніть "Створити".

---

## Основні шаблони VS

:::note[Який шаблон потрібен у цьому курсі]
**Console App** — консольний застосунок. Саме він використовується в темах 1–14:
мінімум зайвого, уся увага на алгоритмах і мові.

Не переплутайте з **Console App (.NET Framework)** — це стара гілка платформи
лише для Windows. Обирайте варіант без приписки, з номером версії .NET.
:::

Visual Studio пропонує безліч шаблонів проектів, таких як:

* **Console Application** — для створення консольних програм.
* **Class Library** — для створення бібліотек класів.
* **ASP.NET Core Web Application** — для розробки веб-додатків.
* **Xamarin.Forms App** — для створення кросплатформених мобільних додатків.
* **Unit Test Project** — для написання тестів для вашого коду.

## Робота з редактором Visual Studio

Редактор Visual Studio підтримує:

* **Автодоповнення** — автоматичне завершення коду.
* **Підсвітка синтаксису** — виділення різних частин коду для кращої читабельності.
* **Інтелектуальні підказки (IntelliSense)** — рекомендації щодо методів, класів, змінних.
* **Рефакторинг** — автоматичні зміни коду для покращення його структури без зміни функціональності.

## Засоби запуску і відлагодження програм

Visual Studio надає різні засоби для запуску та відлагодження:

* **Точки зупинки (breakpoints)** — дозволяють зупинити виконання програми в певному місці.
* **Stepping** — можливість виконувати код покроково для детального аналізу.
* **Перегляд значень змінних** — відображення поточних значень змінних під час виконання програми.
* **Output Window** — виведення повідомлень про помилки, попередження та іншу діагностичну інформацію.

:::tip[Як налагодити програму: покрокова інструкція]
Уявіть, що програма рахує середній бал і видає `4` замість `4.33`. Замість того
щоб вгадувати, подивіться на неї зсередини:

1. **Поставте точку зупинки** — клацніть на сірому полі ліворуч від номера рядка
   (або натисніть <kbd>F9</kbd>). З'явиться червоний кружечок.
2. **Запустіть налагодження** — <kbd>F5</kbd>. Програма зупиниться на цьому рядку
   **до** його виконання.
3. **Подивіться значення** — наведіть курсор на будь-яку змінну або відкрийте
   вікно **Locals**: там перелічені всі поточні змінні та їхні значення.
4. **Виконайте крок** — <kbd>F10</kbd> (наступний рядок) або <kbd>F11</kbd>
   (зайти всередину методу).
5. **Продовжте** — <kbd>F5</kbd> до наступної точки зупинки.

Зазвичай уже на третьому кроці видно, що `sum` і `count` обидві типу `int` —
і причина неправильного результату знаходиться за півхвилини.
:::

:::note[Найкорисніші клавіші]
| Клавіші | Дія |
|---------|-----|
| <kbd>F5</kbd> | Запуск із налагодженням |
| <kbd>Ctrl</kbd>+<kbd>F5</kbd> | Запуск без налагодження |
| <kbd>F9</kbd> | Поставити/зняти точку зупинки |
| <kbd>F10</kbd> / <kbd>F11</kbd> | Крок через / крок усередину |
| <kbd>Ctrl</kbd>+<kbd>K</kbd>, <kbd>D</kbd> | Відформатувати весь файл |
| <kbd>Ctrl</kbd>+<kbd>.</kbd> | Швидкі виправлення й підказки |
:::

:::warning[Налагоджувач замість «виведу все через Console.WriteLine»]
Розставляти `Console.WriteLine` для перевірки значень — робочий спосіб, але
повільний: після кожної перевірки треба змінювати код і перезапускати програму,
а потім не забути все прибрати.

Точка зупинки показує **всі** змінні одразу, не вимагає змін у коді й нічого
не залишає по собі. Витратьте одну пару на освоєння <kbd>F9</kbd> і
<kbd>F10</kbd> — це заощадить десятки годин за семестр.
:::
