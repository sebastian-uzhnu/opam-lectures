# Стандартні типи даних

Тип даних визначає три речі: які значення можна зберігати, скільки пам'яті вони
займають і які операції над ними дозволені. У попередньому підрозділі ми бачили,
звідки беруться діапазони; тепер розберемо самі типи.

## Цілі типи

| Тип | Бітів | Діапазон | Коли використовувати |
|-----|-------|----------|----------------------|
| `sbyte` | 8 | −128 … 127 | Дуже рідко |
| `byte` | 8 | 0 … 255 | Байти файлів, компоненти кольору |
| `short` | 16 | −32 768 … 32 767 | Економія пам'яті у великих масивах |
| `ushort` | 16 | 0 … 65 535 | Рідко |
| **`int`** | **32** | **−2 147 483 648 … 2 147 483 647** | **Типовий вибір за замовчуванням** |
| `uint` | 32 | 0 … 4 294 967 295 | Рідко |
| `long` | 64 | ±9,2 · 10¹⁸ | Дуже великі числа, мітки часу |
| `ulong` | 64 | 0 … 1,8 · 10¹⁹ | Рідко |

:::tip[Практичне правило]
Використовуйте **`int`**, доки не з'явиться конкретна причина цього не робити.
Процесор працює з 32-бітними числами найефективніше, і економія пам'яті на `short`
в одиничній змінній нічого не дає — вона має сенс лише в масивах на мільйони елементів.
:::

### Приклад: коли `int` не вистачає

```csharp
int population = 2_000_000_000;         // ✅ вміщається
int tooBig = 3_000_000_000;             // ❌ помилка: більше за int.MaxValue

long bigNumber = 3_000_000_000;         // ✅ потрібен long
```

Максимум `int` — приблизно **2,15 мільярда**. Число 3 мільярди в нього
**не вміщається**, потрібен `long`.

```csharp
Console.WriteLine(int.MaxValue);    // 2147483647
Console.WriteLine(long.MaxValue);   // 9223372036854775807
```

:::warning[Класичний приклад із життя]
Кількість секунд від 1 січня 1970 року зберігали у 32-бітному числі. 19 січня
2038 року воно переповниться — це відома «проблема 2038 року». Сучасні системи
перейшли на `long`, але старе обладнання досі вразливе.
:::

## Дійсні типи

| Тип | Бітів | Точність | Призначення |
|-----|-------|----------|-------------|
| `float` | 32 | ~7 значущих цифр | Графіка, ігри — де важлива швидкість |
| **`double`** | **64** | **~15–17 цифр** | **Типовий вибір для дробових** |
| `decimal` | 128 | 28–29 цифр | **Гроші та фінанси** |

```csharp
float f = 3.14f;         // суфікс f обов'язковий
double d = 3.14;         // за замовчуванням дробовий літерал — double
decimal m = 3.14m;       // суфікс m обов'язковий
```

### Чому для грошей потрібен `decimal`

`float` і `double` зберігають числа у двійковій системі, а `0.1` у двійковій —
нескінченний дріб (як `1/3` у десятковій). Звідси похибки:

```csharp
double a = 0.1 + 0.2;
Console.WriteLine(a);              // 0.30000000000000004
Console.WriteLine(a == 0.3);       // False

decimal b = 0.1m + 0.2m;
Console.WriteLine(b);              // 0.3
Console.WriteLine(b == 0.3m);      // True
```

`decimal` зберігає числа в десятковій системі — повільніше, зате без сюрпризів.

:::warning
Ніколи не зберігайте грошові суми в `double`. У банківському застосунку похибка
в соті копійки, помножена на мільйон операцій, перетворюється на реальні гроші
й реальний судовий процес.
:::

## Символьний тип `char`

Зберігає **один** символ Unicode, 16 бітів.

```csharp
char letter = 'A';
char digit = '7';
char newLine = '\n';

Console.WriteLine((int)letter);   // 65 — код символу
Console.WriteLine((char)66);      // B
```

Керуючі послідовності — символи, які не можна написати напряму:

| Послідовність | Значення |
|---------------|----------|
| `\n` | Новий рядок |
| `\t` | Табуляція |
| `\\` | Сам зворотний слеш |
| `\"` | Подвійна лапка |
| `\'` | Одинарна лапка |

## Логічний тип `bool`

Два значення: `true` або `false`.

```csharp
bool isReady = true;
bool isEmpty = (count == 0);
```

:::note
У C# `bool` **не є числом**. Запис `if (1)`, звичний для C++, тут не скомпілюється —
умова має бути саме `bool`. Це знову ж таки захист від помилок.
:::

## Рядковий тип `string`

Послідовність символів. На відміну від попередніх, це **посилальний** тип.

```csharp
string name = "Олена";
string empty = "";
string multi = "Перший рядок\nДругий рядок";
```

Основні дії:

```csharp
string s = "Програмування";

Console.WriteLine(s.Length);          // 13 — кількість символів
Console.WriteLine(s.ToUpper());       // ПРОГРАМУВАННЯ
Console.WriteLine(s.Substring(0, 5)); // Progr → "Прогр"
Console.WriteLine(s.Contains("грам"));// True
Console.WriteLine(s[0]);              // П — символ за індексом
```

Склеювання рядків і інтерполяція:

```csharp
string first = "Іван";
string last = "Петренко";

string full1 = first + " " + last;          // конкатенація
string full2 = $"{first} {last}";           // інтерполяція — зручніше
```

:::tip
Інтерполяція `$"..."` майже завжди читабельніша за склеювання через `+`,
особливо коли в рядку є числа:

```csharp
Console.WriteLine("Сума: " + sum + " грн, знижка " + discount + "%");
Console.WriteLine($"Сума: {sum} грн, знижка {discount}%");   // ✅ краще
```
:::

## Стандартні функції

Багато математичних дій уже реалізовано в класі **`Math`** — писати їх самостійно
не треба.

| Метод | Дія | Приклад | Результат |
|-------|-----|---------|-----------|
| `Math.Abs(x)` | Модуль | `Math.Abs(-7)` | `7` |
| `Math.Pow(x, y)` | Степінь | `Math.Pow(2, 10)` | `1024` |
| `Math.Sqrt(x)` | Квадратний корінь | `Math.Sqrt(16)` | `4` |
| `Math.Round(x)` | Округлення | `Math.Round(3.6)` | `4` |
| `Math.Floor(x)` | Округлення вниз | `Math.Floor(3.9)` | `3` |
| `Math.Ceiling(x)` | Округлення вгору | `Math.Ceiling(3.1)` | `4` |
| `Math.Max(a, b)` | Більше з двох | `Math.Max(3, 7)` | `7` |
| `Math.Min(a, b)` | Менше з двох | `Math.Min(3, 7)` | `3` |
| `Math.PI` | Число π | — | `3.14159...` |

```csharp
// Довжина гіпотенузи за теоремою Піфагора
double a = 3, b = 4;
double c = Math.Sqrt(Math.Pow(a, 2) + Math.Pow(b, 2));
Console.WriteLine(c);   // 5

// Площа круга
double radius = 5;
double area = Math.PI * Math.Pow(radius, 2);
Console.WriteLine($"{area:F2}");   // 78.54
```

:::note[Округлення «до парного»]
```csharp
Console.WriteLine(Math.Round(2.5));   // 2, а не 3!
Console.WriteLine(Math.Round(3.5));   // 4
```

За замовчуванням `Math.Round` використовує «банківське округлення» — до найближчого
парного. Це зменшує систематичну похибку у великих обсягах обчислень. Щоб отримати
звичне шкільне округлення:

```csharp
Console.WriteLine(Math.Round(2.5, MidpointRounding.AwayFromZero));   // 3
```
:::

## Перетворення типів

```csharp
// Неявне (розширення) — без втрат, автоматично
int small = 5;
double big = small;        // ✅ int вміщається в double

// Явне (звуження) — з можливою втратою, потрібне приведення
double d = 9.8;
int i = (int)d;            // 9 — дробова частина ВІДКИДАЄТЬСЯ, не округлюється

// З рядка в число
string text = "42";
int number = int.Parse(text);
```

:::warning
`(int)9.8` дає `9`, а не `10`. Приведення типу **відкидає** дробову частину.
Щоб округлити, потрібен `Math.Round`:

```csharp
int rounded = (int)Math.Round(9.8);   // 10
```
:::

Детально всі види перетворень розглянемо в темі 3.

## Визначення типу: `var`

Якщо тип очевидний із правої частини, його можна не писати:

```csharp
var age = 20;              // компілятор виводить int
var name = "Олена";        // string
var price = 19.99;         // double
```

Це **не** динамічна типізація: тип визначається на етапі компіляції й далі
не змінюється.

```csharp
var x = 5;
x = "текст";    // ❌ помилка: x має тип int
```

## Зведена таблиця

| Треба зберегти | Тип | Приклад |
|----------------|-----|---------|
| Кількість, індекс, вік | `int` | `int count = 10;` |
| Дуже велике ціле | `long` | `long id = 5_000_000_000;` |
| Вимірювання, середнє | `double` | `double avg = 4.75;` |
| Гроші | `decimal` | `decimal price = 199.99m;` |
| Один символ | `char` | `char grade = 'B';` |
| Текст | `string` | `string name = "Олена";` |
| Так/ні | `bool` | `bool isDone = false;` |

## Висновок

- **`int`** — типовий вибір для цілих, **`double`** — для дробових,
  **`decimal`** — обов'язково для грошей.
- Максимум `int` ≈ **2,15 мільярда**; для більших чисел потрібен `long`.
- `float`/`double` зберігають числа наближено — звідси `0.1 + 0.2 != 0.3`.
- `char` — один символ в одинарних лапках, `string` — текст у подвійних.
- Клас **`Math`** містить готові математичні функції; `Math.Round` за замовчуванням
  округлює до парного.
- Приведення `(int)` **відкидає** дробову частину, а не округлює.
- **`var`** не робить типізацію динамічною — тип визначається на компіляції.
