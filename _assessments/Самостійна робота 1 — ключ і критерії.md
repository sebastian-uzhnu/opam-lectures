## Рівень 1. Знання — по 1 б.

**1.** Яка властивість алгоритму означає, що він завершується після скінченної кількості кроків?

Відповідь: **C) Скінченність**

> Скінченність (завершуваність) — алгоритм не може виконуватись нескінченно.

**2.** Яка властивість алгоритму означає, що його можна застосувати до цілого класу однотипних задач, а не лише до одного набору даних?

Відповідь: **B) Масовість**

> Масовість: алгоритм ділення стовпчиком працює для будь-яких чисел, а не лише для 12 і 4.

**3.** Який елемент блок-схеми позначає перевірку умови?

Відповідь: **B) Ромб**

> Ромб — блок розгалуження, з нього виходять дві гілки: «так» і «ні».

**4.** Яким блоком на блок-схемі позначають початок і кінець алгоритму?

Відповідь: **C) Овал**

> Овал (термінатор). Прямокутник — дія, паралелограм — введення-виведення.

**5.** Що з переліченого НЕ є способом запису алгоритму?

Відповідь: **D) Компілятор**

> Компілятор — це програма, що перекладає код, а не форма запису алгоритму.

**6.** З якого етапу починається розв'язання задачі за допомогою комп'ютера?

Відповідь: **B) Постановка задачі**

> Спершу треба зрозуміти, що саме є вхідними даними і який результат потрібен.

**7.** Скільки бітів міститься в одному байті?

Відповідь: **B) 8**

> 1 байт = 8 бітів, тобто 256 різних значень.

**8.** Який метод є точкою входу консольної програми на C#?

Відповідь: **C) Main**

> Виконання починається з методу Main.

**9.** Як у C# записують однорядковий коментар?

Відповідь: **B) // коментар**

> // — однорядковий, /* */ — багаторядковий.

**10.** Який тип даних у C# використовують для зберігання логічного значення «істина або хиба»?

Відповідь: **B) bool**

> bool має лише два значення: true і false.

**11.** Скільки байтів у пам'яті займає змінна типу int у C#?

Відповідь: **B) 4**

> int — це 32 біти, тобто 4 байти, діапазон приблизно від -2,1 до +2,1 мільярда.

**12.** Яке ключове слово дозволяє оголосити змінну так, щоб компілятор сам визначив її тип зі значення?

Відповідь: **C) var**

> var — неявна типізація. Тип визначається на етапі компіляції і надалі не змінюється.

**13.** Яке значення за замовчуванням має неініціалізоване поле типу bool у C#?

Відповідь: **B) false**

> Числові типи отримують 0, bool — false, посилальні типи — null.

**14.** Який символ ставлять перед рядком у C#, щоб використати інтерполяцію?

Відповідь: **B) $**

> $"Привіт, {name}!" — значення змінної підставляється прямо в рядок.


## Рівень 2. Розуміння — по 2 б.

**15.** Що виведе програма? int a = 7; int b = 2; Console.WriteLine(a / b);

Відповідь: **B) 3**

> Обидва операнди цілі, тому ділення цілочисельне: дробова частина відкидається, 7 / 2 = 3.

**16.** Що виведе програма? int x = 5; x += 3; x *= 2; Console.WriteLine(x);

Відповідь: **B) 16**

> x += 3 дає 8, потім x *= 2 дає 16. Операції виконуються послідовно.

**17.** Яким буде результат виразу 17 % 5?

Відповідь: **B) 2**

> % — остача від ділення: 17 = 5 * 3 + 2.

**18.** Що виведе цей код? Console.WriteLine("Сума: " + 2 + 3);

Відповідь: **B) Сума: 23**

> Операції виконуються зліва направо: "Сума: " + 2 дає рядок "Сума: 2", далі до нього дописується 3.

**19.** Яке значення матиме змінна result? bool result = (5 > 3) && (2 > 4);

Відповідь: **B) false**

> Перша умова істинна, друга хибна. Операція && дає true лише коли істинні обидві.

**20.** Які з перелічених типів C# є значимими (value types)? Оберіть усі правильні варіанти.

Відповіді: **A) int, C) double, D) bool**

> int, double і bool — значимі типи і живуть у стеку. string та object — посилальні.

**21.** Що робить керуюча послідовність \n усередині рядка?

Відповідь: **B) Переводить курсор на новий рядок**

> \n — новий рядок, \t — табуляція, \\ — сам слеш, \" — лапки.

**22.** Який із записів є прикладом розширення типу (неявного перетворення)?

Відповідь: **B) double d = 5;**

> int вміщується в double без втрат, тому компілятор перетворює сам. Решта варіантів — явне перетворення або розбір рядка.

**23.** Що виведе цей код? int a = 10; int b = a; b = 20; Console.WriteLine(a);

Відповідь: **A) 10**

> int — значимий тип, тому b отримує копію значення. Зміна b не впливає на a.

**24.** Де у пам'яті зберігається значення локальної змінної типу int, оголошеної всередині методу?

Відповідь: **B) У стеку (stack)**

> Значимі типи розміщуються у стеку і звільняються автоматично при виході з методу.

**25.** Що виведе цей код? string path = @"C:\temp\file.txt"; Console.WriteLine(path);

Відповідь: **A) C:\temp\file.txt**

> Символ @ робить рядок дослівним (verbatim): керуючі послідовності в ньому не обробляються.

**26.** Які твердження про рішення (Solution) та проєкт (Project) у Visual Studio є правильними? Оберіть усі правильні варіанти.

Відповіді: **A) Рішення може містити кілька проєктів, C) Кожен проєкт компілюється в окрему збірку**

> Рішення — контейнер для проєктів. Кожен проєкт дає свою збірку (exe або dll).


## Рівень 3. Застосування — по 4 б.

**27.** Обчисліть значення виразу, якщо всі числа цілі: 2 + 3 * 4 - 6 / 2. Запишіть лише число.

Відповідь: **11**

> Спершу множення й ділення: 3 * 4 = 12, 6 / 2 = 3. Далі 2 + 12 - 3 = 11.

**28.** Переведіть число 25 з десяткової системи числення у двійкову. Запишіть лише результат, без пробілів.

Відповідь: **11001**

> 25 = 16 + 8 + 1, тобто 11001 у двійковій системі.

**29.** Обчисліть результат побітової операції 12 & 10 і запишіть його в десятковій системі.

Відповідь: **8**

> 12 = 1100, 10 = 1010. Побітове І дає 1000, тобто 8.

**30.** Що виведе цей код? byte b = 250; b += 10; Console.WriteLine(b);

Відповідь: **B) 4**

> byte вміщує значення 0..255. Відбувається переповнення: 260 - 256 = 4. За замовчуванням воно не перевіряється (unchecked).

**31.** Знайдіть помилку в цьому коді: int age = "18"; Console.WriteLine(age);

Відповідь: **B) Не можна присвоїти рядок змінній типу int без перетворення**

> "18" — це рядок. Потрібно int age = int.Parse("18"); або краще int.TryParse.

**32.** Що станеться з цим кодом? int x = 5; if (x = 3) { Console.WriteLine("Три"); }

Відповідь: **C) Помилка компіляції: не можна перетворити int на bool**

> Тут один знак = замість двох. Вираз x = 3 дає число, а if вимагає bool. У C# це помилка компіляції.

**33.** Що виведе цей код? int a = 5; Console.WriteLine(a++ + " " + a);

Відповідь: **B) 5 6**

> Постфіксний a++ повертає старе значення 5, після чого a стає 6. Друга частина виразу бачить уже 6.

**34.** Що виведе цей код? double result = 0.1 + 0.2; Console.WriteLine(result == 0.3);

Відповідь: **B) False**

> Типи double і float зберігають дроби наближено, тому 0.1 + 0.2 не дорівнює точно 0.3. Для грошей використовують decimal.


## Рівень 4. Аналіз — по 6 б.

**35.** Складіть словесний алгоритм обчислення середнього арифметичного трьох чисел, які вводить користувач. Запишіть 5-7 кроків і навпроти кожного вкажіть, яким блоком блок-схеми він позначався б (овал, паралелограм, прямокутник, ромб).

Відкрите питання — оцінюється вручну.

> Очікується: 1) початок (овал); 2) введення трьох чисел (паралелограм); 3) обчислення суми (прямокутник); 4) ділення суми на 3 (прямокутник); 5) виведення результату (паралелограм); 6) кінець (овал). По 1 балу за кожен коректний крок, до 6 балів. Ромб тут не потрібен — це лінійний алгоритм, і згадка про це заслуговує окремого заохочення.

**36.** Поясніть різницю між значимими (value) та посилальними (reference) типами даних. Наведіть по два приклади кожного виду і опишіть, що відбувається при копіюванні змінної кожного виду в іншу змінну.

Відкрите питання — оцінюється вручну.

> Очікується: значимі типи зберігають саме значення у стеку, при копіюванні створюється незалежна копія (2 бали); посилальні зберігають посилання на об'єкт у купі, при копіюванні обидві змінні вказують на той самий об'єкт (2 бали); приклади: int, double, bool, char, struct / string, object, масиви, класи (1 бал); коректний приклад коду або опис наслідку зміни через друге посилання (1 бал).

**37.** Поясніть, чому вираз (int)3.9 дає 3, а не 4. Що таке звуження типу і чим воно небезпечне? Як у C# змусити програму повідомляти про переповнення замість того, щоб мовчки видавати неправильний результат?

Відкрите питання — оцінюється вручну.

> Очікується: приведення double до int відкидає дробову частину, а не округлює (2 бали); звуження — перетворення до типу з меншим діапазоном, дані можуть втратитися або виникне переповнення (2 бали); ключове слово checked кидає OverflowException, згадка про Math.Round для округлення (2 бали).

**38.** Опишіть шлях програми на C# від написаного коду до виконання на комп'ютері. Поясніть, що таке проміжна мова IL, JIT-компіляція та середовище CLR і навіщо потрібен кожен із цих етапів.

Відкрите питання — оцінюється вручну.

> Очікується: вихідний код .cs компілюється Roslyn не в машинний код, а в проміжну мову IL, яка лягає у збірку .dll або .exe (2 бали); під час запуску CLR за допомогою JIT перекладає IL у машинний код конкретного процесора (2 бали); навіщо: переносимість між платформами й оптимізація під конкретне обладнання, CLR також відповідає за керування пам'яттю і збирач сміття (2 бали).

**39.** Напишіть код консольної програми, яка запитує в користувача ім'я та рік народження, обчислює приблизний вік і виводить повідомлення у форматі: Привіт, Ольго! Тобі 18 років. Використайте інтерполяцію рядків і безпечне перетворення введеного року в число.

Відкрите питання — оцінюється вручну.

> Очікується: Console.Write із запитом і Console.ReadLine (1 бал); int.TryParse замість int.Parse із перевіркою результату (2 бали); коректне обчислення віку через DateTime.Now.Year (1 бал); інтерполяція $"Привіт, {name}! Тобі {age} років." (2 бали). Якщо використано Parse без перевірки — мінус 2 бали.
