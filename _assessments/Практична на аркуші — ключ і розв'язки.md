## Рівень 1 — по 3 б.

### Р1-1

**Умова.** Оголосіть дві цілі змінні зі значеннями 15 і 4. Виведіть чотири окремі рядки: суму, різницю, добуток і частку від цілочисельного ділення. Кожен рядок — із підписом.

```csharp
int a = 15;
int b = 4;
Console.WriteLine($"Сума: {a + b}");
Console.WriteLine($"Різниця: {a - b}");
Console.WriteLine($"Добуток: {a * b}");
Console.WriteLine($"Частка: {a / b}");
```

**Вивід:**

```
Сума: 19
Різниця: 11
Добуток: 60
Частка: 3
```

> Частка саме 3, а не 3,75 — обидва операнди цілі.

### Р1-2

**Умова.** Програма запитує ім'я користувача і вітається з ним. Обов'язково скористайтеся інтерполяцією рядків.

```csharp
Console.Write("Як тебе звати? ");

Console.WriteLine($"Привіт, {name}! Раді бачити.");
```

**Вивід:**

```
Як тебе звати? Олена
Привіт, Олено! Раді бачити.
```

> Без символу $ перед рядком інтерполяція не спрацює.

### Р1-3

**Умова.** Одним викликом Console.WriteLine виведіть дві колонки, вирівняні табуляцією: перший рядок — Ім'я та Вік, другий — Олена та 18.

**Вивід:**


> \t — табуляція, \n — перехід на новий рядок.

### Р1-4

## Рівень 2 — по 4 б.

### Р2-1

**Умова.** Користувач вводить довжину та ширину прямокутника (цілі числа). Обчисліть і виведіть периметр та площу.

### Р2-2

**Умова.** Користувач вводить ціну товару (дробове число) і кількість (ціле). Виведіть суму до сплати з двома знаками після коми.

### Р3-2

**Умова.** Товар коштує 47 грн, покупець дав 100 грн. Обчисліть решту і виведіть, скількома купюрами по 20, по 10, по 5 та монетами по 1 грн її можна видати. Купюр кожного номіналу треба видати якнайбільше.

```csharp
int price = 47;
int paid = 100;
int change = paid - price;

int b20 = change / 20;
change = change % 20;
int b10 = change / 10;
change = change % 10;
int b5 = change / 5;
int c1 = change % 5;

Console.WriteLine($"Решта: {paid - price} грн");
```

**Вивід:**


> Перевірка: 2×20 + 1×10 + 0×5 + 3×1 = 53. Після кожного номіналу лишок зберігаємо назад у change.

### Р3-4

**Умова.** Оголосіть змінну типу byte зі значенням 200 і додайте до неї 100. Запишіть, що виведе програма і чому. Потім допишіть варіант коду, у якому програма повідомить про переповнення замість тихого неправильного результату.

```csharp
byte value = 200;
value += 100;
Console.WriteLine(value);        // 44 — тихе переповнення
```

## Виправлення помилки — по 3 б.

### В-1

**Код студентові:**

```csharp
int age = "18";
Console.WriteLine(age);
```

**Правильно:**

```csharp
int age = int.Parse("18");
Console.WriteLine(age);
```

> "18" — це рядок, а age оголошено як int. Потрібне перетворення (або треба було оголосити string age = "18";).

### В-2

**Код студентові:**

```csharp
Console.Write("Введи число: ");
int n = Console.ReadLine();
Console.WriteLine(n * 2);
```

**Правильно:**

```csharp
Console.Write("Введи число: ");
int n = int.Parse(Console.ReadLine());
Console.WriteLine(n * 2);
```

> Console.ReadLine повертає string, його не можна присвоїти змінній типу int напряму.

### В-3

**Код студентові:**

```csharp
double average = (7 + 2) / 2;
Console.WriteLine(average);
```

**Правильно:**

```csharp
double average = (7 + 2) / 2.0;
Console.WriteLine(average);
```

> Код компілюється, але виводить 4 замість 4,5: ділення цілочисельне, і лише потім результат перетворюється в double.

### В-4

**Код студентові:**

```csharp
Console.WriteLine("Шлях: C:\temp\new.txt");
```

**Правильно:**

```csharp
Console.WriteLine("Шлях: C:\\temp\\new.txt");
// або
Console.WriteLine(@"Шлях: C:\temp\new.txt");
```

> \t сприймається як табуляція, а \n — як новий рядок. Слеші треба подвоїти або зробити рядок дослівним через @.

### В-5

**Код студентові:**

```csharp
int x = 5
Console.WriteLine(x);
```

**Правильно:**

```csharp
int x = 5;
Console.WriteLine(x);
```

> Пропущена крапка з комою наприкінці оголошення змінної.

### В-6

**Код студентові:**

```csharp
string name = "Олена";
Console.WriteLine("Привіт, {name}!");
```

**Правильно:**

```csharp
string name = "Олена";
Console.WriteLine($"Привіт, {name}!");
```

> Без символу $ рядок не інтерполюється — виведеться буквально «Привіт, {name}!».


## Як оцінювати

Бали за завдання нараховуються так:

- **повний бал** — код робочий, типи обрані правильно, вивід відповідає умові;
- **мінус 1 бал** — код по суті правильний, але є одна змістовна недоробка: забутий підпис у виводі, конкатенація замість інтерполяції там, де її вимагала умова, зайва змінна;
- **половина балів** — правильна ідея, але зламана типізація: цілочисельне ділення там, де потрібне дробове, або відсутнє перетворення `Console.ReadLine`;
- **0 балів** — розв'язок не відповідає умові або відсутній.

Описки в назвах (`Console.Writeline`, `int.parse`) помилкою не вважаються: на аркуші немає підказок середовища. А от `int n = Console.ReadLine();` — це саме змістовна помилка, бо вона про типи.

У завданні на виправлення помилки бали діляться так: **2 бали** за правильно переписаний код і **1 бал** за пояснення причини. Якщо студент виправив код навмання, але не може пояснити, чому — 2 бали.
